# 裁定:可达性战役收束 —— (A) 验 R3,决定性分岔;R3 验证预注册

*车道A,2026-07-24。承接可达性战役 (ii) 三放松候选备料完整。裁定 (A),但把 R3 代价框定完整、预注册两半验证判据、交还纲领边界价值判断给 PI。*

## 正面事实(立住)

三放松候选(R1 严格局域 / R2 涌现物质 / R3 精确约束)**全部能达 N_prop=2**,J5 共锥(3.3e-16)+ TT(3.1e-16)全不破。⟹ 不是"绝对不可达",是"放松任一条即可达,问题是代价"。M3 有价,不是死的。

## R3 代价的完整框定(比备料更透)

R3 = **传播 DOF 涌现(核心主张保住,N_prop=2 从走行来)** + 约束近似(12–18% 残差)+ 违反用 R26 清除。

**关键正面框定**:"约束不精确保持"不是我们的缺陷,是所有离散引力的共同特征——数值相对论(BSSN/Z4/CCZ4)从无人精确离散保约束,全靠 constraint damping。所以 R3 若成立,结论 = "线性化引力波 2 极化从 QCA 走行涌现,约束用双曲阻尼控制,如同数值相对论"——**不是纲领失败,是把纲领接到主流数值相对论标准实践上**。可发表的正面结果。

## 对抗性质询(决定 R3 真软还是伪软)

RC3 障碍是二分:(a) −ω 约束行曲率(ker C 外=约束违反,R26 能清)+ (b) +ω gauge 传播(ker C **内**=约束满足,**R26 清不了**)。备料只讲 (a) 半是 R26 class,**没说清 R3 达 N_prop=2 怎么处理 (b)**。R35 已判:(b) slave 路线死、复形路线要走行结构改动(破坏涌现)。

⟹ 若 R3 达 2 悄悄对 (b) 做复形结构改动,则 R3 偷含 R2 手搭代价,"最小代价"作废。

## R3 验证预注册(两半判据,分支写死)

**(a) 半 —— R26 可清除性重认证**(在 RC3 定位的具体 −ω 行曲率上重跑 R26):
- PASS = 残余 ≤ 1e-3、时标 ~L/c、k-无关(对齐 R26 原 12/12 证书);
- FAIL = 残余不降 / 时标发散 / 清除后 N_prop 仍 >2。

**(b) 半 —— gauge 传播处理质询**(R3 达 N_prop=2 时 +ω gauge 模如何零曲率化):
- PASS = 不需要结构改动(找到非破坏涌现的机制)⟹ R3 真软;
- FAIL = 需要复形结构改动(破坏涌现/J5)⟹ R3 偷含 R2 代价,"最小"作废,重新评估。

**合流分支:**
- 两半 PASS 且 (b) 不破坏涌现 → **R3 正面收束**(引力波涌现 + 标准约束阻尼),可达性战役以正面结局关闭,进 M3/卡点④;
- 任一半 FAIL → 三候选只剩 R1(弃局域,基本不选)/ R2(弃涌现)→ 逼近 **(B) 封存**"M3 结构性不可达 / 须弃核心主张"。

## 交还 PI 的纲领边界价值判断

即使 R3 两半全 PASS,仍有一个**不是技术能答的**问题归 PI:**"精确约束传播 → 阴影守恒(约束近似 + 清除)"这个代价,是否越过你不愿放松的线?**
- 若你接受(理由:数值相对论也这样,核心主张"引力波涌现"保住)→ (A) 验证过即正面收束;
- 若你认为"精确约束"本身是纲领不可放松的承诺(即便 R26 能清,那也不再是精确约束涌现)→ 即便 (A) 过,也应 (B) 封存,战役结论 = "纲领四承诺(精确约束+涌现+严格局域+酉)全要时,自旋2 M3 结构性不可达"——干净、有完整证据链的科学结论。

**这个价值判断我不替你做。** 技术上 (A) 值得先验(便宜、可证伪、决定正面 vs 结构性两种天壤结局);但验证过之后要不要接受 R3 的代价,是你的线。

## PI 裁定(2026-07-24,验证结果出来之前预注册,不许事后改)

**价值判断回答:"精确约束传播 → 阴影守恒 + R26 清除"不越过纲领的线。** 三条理由,全部
出自纲领自己的文件:
1. "精确约束传播"从不在 H 层承诺(阶段复盘 §6.1 H 层=幺正/概率、严格局域与因果、守恒、
   2 引力子 DOF、J5、Newton/Eddington;约束**处理方式**是 S 层实现选择,非物理承诺);
2. 纲领在 L2 采纳 Z4c 时已裁"Z4c 定性为必然而非移植"——约束被动力学控制在那一刻已被
   接受;北极星 M3 约束门本身="衰减到机器底"(动力学达成),非逐步恒等为零;
3. 车道A 框定采纳为正式口径:数值相对论(BSSN/Z4/CCZ4)从无人精确离散保约束,全靠
   constraint damping。R3 真软 ⟹ 结论="引力波 2 极化从 QCA 走行涌现 + 约束双曲阻尼控制,
   如同数值相对论"=把纲领接到主流标准实践,可发表正面结果。

**分支映射(写死)**:两半 PASS 且 (b) 无结构改动 → 正面收束,进 M3/卡点④;任一半 FAIL
(尤其 (b) 偷含手搭)→ (B) 封存"四承诺(精确约束+涌现+严格局域+酉)全要时自旋2 M3
结构性不可达",不再有第三条路、不找新假说。
**边界防夸大**:即使正面收束,措辞为"涌现 + 约束阻尼控制"(NR 标准实践),不得写成
"精确约束下涌现";R30 存在性构造(算子恒等式路线)作为定理保留——它证明恒等式路线
**存在**,只是涌现走行走的是阻尼路线,两者并立不矛盾。
