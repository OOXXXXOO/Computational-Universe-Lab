## 一、总原则

1. **先验 = 连续采样参数**,构成未来 M4 流形搜索的坐标;**炮 = 离散开关**,
   不进先验,只在全绿点上重放、必须在预期列上 FAIL。离散病态开关混进先验会
   制造不连通伪流形,污染连通性分析(M4 草案 §一.2 条款,原样继承)。
2. **硬要求(强主张恢复的前提,复盘 §五)**:族必须包含**非 GR 候选**——
   即存在先验测度非零的方向,其上候选离开 GR 通道并被预注册 QA 剪掉。
   §三逐条写明哪些方向离开 GR 通道、预期哪个证书列剪它、以及自测实测结果。
3. **先验覆盖门边界**:采样范围故意越出预期存活区(两侧),使每条轴都能画出
   "存活率(阈值)"剪刀曲线并有先验对照(44M 符号教训:没有对照的"律"可能是
   采样伪影)。**进先验 ≠ 预期存活**;某些轴(selector 轴)的存活集预期是
   基点的机器精度邻域,采样它正是为了把这条"精确暗"选择律定量化。
4. 判据口径(列阈值、门 k 集、rank 容差 1e-9、格子、频率支约定)全部冻结,
   不采样、不调参;见 `data/runtime/r25_eval_schema.json`(schema `r25_eval/v1`)。
5. 本草案**不发令、不含长跑停跑常量**:阶段B只做小规模 compose 与负控
   (复盘 §七阶段B"先跑小规模,不直接放 10⁵");10⁵ 级战役的停跑规则在
   M4 预注册时另立(参照 M4 草案 §三的三条安全阀结构)。

### 冻结项盘点(不采样,防调参漂移)

θ=π/3、c=1/2(共锥归一)、物质 walk 符号(`cp1_v4_L2.walk_symbol`,xyz 序,
sha256 入 schema provenance)、η=diag(−1,1,1,1)、SYM 打包次序、门 k 集
(六个 32 格模,含体对角 (2,2,2))、rank 容差 1e-9、各列阈值
(J5<1e-2、恒等残差<1e-11、暗性<1e-11、虚部<1e-12)、随机采样种子策略。

### 逐轴理由(节选)

1. **`alpha_W` 是本族第一物理轴**。UV exceptional 审计(r25_uv_exceptional)
   证明冻结物质 walk 有精确第二 +I 节点 `k_x=k_z=−1.714143896`,canonical
   detour 在该点秩崩塌;auxiliary Wilson mapping cone(r25_auxiliary_wilson)
   以 r=α·q 提升该节点同时保留原点 Newton 零模。α 的两端死法不同
   (下端 UV、上端稳定窗),正好画出双侧剪刀。α 大端边界 0.657 是 32³ 口径
   的实测参考值,不冻结为门——门是"全 BZ 0<a_W<4"本身。
2. **selector 轴是"精确暗"选择律的候选**。基点 (0.75, 3.0) 使局域 Newton
   lift 恰好落在全部 8 行约束核内(实测 4.1e−15);任何偏移都让 auxiliary
   dressing 污染静态通道(非 GR 静态响应,§三)。采样它不是期待存活,而是
   让 M4 能报告"存活集在 selector 轴上塌缩到基点"这一定量选择律——与 M4
   草案 dθ 轴的方法完全同构(J5 剪刀的解析预期 ↔ 此处暗性残差的线性剪刀)。
3. **`mu_damp` 占位条款**。复盘 §2.4:当前直接收缩最慢率 ≈0.99999937,
   达机器底需 ~5×10⁷ 步,不可接受;预条件化搜索(卡点②)被主动停止待复盘。
   本轴现在只锁"稳定 + 单位模恰 12 + 率如实报告"三件,不锁率门数值;
   卡点②胜者出来后,以其参数化替换本轴并重新预注册率门。
4. **轴序不进先验**(继承 M4 草案 §二.6 的裁定与双方案结构):它是实现
   规范选择,进先验只会把同一物理的不同实现计成不同规则,稀释真实轴的
   统计功效;且 R25 的门 k 集/oracle 全部按 xyz 预注册,静默混采样违反
   "不许静默绕开"条款。

## 三、非 GR 候选:哪些方向离开 GR 通道,谁剪它们(硬要求落实)

**前提声明**:M4 恢复"规则空间涌现 GR"强主张,要求族中存在会被 QA 剪掉的
非 GR 候选,否则"存活"是同义反复。本族当前的非 GR 方向及自测实测
(`data/results/r25_family_eval_selftest.json`,N1–N6 全部按预期红):

| # | 方向 | 离开 GR 通道的方式 | 预期剪它的列 | 自测 |
|---|---|---|---|---|
| N1 | `alpha_W=0`(无 Wilson) | 第二 UV 节点保留额外同调 → 额外静态极点/额外 UV 态(非 GR 谱内容) | uv_audit(连坐 cohomology、contraction) | 红 ✓ |
| N2 | selector 偏移(如 `sel_trace=2.0`) | Newton lift 失暗 → auxiliary dressing 进静态响应(第五力型偏离) | static_newton | 红 ✓ |
| N3 | `selector_family=none` | 无消除 syzygy → 商维 6:四个 auxiliary 假 DOF 计入物理(错误引力子计数) | cohomology | 红 ✓ |
| N4 | `pairing=single` | 物理度规复值(非物理实结构) | reality_pairing | 红 ✓ |
| N5 | `axis_order=zyx`(仅几何) | 几何壳离开物质壳 → 双锥(J5 违反) | shell_J5 | 红 ✓ |
| N6 | `mu_damp=0.03` | 约束收缩变注能/失稳(J1 型死亡) | contraction_rate | 红 ✓ |
| — | `alpha_W≳0.657` | 稳定窗破 a_W≥4(J1 型) | static_newton + contraction | 边界待族扫描画出 |

**诚实边界(必须写进 M4 报告)**:上述非 GR 方向都是"R25 构造的破坏方向",
即同一生成元字典内的变形;它们支持"这些 QA 有牙",但还不构成"宽规则空间"。
M4 发令前应评审是否再加**独立生成元轴**(例:κ 的其他 Laurent 分解、E 算子
的非 detour 变形、非 Killing 型 G 候选),作为扩展轴另行预注册;本草案先把
现有证书链覆盖的轴钉死。
