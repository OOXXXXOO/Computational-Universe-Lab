# 任务书:可达性战役 —— 涌现走行形变到 R30 复形

*车道A 编排,2026-07-24。执行=lane B,复核=车道A,拍板=PI。判据预注册,开工后只许收紧。承接 R30(复形存在,已独立复核)+ R32(锁死信号)+ R33(便宜档够不着,精炼判据)。*

---

## 0. 一句话目标

判定:**涌现的物质走行的传播不变子空间,能否被形变到 R30 已证存在的复形的 ker C 上,使无投影 N_prop=2。** 这是 M3 涌现A门的定义,也是卡点④ 的前置。

## 1. 战役性质(先说死,防误读)

这是**可达性判定战役**,不是构造保证。它的合法产出是二选一之一:
- **可达**(找到形变通道)→ 转构造 → 卡点④ 可达;
- **拓扑锁死**(通道被不变量堵死)→ 转 R29 式裁定(放松酉/局域/精确约束/手性物质哪一项)。

两个都是有价值的诚实结果。**不预设哪个。** R30 的边界继续保持:复形存在≠涌现≠M3。

## 2. 前置事实(这场仗的地基,不重验)

- R30:局域酉离散线性化-Bianchi 张量复形**存在**,ker C=规范⊕TT 6维,N_prop=2 断崖(代数骨架已车道A独立复核)。
- R32:走行的 **TT/真引力子曲率分量已在 ker C 内**(可达一半);**2–3 个约束行曲率 DOF 主角锁在 40–90°**(锁死一半);μ/Wilson/k-ray 便宜档动不了它们。
- R33:单粒子缠绕数在物理点(massless=gapless Dirac 点)**ill-defined**,便宜单粒子拓扑判定够不着 ⟹ 必须张量层指标;**质量 dm 携拓扑内容**(单粒子 W:dm=0→0 / dm≠0→1 相变)。

## 3. 里程碑 RC1(核心判定):张量指标 + 主角度,(θ,dm) 联合扫

**三个观测量(每个 (θ,dm) 网格点,在 c=cosθ 上重装 placed κ + Wilson + ker C + 张量走行):**

| 观测量 | 是什么 | 判什么 |
|---|---|---|
| 主角度表 θ_princ(k)| 走行传播子空间 vs ker C 的主角(R32 已在 μ/Wilson 测,现在在重装复形后测)| **形变距离**(近可掰)|
| **张量拓扑指标 I(θ,dm)** | 锁死子空间(ker C 外携曲率模)在 BZ 上的谱流/缠绕**整数**——**张量层,非单粒子**(R33 硬要求)| **拓扑距离**(锁不锁死,判 no-go)|
| N_prop(θ,dm)| 无投影计数 | confirm 4-5 还是降 2 |

**内部便宜先行(RC1a→RC1b):**
- **RC1a**:先在少数代表点(轴向/面斜/体对角各一 + **R33 的 dm 相变点 dm≈0→非零**)算 I 与 max 主角,便宜地看有无过零/下降迹象。
- **RC1b**:仅当 RC1a 出迹象,才在 (θ,dm) 平面密扫。不出迹象不密扫(省算力,和便宜档纪律一致)。

**RC1 验收判据(预注册,二选一):**

- **判"可达通道"**(进 RC2)须**同时**:存在 (θ\*,dm\*) 使 (a) max 锁死主角 → 0(< 5°),(b) 张量指标 I = 0,(c) N_prop 实测 → 2。**三条缺一不可**——只有主角降不算(形变距离近 ≠ 可达),必须 N_prop 实测兑现。
- **判"拓扑锁死"**(进 RC3)须:max 锁死主角在整个物理 (θ,dm) 范围有**非零地板**,**且** I 是**干净非零整数不变量**(不是"大概不为零")。只有干净整数不变量才能宣称拓扑锁死——否则是信号不是定理(R32/R33 口径)。
- **其余**(主角降但 N_prop 不降 / I 非整数模糊 / 两轮不出干净通道也不出干净锁死)→ **停手会商**,可能需要更根本的重新表述。

## 4. 里程碑 RC2(条件:RC1 出通道)—— 通道构造 + 终验收

在通道 (θ\*,dm\*) 上构造走行形变,实测:
- N_prop = [2,2,2,2] 断崖(含体对角),第 3 奇异值掉噪声(对齐 R30);
- ker C 外残差 ~1e-15(对齐 R30 的 1e-15,对比 R28 走行的 0.34–0.49);
- **TT/规范不动**(只清那 2–3 个锁死主角,物理引力子与规范扇区逐位不变);
- 去唐纳约束全 T ≤ 1e-13;
- 双正控(沿用 R30):teeth→[6,6,6,6]、合成 TT→[2,2,2,2] 断崖、纯规范→[0,0,0,0]。

RC2 全过 ⟹ 涌现走行落在复形上,N_prop=2 达成 ⟹ **卡点④ 前置满足**,联验有意义。

## 5. 里程碑 RC3(条件:RC1 锁死)—— R29 式放松假设裁定

若 RC1 判拓扑锁死:识别**必须放松哪一项**假设(严格酉 / 严格局域 / 精确约束传播 / 手性物质),各做一个便宜的"放松此项后锁死是否解除"的符号层探测(和 R29 同样打法)。产出:一个具名的、有证据的"放松 X ⟹ 可达"或"全都放松也不行"的裁定。这本身是重大诚实结果(纲领的 N-N 边界)。

## 6. 不做清单(R32/R33 已排除的死路)

1. 不把开局花在 μ(约束阻尼)/ Wilson α —— R32 证明只改阻尼率/UV 正则,动不了传播不变子空间;
2. 不靠单粒子拓扑判定 —— R33 证明物理点 gapless,单粒子缠绕数 ill-defined,必须张量层指标;
3. 不在重装复形前先扫便宜旋钮 —— 已排除;
4. 不在 N_prop 实测=2 之前碰卡点④ —— 联验一个 N_prop=4-5 的构造不会变 2。

## 7. 诚实纪律(写进战役,防 R27 覆辙)

- **两侧留白**:不把锁死夸成拓扑定理(除非 I 是干净整数不变量),不反向宣称形变可行(除非 N_prop 实测=2)。R32/R33 的诚实口径继续。
- **便宜先行**:RC1a 便宜代表点先行,不出迹象不密扫。
- **停手规则**:RC1 连续两轮不出干净通道也不出干净锁死 → 停手,两车道 + PI 会商是否需要更根本的重新表述。
- **每里程碑落一行到权威记录**(总账/README),无痕轮禁止。

## 8. 卡点④ 命运(条件式,本体继续按住)

- RC2 成功(N_prop=2 断崖)→ 卡点④ 前置满足 → 联验(两轴合流+全门+九炮+endurance)有意义,PI 定何时启动;
- RC1 锁死 → RC3 放松假设解决前,卡点④ 无意义,继续按住。

## 10. 开局指令(lane B 可直接起)
