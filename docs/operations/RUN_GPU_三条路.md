## 路线 B — 线性化自旋2(区分张量引力 vs 标量)

```bash
python -m rulespace_gpu.pathB_spin2
```

**沙盒结果(CPU 秒级,GPU 不必需但可跑):**
- B1 graviton 极化数 = 2(所有波矢)→ 自旋2 ✓
- B2 光偏折 张量/标量 → 2.0(弱场,|φ|=4.7e-3 时 1.997)= Eddington 因子 ✓

**我会看:** 这两个是「验收测试」——未来的张量-QCA 规则必须复现它们。B 目前是**直接实现**线性化自旋2物理来锁定目标(2自由度、光偏折因子2),不是从规则涌现的。下一步 B 的真正工作量是**让 h_μν 从张量元胞自动机规则涌现**,那一步需要 GPU 跑 3+1维张量场动力学(每格点10分量)。这条命令确认目标正确、工具就位。

## 路线 C — 10⁵ 规则大规模搜索(存活流形高统计)

```bash
python -m rulespace_gpu.pathC_scale --n 100000 --batch 8192
```

**沙盒预跑(6000规则):** 存活率 ~70%,流形结构:Lap 90%激活/100%正(刚度)、rho 源 79%、restoring/damping 负。与 CPU 的 C1b 一致。

**我会看:** 10⁵ 统计下存活流形边界的精细结构、稀有存活方向、以及存活率随规则族的收敛——CPU 上跑不动的规模。若 GPU 很快,把 `--n` 加到 10⁶,并可调 `--T` 看长期稳定性如何进一步剪枝。
