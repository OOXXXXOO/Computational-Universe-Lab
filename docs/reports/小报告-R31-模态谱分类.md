## 一、结论先行（独立复核确认 R28：多出模是约束行空间被激活，不是规范泄漏）

对真实 walk 符号算子 `M = D1.damped_map(k, R.MU)` 的 **12 个单位模**（= 两个 Floquet
支 × 6），在物理-h 坐标下把 10 维对称张量空间正交剖成三扇区
**规范(4) ⊕ TT(2) ⊕ 约束行(4)**（ker K = 规范⊕TT = 6 维，R15 T9；约束行 = ker K 的
正交补 = R28 病灶），逐模量三件事：约束值 |C·h̄(mode)|、placed Riemann 曲率能量、
三扇区能量分数（和=1）。

**三条硬结论：**

1. **规范扇区严格零曲率（E1 内控，逐模）**：把规范扇区取成**精确** placed 规范张成
   （Riemann 线性 ⇒ 整张成零曲率），实测每个 k 每个模的规范投影 Riemann 能量
   ≤ **3.6e-32**（相对峰值）。**没有任何一个携曲率模是规范模**（规范主导曲率载体 = **0**）。
   → "规范模泄漏进曲率"这条被**直接否证**。

2. **多出曲率能量落在约束行扇区**：传播曲率能量按扇区平均分解 =
   **TT 30.9% / 规范 0.0% / 约束行 69.1%**。约束行扇区（ker K 之外）承载了**大多数**
   传播曲率能量。48 个（12×4k）携曲率模里，**29 个约束行主导、19 个 TT 主导、0 个规范主导**。
   → "约束行空间被激活成传播"这条被**确认**（R28 倾向的后者）。

3. **独立复现 R28 的病灶数字**：本文对 ker K 的正交补重新求得每个 k 的
   mean-residual-outside-kerK = **0.469 / 0.485 / 0.341 / 0.389**，与
   `r28_results.json` 的 `mean_residual_outside_placed_subspace` 逐 k 一致到
   **1.1e-16**（机器精度）。R28 的"34–49% 能量在 placed 规范⊕TT 之外"独立重推成立。

**裁定：独立复核确认 R28。** 当前 U 的多出模不是规范起源、不是判据口径伪影——是 walk
演化把内容压进了**约束行空间**并让它**携真曲率传播**。诚实边界（AGENTS.md）：纯诊断，
**不宣告 M3 / 涌现 / DOF 轴关闭**；与 R28 一致——多出模是真物理（约束行曲率），负结果同价交付。

## 三、多出模的扇区归属（精确分解）：Floquet 双支强不对称

N_prop 由 SVD 在"曲率较大的那一支"上数秩得到。R31 把这条按 Floquet 支拆开，
发现**两支性格截然不同**——病灶集中在 **−ω 支**：

| k | −ω 支（高约束支） | +ω 支（低约束支） |
|---|---|---|
| (2,0,0) | curv 行 **0.92** / TT 0.08，mean\|C\|=**0.95** | curv TT 0.71 / 行 0.29，mean\|C\|=0.13 |
| (0,3,0) | curv 行 **0.81** / TT 0.19，mean\|C\|=**1.24** | curv TT 0.49 / 行 0.51，mean\|C\|=0.36 |
| (2,2,0) | curv 行 **0.66** / TT 0.34，mean\|C\|=**0.92** | curv TT 0.93 / 行 0.07，mean\|C\|=0.14 |
| (2,2,2) | curv 行 **0.75** / TT 0.25，mean\|C\|=**1.42** | curv TT 0.96 / 行 0.04，mean\|C\|=0.13 |

**归属结论：**
- **−ω 支** = 病灶主体：强约束违反（mean|C| ≈ 0.9–1.4）、曲率能量 66–92% 落在**约束行扇区**、
  规范扇区零曲率。这些正是 R28 所指"约束行空间被激活成传播"的模——它们**不是规范模**
  （规范扇区在这些模上曲率机器零），是携真曲率的约束行方向。
- **+ω 支** = 接近干净：低约束违反（|C| ≈ 0.13–0.36）、曲率主要在 **TT**（49–96%）、
  其余能量在规范扇区（f_规范 高但曲率零）。这一支更接近"物理 TT + 纯规范"的理想结构。

即：多出的 2 个曲率 DOF（每支 N_prop=4 = 2 TT + 2 多出）在 **−ω 支**表现为强约束、
约束行主导的曲率模；在 +ω 支较弱。规范扇区在所有 k、所有支上都零曲率——**规范不是主犯**。

## 四、给 R30 的线索（动力学半的 curl 该优先杀哪个扇区）

1. **主犯 = 约束行扇区（ker K 的 4 维正交补），不是规范扇区。** R30 的动力学半 / curl 项
   应**优先压制约束行空间的传播**，不要去加码阻尼规范扇区——规范扇区已被 placed Riemann
   判据严格零化（E1，本文逐模复现到 1e-32），再阻尼规范买不到任何 DOF，泄漏纯粹是
   **约束行方向被激活**。

2. **可瞄准 Floquet −ω 支。** 约束行曲率在两支间强不对称：−ω（强约束违反）支承载
   66–92% 的行扇区曲率，+ω 支只有 4–29%。若 R30 的 curl/共变形能在**约束违反最大**的
   方向（−ω 支、mean|C|≈1）优先耗散约束行分量，就直接打在病灶上。约束值 |C| 与 f_行
   强相关，可作为"哪些模该被 curl 杀"的现成筛子。

3. **验收判据（承 R28）仍是**：让 12 单位模能量落进 ker K（mean-resid-out-kerK → 0
   ⟺ 约束行曲率 → 0 ⟺ N_prop = 2）。R31 补充：需要清掉的具体是 **−ω 支的约束行曲率**，
   TT（真引力子）和规范（已零曲率）都不用动。
