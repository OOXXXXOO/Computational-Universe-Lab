# 44M 流形精析:三个真发现 + 一个诚实的非发现 + 下一把刀

*数据源:`run/_acc.json` 蓄水池(lawful 1500 均匀样本,代表 245 万条 lawful 规则;stable 1500 样本代表 3134 万条)。图:`figs/fig_44M_manifold.png`。分析只读 runner 输出,不动管线。*

---

## 真发现一:lawful 流形 ≈ 纯场方程,纯度已定量

- **66.4%** 的 lawful 规则是**严格二项式** □θ=κρ(只有 Lap+ρ,其余四系数精确为零);
- **96.5%** 在允许阻尼后覆盖(即 lawful ≈ {纯波动+源} ∪ {+小阻尼});
- 恢复项在 lawful 集里被压到 4% 激活。
2.45M 条 lawful 的结论:等效原理筛选的不是"参数调好的六项式",是**方程形式本身**。

## 真发现二:弱耦合选择律,200× 压缩

耦合/刚度比 |a₂|/a₀ 的 p90:stable 集 **41.8** → lawful 集 **0.196**——**约 200 倍压缩**。"引力是最弱的力"在这个玩具里不是输入,是 EP+耐力审在 4400 万条规则上强制执行的选择律。中位 |a₂|/a₀=0.028。

## 真发现三:EP 把刚度推高 3.3×(相对先验)

a₀ 中位:采样先验 0.050 → stable 0.034 → lawful **0.112**。等效原理主动选择更"硬"的几何(真双曲传播),不是先验残影。**best 规则**(univ 7.1×10⁻⁸,r²=0.99999,sat 0.5%,θ̈ rms 1.8×10⁻⁴——真动态非冻结,发现于第 3527 万条):θ_tt = 0.1045·∇²θ + 0.00656·(ρ−ρ̄),纯二项、吸引号——**暴力搜索与第三/六波的自洽性理论收敛到同一方程结构**,这是 44M 的最大单点结论。

## 诚实的非发现:吸引符号占比是先验伪影

lawful 71.8% 吸引 vs stable 72.6% vs **采样先验 P(+) = 0.7**(`random_couplings` 里 `sign(rng.random()−0.3)`)。三者一致 ⟹ **没有任何符号选择信号**。这与理论一致(EP⊥吸引性,第二波已证;符号由作用-反作用固定,第三波),但仪表盘上的"70%正"不能当成发现来讲。

## 下一把刀(真实实验级,便宜,锋利):引力波速判据

lawful 集的 graviton 速度 c_g=√a₀:中位 **0.334**,最大 0.890,而物质光速 c=0.900——**现有漏斗没有任何判据要求 c_g=c**,分布形状是选择+先验的混合,上限就是先验上限。而真实世界有 GW170817:引力波速=光速到 10⁻¹⁵。加一条 **J5:|c_g/c−1|<δ** 判据,会消灭当前 lawful 流形的 ~99%,只留 a₀→c² 的尖端。这是纲领核心论题("真实实验剪规则空间")的又一次直接执行,实现成本一行比较。建议在 runner 上作为可选列先统计不淘汰(报 c_g 分布随 δ 的存活率),攒够统计后再决定是否入漏斗。

## 底线

44M 的净进展:lawful 流形从"定性像场方程"升级为**定量的三条选择律**(纯度 66%、弱耦合 200×、刚度 3.3×),暴力与理论在 best 规则上会师;同时排掉一个伪发现(符号占比),并暴露出漏斗缺失的下一条真实验判据(GW 速度)。长跑继续攒统计即可,分析脚本可随时重跑。
