## 五、分支落点 = ambiguous：哪个方向、缺什么数据（预注册模糊分支要求）

- **模糊方向：面斜、体对角。** 主判据拟合给出小而显著的截距 A=0.049±0.012 / 0.031±0.008：
  高于 2σ 与 0 不一致（不满足 C-PASS），低于 O(1) 门 0.05（不触发 C-FAIL）。
- **该截距很可能是拟合窗/函数形式伪影而非物理底**——直接证据：被剔除的更小 |k| 原始读数
  **低于拟合截距**（面斜 0.0219@|k|=0.185、0.0274@0.278 < A=0.049；体对角 0.0213@0.227、
  0.0312@0.340 ≈/< A=0.031），一个真常数底不允许读数落到它下面。但按预注册纪律，
  拟合细节（窗、剔除规则、模型）不得事后调整，故此处只作诊断陈述，不改判。
- **轴向 PASS 是弱证据**：字面判据成立（幂律决定性胜、α=0.37>0、|A|≤2σ_A），但小 α 使
  常数项与幂项近共线，协方差退化（σ_A=2.13），"A 与 0 一致"近乎空转；全局落点不依赖它。
- **缺什么数据**：面斜/体对角方向 |k|<0.37/0.45 处的**拟合合格点**（n≥2 来源）。预注册
  格子系列 16³/24³/32³/48³ 内已无此类点；补上需要 ≥64³（如 64³/96³ 的 n=2,3 点），
  这超出本预注册的格子系列，**须另行预注册并经 PI 批准**，本审计不越权加跑。

## 六、给封存文档的标度证据节素材（边界陈述强度）

在 16³–48³ 预注册系列内可以如实写入封存文档的标度事实：

1. **δ=12–18% 不是格子无关的常数**：它是 16³ 判据点（|k|=0.79–1.36）的读数；同一冻结
   函数在 48³ 最小可分辨 |k| 处已降至 2.1–4.4%（三方向、单调、含泄漏能量同步下降）。
2. **无 O(1) 常数底的证据**：三方向双模型比较幂律全部决定性胜（ΔAIC 2.7/17.5/25.5），
   预注册点名最可疑的轴向亦然——C-FAIL（"残差是 O(1) 常数代价，结构性不可达信号升格"）
   **未触发**。
3. **"严格趋零（A=0）"未确证**：面斜/体对角主判据拟合留下 ≤5% 量级的小截距（虽被更小
   |k| 的剔除点原始读数反压、且次级 resid_mean 口径下与 0 一致），在本格子系列内不可判；
   判定需 ≥64³ 扩展（另行预注册）。
4. 建议边界陈述措辞（素材，PI/车道A 定稿）："R3 的约束残差主体为有限尺寸量
   （48³ 处 2–4%，幂律随 |k| 下降，无 O(1) 常数证据）；是否严格趋零 vs 存在 ≤5% 小残余底，
   在 16³–48³ 内不可判。**不可达的死因是计数+稳定性死锁（R36 (b)），不是残差本身**——
   后半句在两种子形态下均成立。"

  本审计只供边界陈述强度。C-FAIL 若日后触发亦是信号升格，不是定理。
