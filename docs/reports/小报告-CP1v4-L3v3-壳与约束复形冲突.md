# CP1-v4 L3-v3：walk 壳与 placed 约束复形必须共同变形

*2026-07-23。L3-v2 交接的 `a_tr=2-Re tr U_walk` 候选实装与全 BZ 追因。结论：候选不能单件置换；冲突已从“宽盒 vs 光锥”进一步收紧为“演化壳 vs 约束复形”。数值证书见 `cp1_v4_L3v3_diagnostic_results.json`。*

## 结论

L3-v3 **FAIL，且不进入盲目长跑**。局域 Wilson 混合可以同时保住静态双极点、压掉 walk 的 UV 折返，并使正式低动量集合的 J5 最大偏差降到 `4.65e-4`；但旧 `K_placed` 仍定义在 ideal 半角壳上，体对角 `(2,2,2)` 的物理计数从 2 退回 5。波壳修好而约束复形没跟着变形，二者不能分开装配。

## 一、纯 walk-trace 核为什么不能直接用

候选

```text
a_tr(k) = 2 - Re tr U_walk(k) = 4 sin²(ω_walk(k)/2)
```

在正式六个低动量上把几何频率与物质 walk 对到 `5e-15` 内，静态响应仍是精确 `1/a_tr`。但全 BZ 检查发现物质 walk 的 Trotter 乘积在高动量存在近零频折返。例如 `N=32, n=(23,0,23)`：

```text
a_tr = 1.468e-3
Z4c 增广谱半径 = 1.028913
```

因此纯 `1/a_tr` 会把该折返升级成 UV 静态双极点。随盒子加密，稳定所需 `μ` 快速趋零；这不是可扩展的局域引力核。

## 二、Wilson 混合修好了什么

实装半径 4 的局域混合：

```text
q(k)    = [Σ sin²(k_i/2)] / 3
a_v3(k) = [1-q³] a_tr(k) + q³ a_kappa(k)
```

低动量平坦地跟随 walk，高动量回到无折返的 `a_kappa`。证书：

- 实空间 stencil 与符号误差 `5.6e-16`；
- 静态双极点误差 `5.77e-15`；
- 静井仍逐位属于 `ker K_placed`；
- 正式 J5 最大预测偏差 `4.65e-4`，动力学 FFT bin 六点均读到 `1.000000`；
- `N=16/24/32` 已检查参数点的谱半径为 `1+O(1e-15)`。

源链正资产也保持：16³ 精确源约束落到 `3.11e-15`，on-site 为 `2.68e-5`，相差 `8.6e9`；活体 `K.S=4.21e-16`，守恒最差 `6.6e-15`。

## 三、为什么仍然 FAIL

体对角实测：

```text
n_prop = 5
sv3    = 0.183
tt_match = 0.98634
每支亮模 = 6（门要求 2）
```

原因不是阻尼或源，而是 `K_placed` 的 gauge kernel 只在

```text
4 sin²(ω/2) = a_kappa(k)
```

上与线性化 Riemann 的纯规范方向重合。把演化壳改成 `a_v3` 后，即使频率差只有 `4.65e-4`，体对角的四个规范暗模也获得有限曲率，DOF 立刻回到 5/6。

连续插值扫描进一步排除了调权解：体对角想让 J5 `<1%`，需要约 `≥94%` 继承 walk 壳；想让额外曲率奇异值 `<0.05`，只能约 `≤36%` 继承 walk 壳。区间不相交。

## 四、无效运行排除

第一次完整运行中，24³/32³ 使用了抽样谱标定，漏掉窄 UV 不稳点并导致静态段溢出。该段已主动中止，**不计为物理门失败，也不写 L3 门 verdict**。诊断 JSON 单列 `invalid_run_excluded`，避免以后误引。

## 五、需要评审选择的架构分叉

继续前必须选择会改变构造定义的一条：

1. **约束复形随 walk 壳共同变形**：寻找严格局域的 walk-compatible de Donder/gauge complex；这是最正面、也最难的一条。
2. **重做物质 walk**：让物质宏步色散落回已认证的 ideal pair 壳，同时保留幺正、局域、精确键流。简单 `xyz/zyx` 交替已测：平面对角改善到 `<0.3%`，但体对角恶化到 `22.4%`，不足。
3. **收窄主张或改门**：只在轴向/低维子集主张共锥，或放松体对角 DOF/J5；这违反当前预注册，不能由实现侧自行决定。

L4 sponge 只能治疗尾漂，不能改变上述壳—复形失配，因此在分叉裁定前不应提前进入 L4。
