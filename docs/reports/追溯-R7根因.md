**① 动力学判决:** 把 R7 的物种放在冻结的 θ-up 突起(capstone 源挖的"井"就是 θ-up)旁 8 格,测净漂移:

**② 本征相位判决**(分支跟踪,无歧义):

undressed 规则的 θ-力被 **±3 的加性项**主导——质量无关、分支翻符号、幅度是真实引力耦合的数倍。对引力而言完全错误的结构。

## 根因链(三层)

**第一层(直接):源-响应符号错配。** capstone 源 tanθ·T⁰⁰ 把 θ 抬高当"井"——这对推导它的 **1D 共形族**是对的(Shapiro 的无质量探针也确实被吸引,折射机制主导)。但 R7 响应端用 `engine.walk_step`,其重物种在 θ-up 区能量**升高**→被推出。源说这是井,物质说这是山。

**第二层(规则谱系):3D engine 与 1D core 是不同的规则。** 1D split-step 两币 (+θ, −θ+dm) 在 k=0 **相消**,静能=dm 与 θ 无关(第三波"静质量不引力"的那个发现);3D engine 每根轴后放 coin(+θ),三币**不相消**→静止相位混入平凡加性 3θ 势。写 3D 引擎时没意识到这个结构差异。

**第三层(最讽刺):违反了我们自己的作用-反作用原理。** 第五波已证明自洽性要求源耦合=响应耦合(λ=1 被固定)。R7 把 1D 共形族的源公式套在响应结构完全不同的 3D 规则上——正是自洽闭环要防止的错配。教训:**capstone 公式不是万能源,它和规则变体是配对的;换规则必须重新验证 F=−δE_w/δθ 的符号。**

**外加一个泄漏到 R8 的同类错误:** `states.packet` 的旋量制备用 undressed 模算符——给共形规则喂错误规则的分支旋量,制备态成分支混合(这就是 r8 第一次 autopsy 失败的原因;已修:`conformal_packet` 用共形模算符自己的正能分支)。

## 修复:共形 3D 行走者(`r8_conformal_selfbind.py`)

轴币交替 ±θ(k=0 处加性项相消)+ 共形质量币 dm·cosθ/cosθ_ref(静能随局域光速红移):
- 本征相位:两物种正能分支都是井,幅度精确=理论值 −dm·sinθ/cosθ_ref ✓
- 动力学:dm=2 吸引恢复(+0.88)✓
- 轻物种(dm=0.45)符号已对但耦合弱(∝dm),小尺度漂移测试被反射瞬态压过——不是未修,是该物种引力本来就弱(这本身与共形族 EP 结构一致)。

## 对已有结论的修订

- **总账 #35"相对论物质不自束缚"→ 降级为未定。** R7 从未给过相对论物质一次符号正确的机会;真正的 rematch 是共形规则+正确旋量下重跑自束缚(命令在下)。
- **#36"标量度规聚不出视界"→ 保留但弱化**:它是在错误符号下观察到的,需在 rematch 后重估。
- 原报告三条原因(相对论弥散、Catch-22、clip)→ 降为次要因素,rematch 中仍需面对(即使符号对,弥散仍可能赢——那才是干净的物理结论)。
- **路 A(S-N 孤子)不受影响**:Schrödinger 的势直接进哈密顿,源-响应天然匹配;这也解释了为什么路 A 一次就成——它不可能犯这类错。

## 教训(写进工程清单的那种)

1. **换规则变体必须重新验证源-响应符号**(一个 20 行的 drift test / 本征相位检查,今后新耦合实验的准入测试)。
2. **旋量制备与演化规则必须同源**(`states.packet` 只对 undressed 有效;任何新 walk 变体要配自己的 mode operator)。
3. 负结果报告也要追根因——R7 当时给了三条"体面的物理原因",全是真的,但都不是主因。**体面的解释是追因的敌人。**
