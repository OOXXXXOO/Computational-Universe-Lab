# R22:Z4c 型约束阻尼对比——共动载波 + κ₁ 衰减在 oracle 上显著优于 Chebyshev

*方法评估轮(P4/R22),2026-07-23。`r22_z4c_damping.py` → `r22_results.json`,图 `figs/r22_z4c_damping.png`。台架:R16 in-vitro oracle(单 k、在壳、符号空间),雅可比与 σ² 谱沿用 R18 的实空间口径,fp64,种子 22,分钟级。*

## 结论先行

**Z4c 型方案有资格进 M1 装配,附三个硬条件。**在全布里渊区最坏模收缩(主指标)上,Z4c 达 **0.141/3步(0.520/步)**,显著优于三级 Chebyshev 的 0.247/3步(0.628/步)与单 γ 的 0.513/3步(0.801/步);TT 保真三方案同为机器零;瞬态放大 1.20 倍(Chebyshev 循环内 4.87 倍);刚度低估余量 1.16–1.20×(γ/Chebyshev 均为 1.11×)。收缩率在 μ_z 平台内**对 μ_z 完全平坦**(恒 = √(1−κ₁)),这是三方案中唯一的"参数不敏感"性质。

代价与条件(装配前必须满足,见 §七):
1. **Z 载波必须与物质 walk 共锥/共相**——消融显示静止 Z 载波在同参数下直接不稳定(ρ=1.48),重新优化后最好也只有 0.798/步,连单 γ 都打不过;
2. **N_prop 类判据显式扣除 Z 扇区**(方法见 §五,已给谱证书);
3. **装配层重测 σ² 谱后按平台公式重定 (μ_z, κ₁)**,禁止照抄本文数字(R16 更正栏的教训)。

诚实定位:在单 k 台架上,Z4c 的全部增益来自"记忆/动量"机制(等价于重球加速,把条件数 κ 变成 √κ);"把约束破坏运走"的传播效应单 k 看不到,只有全装配能检验(§八)。

## 二、Z4c 方案的移植与谱分析(任务 2)

**离散化。**引入辅助场 Z^ν(与 C_ν = J h̄ 同形状,4 分量),每宏步(无滞后,同步闭合,次序同 R18 处方"walk → 测 C → 阻尼"):

```
χ_w = e^{-iω} χ                    (walk)
C   = J χ_w                        (测约束)
Z'  = e^{-iω}(1−κ₁) Z + C          (共动载波 + κ₁ 衰减 + 源)
χ'  = χ_w − μ_z J† Z'              (梯度回授)
```

κ₁=1 时精确退化为单 γ 方案(γ=μ_z)——γ 方案是 Z4c 的无记忆极限。

**为什么可解析定窗(不试凑)。**取 Z 载波与物质同色散 e^{-iω(k)} 后,在 J 的每个奇异方向 (v_j,u_j) 上,步算子精确分块为 e^{-iω}·M(σ),M 为**实** 2×2:M = [[1−μσ², −μ(1−κ₁)σ], [σ, 1−κ₁]]。关键恒等式:**det M = 1−κ₁,与 σ 无关**。于是当所有 σ² 满足 (1−b)² < μσ² < (1+b)²(b=√(1−κ₁),复特征值区)时,**每个模每步收缩恰为 b,全 BZ 一致、与刚度无关**。可行性要求 b ≥ (√κ−1)/(√κ+1);稳定窗(Jury 判据):0<κ₁<1 且 μσ²_max < 2(2−κ₁)。这正是重球/动量法的 √κ 加速,Z 场 = 约束破坏的指数加权记忆。

**数值 minimax 与闭式一致**:数值 (μ=0.0825, κ₁=0.7483, ρ=0.5017) vs 闭式 b*=0.5006, κ₁*=0.7494, μ*=0.0828。最优点是 μ 窗的收缩点(零宽),故**工作点退一步换窗**:

> **工作点:κ₁ = 0.7296,μ_z = 0.0807 → ρ = 0.5200/步 = 0.1406/3步**
> μ 平台 [0.0765, 0.0849](半宽 ±5.2%,平台内 ρ 恒 0.52);稳定上界 μ < 0.0934;离散 BZ 实测最坏 ρ = 0.5200(与区间分析一致)。

**消融(静止 Z 载波,φ=0)**:工作点参数下 ρ=1.4843(不稳定!);重新优化后最好 0.7982/步(μ=0.0610, κ₁=0.9103),不如单 γ。**相位匹配是增益的必要条件**,不是锦上添花。

**规范模口径(同 R18 第四件事)**:三方案都用同一 J,ker J 相同,故规范模行为**逐方案完全相同**——规范模不在 ker J(|J·gauge|=0.97),其行空间分量被压掉,范数落到 ker J 分量平台(三个 k 实测 0.889/0.921/0.936,与预言 ‖P_ker·gauge‖/‖gauge‖ 逐位吻合)。阻尼不动点仍是"TT ⊕ ker J 其余方向",不是 TT⊕gauge;判据不可把规范衰减读成自由度丢失。**Z4c 在这一口径上不引入任何新东西。**

## 四、鲁棒性细节

刚度低估(装配的真实风险:真格点比 in-vitro 更硬)下的行为(图右panel):单 γ 从 f=1 起收缩率单调劣化、f>1.111 不稳定;Chebyshev 劣化**更快**(第一级 γ=0.2159 先撞界),f>1.111 不稳定;Z4c 在 f≤1.05 收缩率**纹丝不动**(平台),1.05<f<1.16 平滑劣化,f>1.157 不稳定;把 μ 放到平台低端(0.078)可白拿 f_max=1.197 而收缩率不变。**没有一个方案有大余量——装配层必须实测 σ² 谱,这条对三方案一视同仁。**

## 五、Z 扇区自由度记账(硬要求,单列)

Z^ν 是辅助场,**任何模式计数(N_prop 类判据)必须显式扣除 Z 扇区**。扣除方法与本轮谱证书:

1. **观测量层面**:Riemann 能量、T⁰⁰、涌现判据的一切观测量只读 χ(h̄ 扇区);Z 不进任何观测量。Z 的物理身份是"约束破坏的记忆",不是度规分量。
2. **谱证书(k=[0.7,0.2,−0.4],工作点参数)**:增广 14 维步算子的特征谱精确分解为
   - **单位模模式 6 个** = χ 扇区的 ker J(TT 2 + 其余 4),与 γ 方案的 6 个完全相同;其特征向量的 Z 分量 max = 5.4e-15(机器零)——**单位模圆上没有任何 Z 含量**;
   - **Z 混合扇区 8 个**特征值,模长全部 = √(1−κ₁) = 0.5200 < 1,严格收缩,瞬态存在、渐近为零,不可能被数成传播自由度。
3. **装配层操作规程**:(a) 判据谱分析在 h̄ 扇区做(演化后把 Z 投影掉再喂判据),或 (b) 等价地验证 Z→0 的定态条件(C=0 时 Z 的唯一不动点是 0)后按现行判据计数;(c) 硬门:数值断言 Z 混合扇区谱半径 = √(1−κ₁)(本轮已给参考值)。
4. **诚实入册(三方案共有,非 Z4c 特有)**:实空间 ker J ≠ TT⊕gauge,其非 TT 的 4 个方向携带 Riemann 能量(实测 max=0.668,非零)。在壳初条纪律(R16 更正栏第 2 条)下这些方向不被激发;全装配中非线性可能喂进去——这是**现行 γ/Chebyshev 方案同样存在的既有口径**,记账在此,不作为 Z4c 的扣分项,但 CP1 装配时的 N_prop 判读要预期它。

## 六、开销

nnz(J)=16(每行 4 个一阶差分模板)。每格点每宏步复乘:γ/Chebyshev ≈74(J 与 J† 各一遍 + axpy);Z4c ≈114(同样两遍模板 + 4 分量标量 walk 载波 + 衰减/源 axpy),**≈1.54×**;存储 +4 个 Z 复场(载波若用 2-分量 walker 再 +8)。换算成"到给定约束水平的步数":到 1e-6 需 单γ 62 步 / Chebyshev 30 步 / Z4c 21 步;乘上 ×1.54 开销后 Z4c 墙钟 ≈32 单位 vs Chebyshev 30——**墙钟成本相当(Z4c 略高 ~8%)**。Z4c 的净优势不在墙钟,而在:每步一致收缩(物理步数少 30%,与 walk 交错时约束暴露时间短)、无循环相位约束(Chebyshev 必须整循环用,中途打断即失效——R18 已警告)、参数平台与瞬态放大。

## 七、装配建议(任务 4)

**建议:Z4c 进 M1 装配候选,按下列条件与顺序:**

1. **先决条件(不满足则退回 Chebyshev)**:Z 载波用与物质相同的 walk 核(同 θ、同锥)实现,并在装配层复测"共动性"——消融已证明相位失配会直接摧毁方案(§二)。载波用 walker 实现时注意正频支投影(负频支 = 反向相位 = 消融的失败方向)。
2. **定参规程**:装配层实测全 BZ σ² 谱 → κ = σ²_max/σ²_min → b 取 (√κ−1)/(√κ+1) 上浮 3–5% → κ₁ = 1−b²,μ_z 取平台 [(1−b)²/σ²_min, (1+b)²/σ²_max] 中点(要刚度余量就取低端)。全部闭式,无试凑。
3. **判据规程**:§五的 Z 扇区扣除三件套(观测量只读 χ、谱断言、Z→0 定态检查)写进硬门。
4. **回退路径**:κ₁=1 一行退化回单 γ,装配调试期可随时切换;若装配层出现 in-vitro 看不到的注入地板(R18 第二件事型),先按 R18 的 measure==enforce 诊断,别怪 Z4c。

**明确回答任务问题**:是,Z4c 在主指标上显著优于 Chebyshev(0.141 < 0.247,-43%),且稳定窗更宽(f_max 1.16–1.20 vs 1.11)、瞬态放大小 4 倍、参数平台独有;代价是 ×1.54 计算与 +4~12 复场存储。**有资格进 M1 装配**,条件如上。

## 八、诚实边界

1. **单 k 台架看不到"运走"**:数值相对论里 Z4c 的卖点之一是约束破坏以特征速度传播出计算域;周期格 + 单 k 下该效应不存在,本轮测到的增益全部来自动量/记忆机制。全装配若有边界/sponge,传播效应是额外红利,但**本报告不为它背书**。
2. **重球等价性**:本方案在数学上 = 对约束泛函的 heavy-ball 动量迭代(Z = 动量变量的场论化身)。若只要收缩率,9 级 Chebyshev 循环理论上可到 0.54/步,但循环更长、瞬态更凶(>4.87)、参数敏感性更差,且必须整循环用;Z4c 以每步一致收缩 + 参数平台胜出,而不是以渐近率的量级差距胜出(渐近率两者同为 √κ 类)。
3. **σ² 余量普遍偏小**(1.11–1.20×):这是台架对三方案共同的警告,不是选型依据。
4. 本轮全部在壳、线性、符号空间;非线性回授(θ 动力学闭环)下的 Z4c 行为未测,属 M1 装配层问题。
