## 0. 结论先行

**裁定:实测不可达(当前假设集)。** 在整个物理 (θ,dm) 平面全扫——θ∈[0.20, 1.37](15 点,含 π/3)× dm∈[0, 1.0](12 点,dm=0 gapless 物理点加密)× 8 个 k 方向(轴向/面斜/体对角),共 **180 个 (θ,dm) 点、1440 次观测**——**无投影 N_prop 从未到 2**:全平面 N_prop 只取 {4, 5},全局最小 = 4;最大锁死主角地板全平面 ≥ **49.7°**,处处不逼近 0。

这**不是默认锁死**,是实测结论(回应"B 默认锁死"之虑):真扫过了物理范围,不是几个点。R30 断崖([2,2,2,2],第 3 奇异值掉 0.05 噪声)在这套涌现走行 + c=cosθ 一致重装复形上,平面任一点都够不着。

**两侧诚实留白**:
- **不宣称可达**——N_prop 实测从未 = 2(唯一的可达兑现口径);
- **不宣称拓扑锁死定理**——§11 已认账,拓扑指标在 gapless 物理点 ill-posed,本战役不算它;这里给的是**实测不可达**,不是"证明的 no-go"。

**交接:支持转 RC3**(放松假设裁定;§11 的手性加倍 N-N 假说为第一探针)。卡点④ 继续按住。

**忠实性证书**:RC1a 的 c=cosθ 重装在 (θ=π/3, dm=0, c=0.5) 逐位还原冻结栈,max diff = **0.0** → PASS。结论非重装伪影。

## 1. 战役定位(§11)

RC1a 判 NEEDS-会商:既不出通道,也不出干净锁死;车道A 认账判据缺陷——"张量拓扑指标 I"在 gapless(引力子必须无质量 ⟹ 物理点 gapless)点 ill-posed,锁死丛非光滑、无量子化整数(RC1a 实测 det-winding 在 BZ-loop 加密下 0.13→7.5 跳变 = 精炼噪声,非物理缠绕)。

§11 修正:**拓扑指标移出关键路径**(降为可选 gapped 旁证);RC1b 主判据回到**终判据的直接形式**——N_prop + 主角在**整个** (θ,dm) 平面全扫(不只 RC1a/R32 的 θ=π/3 线),看有无**任何** (θ,dm) 使 N_prop→2。全扫无 2 ⟹ 实测不可达(非默认)。

本报告即执行该直接形式。**不算张量指标**(§11 已移出)。机器 100% 复用 RC1a 的 c=cosθ 一致重装(`observables_at`:N_prop 无投影计数 + 主角 S_walk vs 重装 ker C),RC1b 只加密度、不加新物理。

## 2. 方法(便宜,只加密度)

- **重装**:c=cosθ 上重装 placed κ + Wilson + ker C(= 规范4 ⊕ TT2,6 维,R30 骨架)+ 张量走行;质量 dm 按 R33 口径入第二 coin(dm=0 gapless Dirac 点 → dm≠0 gapped)。dm 只经**走行**(S_walk)进入,不改目标复形。
- **每 (θ,dm) 点、每 k**:
  - **N_prop** = 无投影传播-曲率计数(主 Floquet 支上 placed Riemann 像的 SVD-rank,归一化奇异值 > SV_THRESH=0.05 的个数);
  - **max 锁死主角** = S_walk(传播曲率子空间)vs 重装 ker C 的最大主角(→0 = 落进 ker C,→90° = 锁在 row 扇区)。
- **网格**:θ = linspace(0.2, π/2−0.2, 13) 并入 {0.5, π/3};dm = {0, .02, .05, .1, .15, .2, .3, .4, .5, .6, .8, 1.0}(dm=0 附近加密,对齐 R33 相变点);k = {(1,0,0),(2,0,0),(0,3,0),(2,2,0),(3,3,0),(1,1,1),(2,2,2),(3,3,3)}(8 向,均在 c=cosθ 带内,max c·s<1)。
- **聚合**:每 (θ,dm) 记 min/max N_prop over k、是否全 k=2(R30 断崖)、max 主角地板(over k 最小的 max 主角)。
- fp64,RULESPACE_BACKEND=numpy。总耗时 **5.3s**。

## 3. 结果:(θ,dm) 平面 N_prop + 主角

**全平面观测量(180 点 × 8 k):**

| 量 | 全平面取值 | 全局最优(最接近目标) |
|---|---|---|
| N_prop(min over k) | 恒 ∈ {4, 5}(140 点=4,40 点=5) | **min = 4**(从未 3,从未 2) |
| max 锁死主角地板(deg) | 49.7 – 90 | **min = 49.7°**(从未逼近 0;仅 13/180 点 < 60°) |
| 全 k N_prop=2 断崖点 | **0 个** | — |
| 任一 k N_prop≤2 点 | **0 个** | — |

**最接近 N_prop=2 / 最接近主角 0 的点(同一点):**

- (θ*, dm*) = **(0.4927, 1.0)**,c=cosθ*=0.881;
- N_prop by k = [5,5,5,5,**4**,5,**4**,5](min=4);
- max 主角地板 = **49.7°**,min 主角地板 = 0.0°(即 S_walk 有分量落进 ker C,但最大锁死角仍 ≈50° 顶死)。

**无断崖的直接证据(该最接近点、取 max 主角最小的 k):** 归一化曲率奇异值 = **[1.0, 0.697, 0.437, 0.262, 0.080, 0.0]**。第 3、4、5 个奇异值(0.437 / 0.262 / 0.080)**全部高于 0.05 噪声地板** ⟹ N_prop=5。这与 R30 的 [2,2,2,2] 断崖(第 3 奇异值掉进噪声)**恰好相反**:奇异值缓降、不掉崖。全平面同貌。

**热图**(`visualizations/figs/rc1b_nprop_full_scan.png`):左=N_prop(min over k),全平面 4–5 一片,无 2 的低谷;右=max 锁死主角地板,全平面 50–90° 高台,无逼近 0 的洼地。π/3 竖线(R32/R30 标定)与其余 θ 无质变——RC1a/R32 只测 θ=π/3 线的结论在全平面成立。

## 4. 裁定(对着终判据 N_prop=2)

按任务书 §11 直接形式判据:

- **可达通道?否。** 全平面无一点 N_prop→2(既无全 k=2 的 R30 断崖,也无任一 k 到 2)。不满足可达兑现(只有 N_prop 实测=2 才算,主角降不算——本例主角地板连 49.7° 都下不去,更遑论 0)。
- **实测不可达(当前假设集)?是。** N_prop 恒 4-5、全局 min=4;max 主角地板全平面 ≥49.7°,处处不逼近 0。涌现走行的传播-曲率子空间在整个物理 (θ,dm) 平面**保留其多余的约束-row 曲率 DOF**。因真扫过物理范围(180 点,dm=0 gapless 点已加密),这是**实测结论、非默认**。

**红线复述**:纯可达性实测判定。不宣告 M3 / 涌现 / 可达性关闭;R30 存在性与边界不变(存在≠涌现≠M3)。不宣称拓扑锁死定理(§11:指标 gapless ill-posed,未算)。
