## 一、结论先行:**便宜档旋钮下"锁死",可达性 CAUTION / NO-GO-LEAN 信号——但不是拓扑定理**

逐波矢主角度直接量出:当前涌现走行 U 的**传播不变曲率子空间** S_walk 与 R30 复形的
**ker C**(= placed 规范⊕TT，6 维)之间,每个 k 都有 **1–2 个主角度 ≈0°**(走行的 TT/真引力子
分量**已在** ker C 内、可达),同时有 **2–3 个主角度锁在 40–90°**(多出的**约束行**曲率 DOF,与
ker C 正交)。关键在于:**这批锁死角在两个便宜档旋钮下纹丝不动**——沿 μ(约束阻尼耦合,
[1e-5,5e-2])和 Wilson α([0.02,1.4]),N_prop 恒为 4–5、ker C 外残差恒为 0.35–0.53、最大角地板
恒 ~77°;体对角 k-ray 连续扫也从不跌破 5°(地板 77.7°)。

**裁定(按 AGENTS.md 红线,措辞收紧):**

- 这是**形变 vs 拓扑**光谱里偏拓扑一侧的信号,但**不是拓扑定理**——**未算缠绕/指标不变量**。
- 它是**便宜档锁死**:μ(耦合)与 Wilson 正则子**不能**削掉多出的约束行曲率 DOF。
- **诚实范围**:物质扇区旋钮 θ(手性/coin 角,定 c=cos θ)与质量隙 dm **未扫**——它们被绑进
  `walk_symbol`/`K_branch`(c=C 硬编码),一致地扫 θ/dm 会**协同形变整套 placed+Wilson+约束复形**,
  那本身**就是构造战役,不是便宜检验**。所以这**不是**"θ 也锁死"的结论。
- **对战役的决定**:**别把开局几周花在调 μ / Wilson 正则子上**——它们不动约束行曲率;形变若存在,
  **必须作用在物质扇区(θ/dm)并协同挪动复形**,而那能否清掉约束行 DOF 是**真正的开放问题**
  (亦可能像 R29 那样,反过来逼你放松 酉/严格局域/精确约束 中的某一项)。

R30 存在性不变、边界不变(存在≠涌现≠M3)。诚实优先(R27→R28 教训):拿不准的 θ/dm 轴**标注为
未测**,不把"便宜档锁死"夸成"可达性关闭"。

## 二、每 k 主角度表(S_walk 传播曲率 vs S_kerC = ker C,frozen μ/α)

**读表:**
- **好消息(可达的那部分)**:面/体对角有 **2 个 ≈0° 主角**(正好 =2 个 TT DOF),轴向有 1 个——
  走行的**真引力子(TT)曲率分量确实已落在 ker C 内**,这一半是可达的。
- **锁死的那部分**:每 k 有 **2–3 个主角锁在 40–90°**。因约束行扇区**严格正交于 ker C**(按扇区构造),
  S_curv 里 ~50% 的**约束行**曲率能量**必然**逼出 ≥1 个 ~90° 主角。这就是 R31 那 34–49% ker C 外残差

- **主导支 = −ω**,与 R31"病灶集中在 −ω Floquet 支"逐 k 一致。

## 四、与 R31 交叉验证(独立复推)

R32 对 12 单位模独立求得 ker C 外残差 = **0.469 / 0.485 / 0.341 / 0.389**(k=轴/轴/面/体),

(注:R31 是**全曲率能量**加权分解、含 +ω 支;R32 S_curv 是**主导 −ω 支曲率子空间的基向量**扇区能量,
故 TT 占比略高、行占比略低,但定性一致——**主犯是约束行,不是规范**)。规范扇区在两处都零曲率。

## 五、拓扑证据的缺口(为什么只是"信号"不是"定理")

按任务判据,拓扑裁定需"锁死 k + 拓扑不变量(缠绕/指标失配)"。R32 给到了**锁死**(便宜档下 bounded-
away-from-zero,逐 k),但**未给不变量**:未计算 −ω 支的 Floquet 缠绕数、未证 S_walk→ker C 投影沿 BZ 环
的指标失配。因此**红线守住:NO-GO 信号,非 no-go 定理**。要把信号升级为定理,最小补证 =
(a) −ω/+ω 两支沿 BZ 环是否band-crossing(谱流保护约束行模);(b) 约束行投影沿闭环的缠绕数 ≠ ker C 投影。
这属于下一步、非本便宜档。

同样红线另一侧:**未测 θ/dm 物质扇区轴**(§一、§六)。所以也**不能**反向宣称"形变可行"。两侧都诚实留白。

## 六、给 PI 的战役开局建议

1. **别开"调 μ / Wilson 正则子"这条**:R32 已便宜地证明它在便宜档全程不动约束行曲率 DOF
   (N_prop 恒 4–5、残差恒 ~0.4)。省下这几周。

2. **形变的唯一候选杠杆 = 物质扇区(θ 手性/coin 角、dm 质量隙),且必须协同挪动 placed+Wilson+约束复形**
   (因 c=cos θ 定壳)。这正是 R32 无法便宜判、需要真构造的那一步——**它就是战役本体**。
   建议战役**第一个里程碑**设成一个**受限但一致的 θ/dm 符号层检验**:在 c=cos θ 上同时重建 ker C 与走行,
   量同一张主角度表,看 2–3 个锁死角是否随 θ 出现**任一 k 的下降通道**。这仍是线性代数、仍便宜,
   只是需要先把复形随 θ 重装(小工程),故不属于"零构造便宜检验"。

3. **并行补拓扑不变量**(§五 a/b):若 −ω 支有谱流保护,θ 也救不了——那时应转 R29 式裁定,
   决定放松 酉/严格局域/精确约束 中的哪一项,而非继续构造。

4. **验收判据不变**(承 R28/R30):单位模能量落进 ker C(残差→0)⟺ N_prop=2。R32 补充精确定位:
   要清掉的是 **−ω 支约束行曲率**对应的 2–3 个锁死主角;TT(1–2 个 ≈0° 角)与规范(零曲率)不用动。
