## 二、L1 构造(按拍板文档,逐条对应修复清单)

- **walk 核**:10 分量 χ_c(复 2-旋量)全部由 `rulespace_gpu.green_one_walk.geom_walk_all`
  演化,θ_g=θ_m=π/3。**import 同一代码对象即共锥保证**,不另抄一份。
- **存储**:R19 放置语义(H_c[n,j] := h̄(t=n+o⁰/2, x=j+o^sp/2))。交错只进初值放置与
  K 的配对约定,演化算子无任何相位。
- **K_placed**:`r19_staggered_placement.K_placed` 逐字移植——R17 fwd/bwd 字典整数 roll +
  R20 认证时间配对(**h̄₀₀ forward (next−cur)、h̄₀ᵢ backward (cur−prev)**);**hprev 退役**
  (算子只见滚动切片缓冲,无阻尼史)。
- **约束施加**:精确逐步执行(拍板允许的精确投影选项):每宏步解出新切片的 0ν 行使
  K_placed(H(t−2),H(t−1),H(t))≡0 恒成立;**修正量由测量所用的同一个 K_placed 函数算出**
  (B0 probe:同一函数对象,‖K_meas−K_enf‖=0.0)。
- **R21 覆盖**:slave 每步**全量覆写 χ₀ν 的两个旋量分量、实部与虚部(4/4 实维)**,0ν 扇区
  不留任何 walk 携带的自由度(杀掉 R21 的 16 个幺正残留)。
- **R20 vs R21 解读(按任务书要求写明)**:R20 禁的是"投影面≠测量面"的口径失配 slave;
  R21 要的是 0ν 相位自由度全覆盖。本实现同时满足两者:执行与测量同一 K(无口径失配),
  覆盖 4/4 实维(无相位残留)。二者不矛盾。
- **L1 不含**:阻尼、源、sponge(L2–L4)。

## 三、斜向 k 的处理:为什么选 oracle 而不是回文

回文轴序(xyz·zyx 宏步)使宏步本征相位 ω_pal≈2ω,则 sin(ω_pal/2)=sin(ω)≠c·2sin(k/2)·(…)
——**轴向半角壳被破坏**,而 R19 的 κ_placed 零性、K_placed@TT≡0、全部硬门都建立在该壳上。
换回文=重造 K 的字典,超出 L1"照抄 R19"的范围。故取选项二:oracle 逐点预测。

## 八、给 L2 的交接说明

1. **头号目标**:Z4c 阻尼要杀两样东西——(i) 长期规范 Jordan 模(h₀₀ ramp;生初条必激发),
   (ii) 在壳规范行波。L1 的 run A/run B 对照就是 L2 的现成前后对照实验:阻尼开启后 run A
   的 ramp 必须消失、全态漂移应降到 run B 水平。
2. **σ² 重测**:L1 的精确 slave 在 L2 换成 (I−γK†K) 软阻尼时,K†K 的 BZ 谱必须在**本装配**
   上重测(拍板:禁抄 R22 数字;R20 的 certified 谱 γ*=0.0509 一族仅作参考)。
3. **免费预言**:阻尼压掉规范后 stock 全角计数应从 5–6 收敛到 2(§四声明)。若不收敛,
   查微积分失配以外的新泄漏。
4. **(2,2,2) 条款**:斜向超额是 walk 核属性,L2 阻尼**压不掉**(它们在 ker K 里,阻尼不动点
   之内)。若 L2+ 需要体对角也=2,唯一出路是核升级(回文+重造 K 字典,或 R13 步幅桥语义),
   立项要单独走,不许在 L2 里顺手改核。
5. **接口**:`make_stepper("certified")` 的滚动双切片 hist 即 L2 插入阻尼的位置;监视器
   (K_placed 三切片)与执行共用同一函数,probe 断言保留,别拆。
