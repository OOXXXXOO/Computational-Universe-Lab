## 主张与结果(全部精确自由费米子,四证书 PASS)

把行走者费米子放到温度 1/β(准能带的 Fermi-Dirac 填充),热 CFT/RT 预言块熵走 **BTZ 黑洞测地线长度**:

$$S(\ell)=\frac{c}{3}\ln\!\Big[\frac{\beta v}{\pi}\sinh\frac{\pi\ell}{\beta v}\Big]+c_1'\;,\qquad s_\infty=\frac{dS}{d\ell}\to\frac{\pi c}{3\beta v}$$

小 ℓ 是真空 AdS₃ 测地线(对数),大 ℓ 是贴视界测地线(线性)——线性斜率就是**视界长度定律**。

| 证书 | 结果 |
|---|---|
| B1 T→0 回归真空 | c = 1.0000,r² = 1.000000 |
| B2 三个温度 sinh 拟合 | c = 1.002/1.002/1.001,r²=1.000000;**v_fit = 0.8801 vs 解析锥速 cos(0.5)=0.8776(0.3%)** |
| B3 视界熵密度 | 实测/πc(3βv)⁻¹ = **1.0001** |
| B4 有牙对照(隙0.55≫T)| c_fit = 0.0000,sinh 形式塌掉 |

**最有味道的一条是 B2**:光锥速度 v 纯粹从纠缠熵的温度标度里拟合出来,和色散关系解析值差 0.3%——热纠缠"知道"规则的光锥。

## 途中钉下的格点知识(两条,已写码内注释)

1. **环上 k=0 二重零模污染**:周期环的 ω=0 精确零模被热填充半占据(f=1/2),给熵加 ~(ℓ/L)ln(L/ℓ) 的 ℓ 依赖污染,把真空 c 偏置到 1.047。解法=反周期(NS 扇区)k 网格,标准费米环操作。
2. **NS 核反周期符号**:C(d+L)=−C(d),r11 的 %L 索引会静默丢符号——块组装必须用带符号间隔。

## 诚实定位

这是**标度律**层面的对应:S(ℓ) 的数值与 BTZ 测地线公式逐点吻合、熵密度=视界长度定律到 0.01%。它**不是**微观态计数(那需要模不变性/精确简并谱,仍在不可及区,不变);ln sinh 与 CC 热公式在数学上同源,本实验的增量在于:(a) 我们的**具体规则**的海精确落在这条线上且 v、c 都被独立交叉认证;(b) 有牙(隙规则塌形)。梯子的下一档(可及内):双曲格 RT 玩具(最小割 vs 熵);以及把 c/v/β 三量交叉认证做成 J6 扩展列。
