## 二、机制:几何核在约束层复制(执行令第 1 条)

约束违反扇区搬用 L3→(h,π) 那次双曲升级,落在约束复形层:

```
π_ζ' = (1−κ) π_ζ − S(ζ)          [+ 泄漏源 leak·K_apply(h,π)]
ζ'   = ζ + π_ζ'
sponge:  ζ' −= sp · π_ζ'          # L4 出射吸收,逐字复用 green_one 模式
```

`S(ζ)=c²·(−Δ)ζ` 是纯整数 roll 的自伴刚度 stencil(符号 `c²·4Σsin²(k_i/2)`,最大 3<4
⇒ leapfrog 全 k 稳定),给出**与几何同一的光锥 c**。κ 是**只住在违反块**的 k-无关阻尼质量。
`sp` 来自 `tensor_coin_feedback._sponge_field(L,width,gmax)`——**不新建边界**,与 B4/L4
同一吸收层。

## 三、与卡点② 就地机制的对照(执行令第 3 条,核心)

| | 就地阻尼(卡点② no-go) | 双曲化 + sponge(R26) |
|---|---|---|
| 清除机制 | 热扩散,`d_t ζ = γΔζ`,k=0 sink=0 | 以 `c` 输运到边界 + sponge 吸收 |
| 病灶 k=(0,1,0) 清除时标 | **`1/(γk²)` → ∞**(实测 τ=None,永不清) | **~L/c 有限**(实测 62 步) |
| 长波保留(A2) | **1.0000**(精确守恒,清不掉) | 传出后 ret 9.3e-3 |
| 与 k 的关系 | 时标 ∝ 1/k² 发散 | **k-无关**(τ spread 1.59×,群速≈c) |
| 收缩率 | 就地率 `1−O(k⁴)→1`(k→0 退化) | 欠阻尼率 `√(1−κ)=0.990`,**逐 k 相同**(spread 1.2e-15) |

即:**病灶从"就地清不掉的长波"变成"以光锥速跑出体区、被 sponge 吃掉的出射波"。** 时标脱钩
`1/(γk²)`,与波长无关。

## 四、边界 1 认证:共变形后 `K_state` 上的物理块不变(裁定交互警告)

裁定明确警告:符号层 B3 假设 `K` 干净;当 `K` 按 L3-v3 共变形后须在**共变形后的 `K`** 上
重认证。R26-2 **直接用卡点① 冻结符号 `r25_dynamic_symbol.K_state(k)`**(即 Wilson 混合后的
实际 `K_state=[K₀+(1−a_W)K₁, K₁]`,**不是**理想半角壳的干净 `K`)构增广映射:

- 物理 28×28 块 = 冻结 `damped_map(k, μ)`(逐字未改);
- 泄漏 `leak·K_state`:物理 → π_ζ **单向**耦合 ⇒ 44×44 增广映射**块下三角**;
- ⇒ 物理本征值在增广谱中逐位出现,worst dev **8.56e-14**;12 单位模(含牛顿 ω=0 零模)全 k 保持。

结论:双曲化约束扇区**在真实共变形核上**不动物理面,牛顿零模 / TT / J5 结构性受保护
(块三角是结构事实,非数值巧合)。

## 五、给卡点④ 的接口(执行令第 4 条,联验合流)

脚本导出 `coupled_step(h,pi,zeta,pzeta,kappa,sp,leak)`:物理步走**冻结 R25 step**(不动),
物理约束违反 `K_apply(h,pi)` 作为泄漏源注入双曲违反扇区,后者以 c 输运、sponge 吸收。

2. **当 L3-v3 共变形产出新的 `K_state` 时,须重跑 `cert_R26_2`** 在该新核上复检块三角与

3. sponge 参数(width/gmax)已在 R26-4 定标到反射 <1e-3,可直接搬用。

## 六、诚实边界与负结果纪律

- 本文**只**做违反清除机制的实空间构造。**未**做:DOF/J5 无投影动力学重放、运动精确源、
  动态牛顿固定点、Eddington 重放、endurance 与完整证伪炮、emergence_judge 时序。
- **不代表卡点② 解决**:就地 no-go 仍是入册事实;R26 是绕过就地限制的**施工路径**,登记为
  "就地 no-go 确认 + 双曲化出路实空间认证,待与 L3-v3 共变形在卡点④ 合流",**不是** pre-M3
  开放阻塞的关闭。
- 若后续在共变形核上 R26-2 破物理块、或统一闭环中 sponge 不吸,均照实交付为负结果。
- R26-3 诚实记录:全 BZ 稳定窗上边 = 高 k 的 CFL 界 `κ≤2−s/2`(随刚度符号 s 收紧,预期),
  但**存在**对全 BZ 公共的工作窗 [0,0.5],且窗内收缩率 `√(1−κ)` 逐 k 相同——这才是击败卡点②
  的关键(就地率随 k→0 退化,双曲率不退化)。
