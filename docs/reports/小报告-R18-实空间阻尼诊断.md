## 首先纠正我自己:R16 的 "γ=0.3 安全" 是错的

R16 体外预演的 σ²_max=2.2 是**只在 3 个小 k 采样**上算的。全布里渊区上,实空间约束雅可比的 σ² ∈ [3.01, 27.20],所以

$$\gamma_{\max}=\frac{2}{\sigma^2_{\max}}=\mathbf{0.0735},\qquad \gamma^*=\frac{2}{\sigma^2_{\min}+\sigma^2_{\max}}=0.0662$$

**你们实测 γ=0.05 稳定、γ≥0.15 爆炸——与这条边界逐点吻合。** 我给的 0.3 是稳定上限的 4 倍,你们照着调必炸。这条记在我头上,已写进 R16 笔记的更正栏。

## 第二件事:6e-4 不是速率问题,是"地板"

γ=0.05 时最慢模的衰减率是 0.849/步,400 步后应达 **4.4e-29**。你们测到停在 6e-4 ⟹ **不是阻尼太弱,是有东西在持续重新注入约束破坏**。嫌疑排序:
1. **walk 每步重新注入**(你们自己的候选):阻尼与 walk 步的次序——必须"walk → 测 C → 同步阻尼"闭合在同一步内,若阻尼在 walk 前做,每步注入的量就是地板;
2. **measure ≠ enforce 口径**:测量用一种模板、执行用另一种(R17 负控 ‖C·gauge‖=0.316 的量级恰在这个数量级附近)——**一行诊断**:测 C → 用同一代码路径做精确投影 → 再测 C。不掉到机器零,就把两个 K 在单 k 处 dump 成矩阵直接 diff。你们"精确投影不降 measured 约束(停在~9)"这条,几乎必然就是它;
3. 源项 J̄ 的注入未做 de Donder 相容(若源自带非零散度,约束地板 ∝ 源强)。

## 第三件事:tt_match=0.032 不是阻尼干的(把它从嫌疑名单排除)

$|J\cdot TT| = 1.0\times10^{-16}$:**TT 精确在实空间雅可比的核里**(横向性杀掉空间部分、$\bar h_{0\nu}=0$ 杀掉时间部分)。所以阻尼不可能损伤 TT。你们的 tt_match 崩溃和多余支必须去别处找:fold-h-回-Re(χ) 的污染、TT 投影仪是否用了 κ 方向、或读出时刻(t vs t+½)错配。**这条把你们的两个症状拆成了两个独立 bug,应分开修、分开验。**

## 第四件事(判据口径,重要):实空间阻尼会连规范一起压

$|J\cdot\text{gauge}| = 0.97$:规范模只在**壳上**属于 ker K,离壳的实空间雅可比会压它。物理上无害(规范本来就该被压),但**涌现判据不能把"规范模也衰减"读成自由度丢失**——阻尼不动点是 TT,不是 TT⊕规范。这条口径没提前说清也算我的遗漏。

## 处方(按性价比排序)

1. **γ 改到 0.05–0.066**(0.0662 最优),别再试 0.15+;
2. **三级 Chebyshev γ = [0.2159, 0.0662, 0.0391] 循环**:三步周期最坏因子 0.247,优于单 γ 的 0.513——**注意第一个 γ 超过单步稳定界是 Chebyshev 的正常特征**(三步整体收缩),要么整循环用要么别用;
3. **一行 diff 门**:enforce 与 measure 必须是同一个 K,写成同一函数、断言 `‖K_measure − K_enforce‖ = 0`;
4. **次序焊死**:walk → 测 C(用子步中点作时间项)→ 同步阻尼 → 下一步;
5. **SV 谱检查焊进门**(你们已提,我加两条):第 3 大 SV < 0.05 **且** tt_match > 0.95,两条都进硬门,禁止"阈值伪影"式解释。
