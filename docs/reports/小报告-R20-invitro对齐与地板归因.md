## 结论先行(四条)

1. **地板元凶钉死:CP1-v2 的时间槽。** "宏步差分 + 已阻尼 hprev"这一个实现选择,同时制造了矩阵里
   v2 行的全部病症:
   - **(a) 阻尼不动点错位**:v2 meter 的 6 维核 = TT ⊕ **4 个伪方向**(不是 TT⊕gauge;伪方向的
     certified-C 泄漏 0.27–0.42)。初条落在伪方向的内容**永不衰减** ⟹ 判据侧约束地板 O(0.1)·态幅、
     sv3 = 0.2–0.5、tt_match 掉到 0.93(轴向 k + 失配时 0.13)。lane B 实测的"多余支 0.16–0.50、
     tt_match 崩溃"与此同构。
   - **(b) hprev 滞后毁掉收缩率与稳定窗**:R16/R18 的率预言 (1−γσ²) 对 v2 环**失效**——实测=精确
     谱 0.907/3步(理论 0.513);BZ 角 γ*=0.0662 直接不稳(ρ=1.087);**小轴向 k 在任意 γ∈[0.03,0.15]
     都弱不稳 ρ≈1.001–1.002**——有限 T 下这就是"own-meter 停在小值不动"的观感。6e-4 不是一个阈值,
     是这套近临界模式带 + 伪方向水库在 T~500 时的快照。
   - **(c) 折返只写 Re**:与 v2 meter 组合,own-meter 停在 ~7e-7、rate 0.9994/步(certified meter
     下同一折返模型:机器地板、rate 0.9605)。
2. **修好时间放置后三条硬门全过,且对故意失配免疫(单 k、稳定域内)**:certified(史无关、按 OFFSET
   的时间 stencil)+ matched enforce:C 400 步到 **1.75e-13**、sv3 = 8e-14、tt_match = 1.000000、
   TT 保持 = 1;**enforce 故意换成 naive 单味仍到机器地板(3.6e-14)**——嫌疑 2 在"次序正确"列造不出地板。
3. **嫌疑重排**(相对 R18 的排序):嫌疑1(次序/时间放置)**确证为主犯**——但"次序"的真身不是算子
   先后(字面把阻尼放 walk 前:地板不变,0.105 vs 0.118,线性层面纯粹换括号),而是**时间放置**:
   h̄₀₀ 槽 certified 要 forward、v2 统一用了 backward,ΔK₀₀ = (4/c)sin²(ω/2) = 0.445@k_main(正是
   R17 量级 0.316 一族)+ hprev 滞后。嫌疑2(measure≠enforce)**降为帮凶**:单 k 稳定域内无地板,
   但 BZ 全域 γ=0.05 就有 5.1% 角部模式不稳,且 **slave 型"面失配"完整复刻"精确投影不降 measured C
   (停在 O(10))"症状**(own-meter 停 20.7,对照 lane B 实测 ~9)。嫌疑3(源不相容)**排除为本案元凶**
   (green_one 无源),但"地板 ∝ ‖K·s‖"线性确证(每十倍 10.00),列为将来源轮红线。
4. **γ 窗更正(对 R16/R18 各更正一次)**:certified 算子的 BZ σ² = [0.152, 39.10] ⟹ **γ_max = 0.0511、
   γ* = 0.0509**——v3 报的"经验上限 ~0.05"就是它(不是 spinor 额外刚度,是 certified 时间槽自己的谱)。
   R18 的 0.0662 与 Chebyshev [0.2159, 0.0662, 0.0391] 只适用于 J 谱(v2 时间槽),对 certified 算子
   在 BZ 角**理论上就是 4.0/循环的爆炸**。certified 配套 Chebyshev = **[0.3621, 0.0509, 0.0274]**
   (最坏循环 0.934)。刚度 257 ⟹ 最慢模到 1e-12 需 ~3550 步:**"400 步内到机器地板"只是 per-k 门
   (通用 k 成立;轴向小 k 需 ~900+ 步,速率逐模精确可预言)**,不是全 BZ 门。

## 五条处方逐条执行记录

1. **γ 单值 vs 三级 Chebyshev**:BZ σ²(v2/J 算子) = [3.0124, 27.1999],与 R18 逐位一致 ✓。但动力学
   对拍出**新信息**:v2 环(带 hprev 滞后)实测=精确谱 ≠ 理论——单γ 0.907 vs 0.513、Chebyshev 0.873
   vs 0.247(σ_min k);BZ 角单γ 1.283、Chebyshev 1.846(不稳)。**certified 环实测 == 精确 == 理论
   (逐位)**:单γ 0.774/0.806、Chebyshev 0.641/0.690(k_σmin/k_main)。⟹ R16-D2"实测率 vs 预言表
   是装配 bug 定位器"这句话本身被证实:率对不上=有滞后/时间槽病。
2. **enforce 与 measure 同一函数**:测量与执行从同一闭包 probe 出矩阵,断言 ‖K_meas − K_enf‖ = 0
   (同一对象)通过;失配范数:naive 0.656、spatial-only 0.944(对照 R17 的 0.316 量级)。
3. **次序焊死 + 故意错序对照**:walk→测→阻尼 与 阻尼→walk 字面对照在线性层面地板相同(0.118 vs
   0.105)——**"次序错⟹地板"的正确表述是"时间放置错⟹地板"**:v2 的统一 backward 宏步差分把 h̄₀₀
   槽放错(certified 要 forward),这一列 ΔK=0.445,4 个伪方向随之进入不动点。
4. **源相容性**:相容源(‖K_cert s‖~1e-16)不伤机器地板;不相容源地板 ∝ ‖K s‖,每十倍衰减比 10.00,
   线性确证。
5. **硬门(禁止阈值伪影)**:全对齐格 C→1.75e-13 (<1e-12 ✓)、sv3 = 8.4e-14 (<0.05 ✓)、tt_match =
   1.0000 (>0.95 ✓),三条全过;sv3 以连续量给出,v2 行的 0.2–0.5 是真实伪方向内容,非阈值伪影。

## 给 green_one 的修复清单(按优先级)

1. **时间槽史无关化 + 按 OFFSET 分量化**:D₀ 用 walk 自身实现(v3 的 (W−I) 方向正确),但必须按
   OFFSET 逐分量选 stencil:**h̄₀₀ forward、h̄₀ᵢ backward**;统一单味必错 0.2–0.4。从此**彻底退役
   hprev**(滞后 = 率失效 + 小 k 弱不稳的来源)。
2. **γ 按 certified 谱重标**:γ ≤ 0.0511(推荐 0.0509);Chebyshev 用 [0.3621, 0.0509, 0.0274];
   R18 三元组不得用于 certified 算子。收敛预算:通用 k ~400 步,全 BZ ~3500 步(或把硬门写成 per-k
   预言率门)。
3. **enforce == measure 同函数 + probe 断言**(本文件的 probe 模板可直接搬);slave 型投影禁用,
   除非投影面与测量面被证明同一。
4. **折返不许只写 Re**:v3 的全 χ 一致阻尼方向正确,保留。
5. **判据口径两条**:(i) certified 阻尼(在壳单 k)不动点 = TT⊕gauge,规范保留;实空间全装配算子仍会
   压规范(R18 H3),两种口径都不算 DOF 丢失;(ii) "地板"与"慢衰减"必须用尾段率区分(rt≈1 才是地板),
   否则轴向慢模会被误判。
