## 一、事实核:DHM 定理是什么

- **论文**:Yu Deng(邓煜)、Zaher Hani、Xiao Ma,《Long time derivation of the Boltzmann equation
  from hard sphere dynamics》,arXiv:2408.07818(v3, 2025-07-18, 192 页)。邓煜于 2026-07-23
  在 ICM 2026 获菲尔兹奖,此工作是主要贡献之一。
- **结果**:在 Boltzmann–Grad 标度极限(N→∞、ε→0、Nε²=O(1),稀薄硬球气)下,从牛顿硬球动力学
  严格推导 Boltzmann 方程,**有效期 = Boltzmann 解存在期(任意长)**。此前的 Lanford 定理(1975)
  只在约 1/5 平均自由时内成立(空气标况下 ~10⁻¹¹ s 量级);其后 50 年无人越过这个短时墙。
- **伴随论文** arXiv:2503.01800 把该推导接到流体力学极限(可压 Euler / 不可压 Navier–Stokes),
  在稀薄硬球气情形完成希尔伯特第六问题中"从牛顿定律推导流体方程"的微观→介观→宏观全链。
- **方法核心**(摘要与导言口径):
  1. **长时累积量 ansatz**:不假设分子混沌在每个时刻精确重置,而是携带完整碰撞历史记忆的
     累积量展开(cumulant ansatz);
  2. **partial time expansion(时间分层)**:长时间被切成层,ansatz 逐层传播,层间用归纳闭合;
  3. **核心困难 = 累积量的 L¹ 小性**:化归为碰撞历史图("molecules")的组合性质,
     用新发明的 cutting algorithm 证明。
- 该范式源自 Deng–Hani 此前对波动湍流中波动力学方程(wave kinetic equation)的长时推导。

## 二、结构对应表(对应,不是定理迁移)

| DHM / 动理学理论 | 本纲领 |
|---|---|
| 硬球 N 粒子牛顿动力学(微观,可逆) | 局域酉 QCA walk(微观,可逆) |
| Boltzmann 方程(介观有效理论) | 线性化自旋 2 场论 + de Donder 约束(介观) |
| Euler / Navier–Stokes(宏观) | Newton/Eddington/GR judge(宏观 IR 裁判) |
| Boltzmann–Grad 联合标度极限 | **缺位**(现为固定 16³/24³/32³ 格点) |
| 分子混沌(Stosszahlansatz)的传播 | walk U 对 ker K = 规范⊕TT 的保持 |
| 累积量(高阶关联)受控小 | 约束违反扇区能量/残差受控小 |
| Lanford 短时定理 | 我们的符号层证书 + 数百步短窗真时序 |
| 熵增、不可逆(介观定理内容) | 约束阻尼、R26 双曲清除 + sponge 外排 |

DHM 结果的三个结构性教益:

1. **涌现主张本质上是标度极限陈述**。不存在任何固定 N 的硬球系统"逐位满足"Boltzmann 方程;
   分子混沌在固定尺度上永远只近似成立,定理说的是它在联合极限中以受控方式传播。
2. **长时有效性不是靠微观动力学精确保持介观结构**,而是靠"误差(累积量)统计受控 + 时间分层
   归纳"。Lanford 之后卡了 50 年的不是物理,是固定语言下碰撞历史项的组合爆炸。
3. **可逆微观 → 不可逆介观是定理内容本身**,不是妥协或缺陷。熵增在极限中作为定理涌现。

## 三、以此审视当前设计:五个具体缺口

以下缺口引用均指向现有文档,出处随条标注。

**缺口 1:纲领没有显式尺度分离参数。** 涌现判据(N_prop、约束率、J5)全部是固定格点、
逐单位模/逐 k 的精确谱判据(RC3 系列均为 16³ 符号层);连续极限只在 P1 色散收敛阶 2.014
(exp1)那类轨迹级性质上出现过,动力学 DOF 计数从未被表述为极限陈述
(`纲领-投影规则空间物理.md`、`小报告-RC3ii-三放松候选证据表.md`)。DHM 视角下,
"要求 walk U 在固定格子上精确保持 ker K"同构于"要求固定 N 硬球精确满足分子混沌"——
后者已被证明既不必要、也不是涌现的正确表述。

**缺口 2:R28 验收判据没有说明残差沿什么参数趋零。**"单位模能量在 ker K 内的残差 → 0
⟺ N_prop=2"(`阶段封存-2026-07-24-DOF开放阻塞.md` §三)在固定 16³ 上读出的是 O(1) 数
(泄漏 34–49%),缺少"沿 |k|→0?沿格子 L→∞?沿粗粒化块尺寸?"的标度语言,于是只能读成
FAIL。这正是"时间尺度与精度一体两面":固定尺度上,分辨 2 vs 4 个模需要的频率分辨率
随模间隙缩小而增长,观测窗 T 与格子 L、动量 |k| 本应联动取极限,而当前 T=320/16³ 是
一组固定值(`小报告-R25-emergence真时序.md`)。

**缺口 3:endurance 与收缩率走的是蛮力轨迹路线。** 最慢收缩率 0.99999937,跑到机器底
步数不可接受;三族局域预条件器结构性 no-go(`小报告-R25-预条件化收缩.md`)。DHM 的
partial time expansion 正是对同类问题的答案:**不把轨迹跑到无穷,而是证一个短窗定理
加一个可归纳的层间估计**。恰好,R26 已给出天然层长:约束违反以群速 ≈c 传出、清除时标
~L/c 且 k-无关(62 步 ≈ L/c=88,`小报告-R26-约束双曲化实空间.md`)——这是分层归纳
所需的"单层自净"性质。

**缺口 4:E 层没有累积量/熵记账。** 约束违反扇区目前只有能量(二阶量)监测;"长时有效"
由 T=2000 硬门代理(`主线-实施计划-北极星.md` J1),无原理性判据。DHM 中"介观方程持续
有效 ⟺ 累积量保持 L¹ 小"给出的正是这种原理性判据的模板。J6 熵预研(Peschel 关联矩阵
机器)已备好可复用的仪器(`小报告-J6熵判据预研.md`)。

**缺口 5:R3(阴影守恒)缺一个标度依据,现在被框成"放松/代价"。** RC3-(ii) 把
δ∈[0.12,0.18] 的去唐纳残差定价为"弃精确约束"的代价(`小报告-RC3ii`)。但这个数是
**固定 16³、三个代表 k** 上的读数。若它是有限尺寸/有限 |k| 效应,随 |k|→0 或粗粒化
按可测阶收敛到零,那 R3 就不是"放松纲领承诺",而是"涌现主张本来就该在极限中陈述"的
自然形态;反之若残差在 k→0 存在 O(1) 极限,则统计重述也救不了,结构性不可达信号升格。
**两个方向都是决定性的**,而当前证据表没有回答这个问题。

诚实提示:已有两个不祥信号偏向悲观侧——R29 的 k→0 方向依赖 2.009,以及 RC3-(ii) R1
的实空间幂律尾(轴向 R\*=N/2 整盒支撑)。它们提示 k=0 附近可能是真奇点而非有限尺寸
伪影。正因如此,标度审计才值得做:便宜,且无论结果落哪侧都推进裁定。

## 四、可执行改进建议

### 建议 1(最优先):给 R3 验证预注册补一个"(c) 半——残差标度审计"

- **做什么**:复用 rc3ii 冻结机器(只读,谱层,分钟级),在 16³/24³/32³(可及则 48³)上,
  沿轴向/面斜/体对角三条射线,测 +ω 传播模 resid-outside-kerC(k) 与泄漏能量随 |k| 的
  标度,拟合 `resid(k) ≈ A + B·|k|^α`(逐方向)。
- **分支写死(预注册)**:
  - **A ≈ 0 且 α > 0(逐方向)**:残差是有限尺寸/有限 |k| 量 ⟹ R3 的 δ 获得标度正当性,
    "阴影守恒"从"放松公理"重述为"极限语言下的涌现",R3 分岔的纲领边界价值判断天平改变;
  - **A = O(1)(尤其轴向)**:连统计/极限重述都不可达 ⟹ "四承诺全要时 M3 结构性不可达"
    信号显著升格,支持 (B) 封存,且封存文档获得一个干净的标度论证。
- **接口**:作为 (c) 半并入 `裁定-可达性战役收束-R3验证预注册.md`,与 (a) R26 重认证、
  (b) gauge 处理质询并行;lane B 执行、车道A 复核,口径同 RC3-(ii)。

### 建议 2:用分层归纳替代蛮力 endurance(约束 rate 门的重述)

把"收缩率 0.99999937 跑到机器底"的轨迹语言,改成 DHM 式两件套:
(i) **单层不等式**:层长 τ = Θ(L/c)(R26 已证的 k-无关清除时标),数值验证单层内违反
能量压缩比 + 层末残余 ≤ 预注册阈值;(ii) **层间组合引理**:符号/谱层证书证明层末状态
满足下一层初始假设(违反扇区能量 + 若干高阶量受控),归纳到任意 T。
endurance T=2000 保留为负控炮(防慢逃逸的实证检查),不再承担"长时有效性"的主证明角色。
这直接绕开预条件化 no-go:不需要每步收缩快,只需要每层自净。

### 建议 3:把 M3 涌现门升级为带收敛阶的极限陈述(须 PI 裁定 + 预注册)

N_prop 门从"固定 16³ 上精确 = 2"改述为"N_prop(k; L, T(k)) → 2,收敛阶预注册",
观测窗 T(k) 与 |k| 联动(波标度 T~1/|k| 起步)。这与 P1 已有的"色散收敛阶 2.014"
是同一种语言,只是从轨迹级推广到 DOF 计数级。
**红线防护**:这触碰 AGENTS.md"不得用修改阈值掩盖失败"——因此必须(i)先做建议 1 的
标度审计拿到经验标度;(ii)判据改述整体预注册、写死证伪分支(A=O(1) 即 FAIL);
(iii)由 PI 裁定后方可写入北极星,不得由执行侧自行切换。

### 建议 4:E 层加累积量/熵仪表

对约束违反扇区增加三/四阶累积量与粗粒化熵的时序监测(J6 的 Peschel 机器可复用,
自由扇区精确)。用途:(i)为建议 2 的层间引理提供"高阶量受控"的实测面;(ii)为
"介观有效理论何时失效"给出原理性预警(累积量爆 ⟹ 有效描述失效,先于门 FAIL);
(iii)酉微观 + 熵单调外排(sponge)= 时间箭头的 P3 残差正版仪表,反哺纲领 E 层。

### 建议 5:R3 论证的 S 层升级(供 PI 价值判断参考)

R3 预注册现有的正面框定是"数值相对论(BSSN/Z4/CCZ4)也不精确保约束,全靠 constraint
damping"——这是**工程实践类比**。DHM 允许把它升级为**推导范式类比**:在目前唯一被
完整严格打通的微观→介观→宏观案例(稀薄硬球气)中,介观结构(分子混沌/守恒的精确形式)
本来就只在极限意义下逐阶成立,微观可逆与介观不可逆并存是定理内容。若建议 1 的标度
审计给出 A≈0,则"精确约束"与"阴影守恒+清除"的关系,同构于"固定 N 精确分子混沌"与
"极限中传播的分子混沌"的关系——后者才是那个被证明的、正确的涌现陈述。

## 五、诚实边界与风险

- **定理不迁移**:DHM 是经典硬球 + Boltzmann–Grad 稀薄极限;本纲领是酉格点量子行走,
  无稀释参数,连续对称与守恒结构不同。量子对应(量子 Boltzmann/一般波动力学)在一般
  情形仍是开放问题。以上全部是 **S 层结构先验/方法论模板**,不进入 H 层,不为任何门背书。
- **"移动球门"风险**:建议 3 若脱离预注册与 PI 裁定执行,就是用改判定语言掩盖 FAIL,
  踩 AGENTS.md 红线。执行顺序必须是:标度审计(建议 1)→ PI 裁定 → 判据改述预注册。
- **悲观先验要写在明处**:R29 方向依赖 2.009 与 RC3-(ii) R1 幂律尾提示 k→0 可能是
  真奇点。标度审计的价值恰在于:若悲观侧成立,它把"信号"升格为带标度证据的封存论证,
  不是白做。
- 本文档不改变任何现有标签:R25 仍为 pre-M3 存在性构造;R30 存在≠涌现≠M3;卡点④ 按住;
  三放松候选的定价与 R3 两半判据不变。

## 六、对"主轴无法推进"的直接回答

主轴(固定 3+1D 自旋 2 北极星)不需要换。DHM 用 50 年的历史说明:Lanford 短时墙不是
物理边界,是**判定语言与技术的边界**;越过它靠的不是新物理假设,而是把"固定尺度逐位
成立"换成"标度极限中受控传播"。当前可达性战役的 R3 分岔恰好站在同构的位置上:

> 若约束残差有正确的标度(A≈0, α>0),R3 不是"弃精确约束",而是把 M3 从固定尺度语言
> 升级为极限语言之后的自然形态——纲领四承诺可以在极限陈述中全部保住;
> 若残差有 O(1) 极限,则得到一个带标度证据的干净封存结论。

第一步是建议 1 的标度审计:便宜(复用冻结机器、分钟级)、只读、两侧决定性,且不预判
PI 的价值判断,只是把"代价是常数还是趋零量"这个目前无人回答的事实补上。
