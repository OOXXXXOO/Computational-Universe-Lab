## 四、机制详解：复形路线为什么在涌现走行上无处下嘴

R30 复形路线的核心是两个算子恒等式（车道A 已独立复核 7.1e-15 / 4.7e-15）：
- **运动学半 inc∘D=0**：精确 placed-gauge 模零曲率（curl 杀 gradient）；
- **动力学半 div∘inc=0**：收缩 Bianchi κ^μG_μν=0，约束传播是推论。

**探测二逐点验证这两个恒等式在重装 c=cosθ 复形上都在**：`|inc·Q_gauge|≤1.1e-16`（机器零，
运动学半成立）。**但这正暴露了问题**：R30 curl 杀的是**精确 placed-gauge 曲率**，而涌现走行的 +ω
gauge-主导模——

1. **gauge 扇区曲率本就零**：把 +ω 传播曲率子空间 S_curv 的 gauge 投影单独取出，`|inc·gauge-part|
   ≈2e-16–7e-16`（机器零，逐 k 逐 dm）。gauge 模没有曲率可杀。
2. **多出曲率全在非-gauge 混入**：`|inc·nongauge-part|≥1.06`（物理点，随 k 增到 5.6）。
   即 +ω gauge-主导模带 5–18% 的**非-gauge 尾巴**（行+TT 混入），曲率全由这撮尾巴携带。
3. **R30 curl 施上去完全惰性**：把 gauge 扇区曲率像 `inc·(P_gauge B)` 从曲率像里减掉，
   **N_prop 恒 4，svn 一字不改**（原始 [1.0, 0.429, 0.316, 0.176] → curl 后逐位相同）。

**结论**：复形路线（R30 curl + 恒等式）在涌现走行的 gauge 扇区**无处下嘴**——它设计来杀精确
placed-gauge 曲率，而走行的 gauge 模已是零 gauge-曲率，多出的 DOF 藏在**非-gauge 混入**里，
curl 碰不到。这与 R31/RC3 探测一「gauge⊂ker C 却携曲率上阈」逐条吻合，并给出精确机制：
**携曲率的不是 gauge 分量本身，是 gauge-主导模的非-gauge 尾巴。**

## 五、唯一达 N_prop=2 的操作 = ker C 投影 = 非局域（C4）+ 手搭（C5），同一根

把 +ω 模投影到 ker C（=删掉那 5–18% 非-gauge 混入）**确实**把 N_prop 打到 2（干净断崖：
第 3 奇异值→0，逐 k 逐 dm）。**但这个操作**：

- **C4 非局域**：ker C 投影子 P_kerC(k) 在 k→0 方向依赖 **2.009**（轴向/面斜/体对角/斜向两两差）
  ——非解析 k=0 极限——与 R29 的约束投影 P_S 方向依赖 **2.449**、R35 的 slave 系数 **1.215**
  **同根病理**。故删混入的投影**非局域**，R29 撞墙，禁用（任务书禁「不加非局域投影」）。
- **C5 破涌现**：唯一能**局域**装进精确 ker C 模的幺正算子 = R30 手搭的**局域剪切之积 leapfrog**
  ——这是 R30 已做的**存在性构造**（U 是两局域剪切之积），**不是 QCA 涌现的 Dirac 走行**
  （车道A R30 复核明言「U 是手搭的局域剪切之积，不是涌现走行」）。让涌现走行落进复形≠手搭一个复形。
  走行的 +ω 模逐个带真非-gauge 混入（5–18%），这是**涌现走行符号自身的属性**，删它 =
  换掉走行 U = 退化成 R30 手搭构造 = 破坏涌现（任务书禁「退化成 R30 那样手搭的局域剪切之积」）。

**C4 与 C5 是同一根的两面**：删非-gauge 混入若要**精确** = 非局域投影（C4 死）；若要**局域** =
换成 R30 手搭 leapfrog（C5 死）。二者堵死复形路线的涌现 Yee 化。

补充（呼应冻结结果，非本探测重跑）：RC1b 全 (θ,dm) 平面 N_prop 从未到 2、R32 扫 μ/Wilson α
锁死——**没有便宜局域旋钮**能达 2，与 C1 局域涌现路线惰性一致。

## 六、C2/C3 不是病灶（诚实记录：J5 补测 + TT）

RC3 守住的边界要求「涉及构造改动，J5 必须补测」。本探测**补测 C2 J5 共锥**：

- **C2 J5 共锥保持**（对 Yee 目标）：R30 leapfrog（dt=c，cos(w_leap)=1−½c²L，L=Σ(2sin k_i/2)²）
  的频率与走行/物质壳 w_walk=2 arcsin(c√Σsin²(k_i/2)) **全 θ 逐位相同**（\|w_leap−w_shell\|≤3.3e-16，
  θ∈{0.4, π/3, 1.0, 1.2}）。即 R30 Yee 目标的引力子锥 = 物质锥 c=cosθ，**J5 共锥成立**。
  故 **J5 不是杀 (b) 的原因**——这与「宽盒障碍」（正确 DOF⟺次光速引力子）**对比鲜明**：R30 用
  半角 placed κ（非宽盒 stride-2），既 N_prop=2 又共锥，宽盒的次光速冲突在 R30 目标上不出现。
  **但这一点是 moot**：因 C5 涌现已破——共锥保持的是**手搭 R30 目标**，涌现走行落不进去。
- **C3 TT 不动**：ker C 投影下 2 个 TT 引力子极化残差 **1.6–3.1e-16**（逐位不变）。TT 是「可达的
  那一半」（R32），本探测确认任何 (b)-修补都不碰 TT。

**故五条里 C2、C3 通过，C1 局域涌现路线惰性、C4 非局域、C5 手搭——卡在 C4+C5（严格局域+涌现物质）。**
