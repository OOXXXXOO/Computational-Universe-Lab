## 阶段 0:预注册补丁(PI 签发,半天)

把 **(c) 半 —— 残差标度审计** 并入 R3 验证预注册,分支写死:

- **探测**:复用 rc3ii 冻结机器(只读),格子 16³/24³/32³(48³ 可及则加),
  沿轴向/面斜/体对角三射线,测 +ω 传播模 `resid-outside-kerC(k)` 与泄漏能量,
  逐方向拟合 `resid(k) ≈ A + B·|k|^α`;同报最小可分辨 |k|=2π/L 处的原始读数。
- **分支**:
  - **C-PASS**:各方向 A 与 0 在拟合误差内一致且 α>0 ⟹ δ 为有限尺寸量,
    R3 获标度正当性("极限语言下的涌现");
  - **C-FAIL**:任一方向 A=O(1)(轴向最可疑)⟹ 统计/极限重述亦不可达,
    结构性不可达信号升格。
- **稳健性要求**(车道A 复核口径,预注册):方向分层拟合、剔除 k=0 邻域一格、
  常数模型 vs 幂律模型双模型比较;拟合细节不得事后调整。
