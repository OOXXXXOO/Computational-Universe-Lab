## 零、北极星与预注册成功判据(先说死,再开跑)

**主目标**:一条 3+1D 张量元胞规则,线性化引力从它**动力学涌现**——不靠测量投影、不靠手写波动方程。

**"主目标实现" = M3 全绿一号 + M4 去孤岛 两个 checkpoint 都过。** 判定标准现在预注册(下文 M3/M4 的数值表),之后**只许收紧不许放松**;任何达不到就改判据的提议都视为失败信号。

**成了不意味着**:非线性GR(近日点/强场)、量子引力、"世界是CA"。这三条写死,报告里不许暗示。

**当前起点（2026-07-24）**：旧四扇区资产仍有效；R25 新增一般 walk 壳上的规范复形、
auxiliary Wilson UV 修复和静态 Newton 候选。剩余风险集中在“把这些证书落实为同一实空间
rule 时是否互相破坏”，尤其是约束收缩率、moving exact source、动态 Newton/Eddington 与耐力。

## 二、阶段与 Checkpoint

### M0 战役 compose 过线(已拍板,车道B执行中)
四条验收线见 TENSOR_CAMPAIGN_INTERFACE.md 标定拍板节。**过线即放 10⁵ 后台跑**(第二命题,与主线并行不占关键路径)。
- FAIL 分支:金标准探针不 lawful → 贴 tier-2 各判据数值,车道A 24h 内追因。

### M1 T3 交错几何核(车道B主build,车道A理论支援)
**目标**:把 43f 的 null-box+无滞后阻尼几何演化器重建在交错微积分上,加 sponge,**纯几何扇区**重过涌现判据。
**实验**:纯几何(无物质):平面波/纯gauge/混合初条三组。
**checkpoint(数值)**:
| 判据 | 过线 |
|---|---|
| N_prop(无投影 Riemann-SVD)| = 2,全部测试 k |
| 纯 gauge 初条规范反常 | < 1e-12(jax fp64)|
| 约束 C 衰减 | 单调,≥6 个数量级 |
| sponge 反射系数 | < 1e-3(测:出射包往返对比)|
| 体区能量记账(sponge 吸收 = 体区损失)| 差 < 1e-6 |
- **车道A并行交付 R13**:交错 de Donder/E_μν 相容性引理——把 R9 桥引理 T3 从 1 分量扩到 10 分量,认证 ∂·E≡0 在交错点机器零。M1 卡住时这是第一救援。
- FAIL 分支:交错化后 N_prop 回 5/6 → 说明 43f "共享同一微积分"在 10 分量层有新障碍 → 升级为具名开放问题,R13 优先级提到最高,M2 暂停。

### M2 精确流喂源(关键假设的检验点)
**目标**:R10 键流作为 de Donder 源接进 M1 几何(B2 只换了测量,这步喂进动力学)。**这是全计划最大的单点假设**:精确源 ⟹ 规范泄漏降。
**实验**:静态重团 + 运动源两组;对照组 = on-site 双线性源(旧)。
**checkpoint**:
| 判据 | 过线 |
|---|---|
| 规范反常泄漏率(∝G 项)| 较 on-site 源 **≥100×** 下降 |
| 源处 de Donder 残差 | < 1e-10 |
| 闭环中 T_μν 行守恒(live,非仅测量)| < 1e-12 |
| 时间居中(R9 T3:J=½(F_t+F_{t-1}))无滞后病 | N_prop 不回退 |
- FAIL 分支(泄漏不降):"精确源⟹规范闭合"假设错——这是**真信息**:意味着规范反常另有来源(候选:Trotter 轴序倾斜)。处置:(a) 归因实验(θ→0 扫描看 ∝sinθ|k| 签名);(b) 若确系轴序 → 回文子步序对称化,重测;(c) 两者都不是 → 具名开放问题,主线诚实停在"四扇区不相容",这本身是可发表负结果。

### M3 全绿一号(β=0 时刻,主目标第一判据)
**目标**:全部部件装配,**同一构造、同一次运行**通过全判据。
**checkpoint(预注册,fp64)**:
| 判据 | 过线 |
|---|---|
| J1 稳定 | 范数漂移 < 1e-10 @ T=2000(endurance,防慢逃逸)|
| 涌现A:N_prop 无投影 | = 2(≥4 个 k)|
| 涌现B:纯 gauge 动力学压制 | C 衰减 ≥6 量级,规范→物理转化 < 1e-3 |
| 规范反常 | < 1e-10 |
| 牛顿 | h₀₀/φ = 2.00 ± 0.02(Tolman 修正另列)+ 1/r 尾相关 > 0.99 |
| 偏折 | Eddington = 2.00 ± 0.02(Born 弱场)|
| 守恒 | T 行残差 < 1e-12(体区)|
| J5 | \|c_gw/c_matter − 1\| < 1e-2 |
| 各向同性 | 轴间 c 离散 < 6%(已知 Trotter 上限,不阻塞)|
| **证伪炮组(全部必须 FAIL)** | tr_sign=0 / 无阻尼 / 滞后阻尼 / on-site 源 / 错符号源,各致至少一判据 FAIL |
- **通过即宣告主目标第一判据达成**,冻结该构造(种子、参数、代码 hash 入册)。
- FAIL 分支:单判据差口径 → 允许**一轮**参数标定(θ、κ、G、阻尼),重跑全表;两轮不过 → 回 M1/M2 找相互破坏项,不许只调过单项。

### M4 去孤岛(主目标第二判据,防"手搭特例"指控)
**目标**:证明全绿一号不是孤岛——把它嵌进参数族(θ、κ、G、阻尼、tr_sign、轴序…),战役搜索。
**实验**:harness 换全绿族 payload,10⁵ 起步,视漏斗形状放大到 10⁶⁺;J5 第一天入总判。
**checkpoint**:
| 判据 | 过线 |

| 谁 | 干什么 |
|---|---|
| **车道B**(用户驱动,照此文档跑到底)| M0 收尾 → M1 build → M2 接源 → M3 装配,每 checkpoint 贴数值表 |

**升级规则**:任何 checkpoint 连续两轮不过 → 停手,写追因小报告(代码逻辑/约定失配/收敛性/物理,按序排除),两车道会商后再动。禁止"调参到过"式通过——证伪炮组每次全绿都要重放。
