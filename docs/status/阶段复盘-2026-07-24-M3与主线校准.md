# 阶段复盘：M3 为什么久卡，以及主线如何重新收敛

*2026-07-24。按要求暂停继续实现。本文件回溯当前证据、计算与可视化基建失联、M3 定位、最初纲领与固定 3+1D 北极星的关系。它是当前阶段状态的首要入口；早期 README 中停在 R19–R22 的“当前状态”按本文更新。*

## 一、结论先行

方向仍然集中，但需要恢复严格的层级：

```text
总纲领：投影规则空间物理
  └─ 当前科学战役：3+1D 局域 QCA 中的场论结构涌现
       ├─ Maxwell：正控与方法标定
       ├─ Einstein/自旋2：当前北极星
       └─ Yang–Mills：Einstein 线闭合后的非阿贝尔推广
  └─ 后续扩展轴：维度可变规则 + 不可约投影 + 投影残差
```

当前没有理由放弃 3+1D Einstein 北极星，也不应现在把主攻面扩成动态维度或超图。固定 3+1D 是观测投影上的标定战场，不是“宇宙本体必为 3+1D”的假设。高维、紧化和不可约投影已经属于纲领 P3/P4 与开放问题 #6，但应作为下一层规则生成轴，而不是拿来绕过当前 3+1D QA。

M3 至今没有通过。更准确的状态是：**M3 首攻失败后，工程一直处于 M1/M2 级的架构重建；R25 刚得到新的 pre-M3 候选，还没有重新装入同一次闭环运行。** 长期继续称其为“M3 工作”造成了进度错觉。

R25 没有偏离自旋 2 主线，但存在主张风险：它主动借用了 Killing–Einstein–Bianchi/detour complex 来合成规则，因此目前证明的是“存在一个严格局域、walk-compatible 的 GR 型候选”，不是“宽规则空间在不预置 GR 的情况下自行涌现出 GR”。要恢复后一个强主张，必须把 R25 变成候选族，重新接回 QA 漏斗、证伪炮和 M4 去孤岛。

## 二、当前进展：什么已经成立，什么还没有

### 2.1 已成立的旧正资产

- 16 分量手性加倍物质 walk：TT 通道、因果传播与精确键流已经分别有证书；
- R10/R13 精确源链：守恒与 de Donder 源相容达到机器精度；
- 无投影 Riemann-SVD 涌现判据：能把“测量时 TT 投影得到 2”与“动力学商空间真为 2”区分开；
- Newton、Eddington、J5、约束、证伪炮均已形成独立裁判，不需要重新发明。

### 2.2 CP1-v4/L3 得到的负结果

L3-v2 的时间交错 `(h,pi)` 几何核恢复了静态双极点、Newton 井和两个传播模，但其 ideal half-angle 壳与物质 walk 的斜向 Trotter 壳不同，J5 失败。

L3-v3 用局域 walk-trace/Wilson stiffness 把 J5 降到 `4.65e-4` 并保住静态井，但旧 `K_placed` 仍属于 ideal 壳，体对角 `N_prop` 从 2 回到 5。连续插值扫描证明没有调权窗口：J5 `<1%` 要求至少约 94% walk 壳，而旧复形的 DOF 门只容许不超过约 36%。这把病因从“参数没调好”升级为“演化壳与约束复形必须共同变形”。

### 2.3 R25 已经证明的内容

证据来自当前 JSON，而不是计划或口头判断：

| 层 | 已通过内容 | 关键数值 |
|---|---|---|
| R25-A | 精确 Laurent/Floquet 符号；B0 separated placed 差分 no-go | 实现差 `7.97e-16`；`det U=1`；半径 1 |
| R25-B | `F=z_tI-U` 导出的 walk-compatible de Donder 与 detour complex | `rank(G,C,E)=(4,4,4)`；`dim ker(E)/im(G)=2`；残差 `6.75e-15` |
| UV audit | 冻结 walk 的精确非零 `U=I` 节点 | `kx=kz=-1.714143896...`；canonical 同调在节点退化 |
| auxiliary Wilson | 4 个辅助场、物理 gauge rank 仍为 4 的 mapping cone | 全 BZ `0<a_W<3.880`；J5 `1.33e-3`；`rank(G,K)=(4,8)`；商维数 2 |
| static Newton | 半径 2 的局域 source lift 与静态双极点 | 24³/32³ `ratio_A=2.000000`；尾相关 `0.999404/0.999778` |
| dynamic symbol | 有限 Laurent 的状态约束与稳定直接收缩候选 | 16³ 全 BZ 12 个单位模；谱半径 `1+6.2e-15` |

R25 同时补上了 reality structure：有序 `xyz` walk 是手性复 stencil，物理实度规由其共轭/镜像 sector 配对得到；现实条件不会把真实 gauge rank 或两种偏振翻倍。

### 2.4 尚未成立，因而 M3 仍为 FAIL

以下任一缺项都阻止宣告 M3：

- R25 的完整实空间 time-step 与伴随桥尚未实现；
- 当前直接约束收缩最慢率约 `0.99999937`，虽稳定但达到机器底需要不可接受的步数；预条件化搜索在本次复盘前被主动停止；
- moving exact-current source 尚未接入 R25 的 14 分量/共轭双 sector；
- 动态 Newton 固定点、活体源守恒、约束 floor 与 rate 尚未在同一次运行验证；
- Eddington 偏折尚未在 R25 构造上重放；
- sponge、endurance 与完整证伪炮没有重放；
- R25 尚未接入 `emergence_judge` 的真实时序记录，因此符号同调为 2 不能代替最终无投影动力学计数；
- 还没有参数族与近邻流形，M4 完全未开始。

所以当前最准确的标签是：

> **R25 pre-M3：复形、UV、静态和动力学符号候选均通过；统一实空间闭环未验证。**

## 三、为什么 M3 卡了这么久

### 3.1 M3 是交叉相容门，不是普通实现任务

M1/M2 的零件可以各自全绿，M3 问的是它们在同一规则中是否互相破坏。实际连续暴露了五类不同的结构问题：

1. wide null-box 能给 DOF=2，但稳定光速达不到物质光锥；
2. unitary first-order walk 有传播壳，却没有 Newton 所需的静态双极点；
3. symplectic pair 恢复双极点后，ideal 壳与完整 walk 壳在斜向分离；
4. 只换演化壳、不换 gauge complex，会把四个规范暗模重新读成物理曲率；
5. 纯 walk 壳本身有第二个精确 UV `U=I` 节点，必须与复形共同 Wilson 化。

这些问题都不能靠一次参数扫描解决。M3 卡住的本质是：我们原先把“局域规则”误看成传播核、约束、源和阻尼的可独立积木；实际它们必须来自同一个离散微积分或同一个自由分解。

### 3.2 流程上确实有三项失误

- **里程碑命名失真**：M3 失败后仍把所有架构研究称作“继续 M3”，没有显式回退为 `M3-R/pre-M3`；
- **文档滞后**：README 停在 R19–R22，总账只到 43aa，无法反映 L3-v3/R25；甚至“无 doubler”的旧说法已被精确 UV 根推翻；
- **基建脱钩**：每轮做了独立 JSON 和小报告，却没有要求新候选同时实现 evaluator schema、dashboard panel 与 campaign adapter。

这些是项目治理问题，不是物理 no-go。它们解释了为什么真实进展不少，整体感受却像“卡住且看不见”。

## 四、可视化与计算基建为什么没有参与当前工作

### 4.1 它们其实参与过，但参与的是旧候选族

- 标量 harness 已扫 `54,083,584` 条规则；
- 张量 harness 已完成 `106,496` 条旧五参数规则，记录 `1,470` 条 `lawful_tensor`；
- `dashboard_tensor.html`、`dashboard_ladder.html` 和实时 TT shader 均已存在。

所以不是“没有基建”，而是**基建的 payload 仍是旧 `tensor_qca(cg2,gamma,G,tr_sign,sigma)` 代理族**。这些 1,470 条存活者不能替 R25 背书，因为旧 tier-2 没有测试新的 walk shell、Laurent gauge complex、UV exceptional set 和 auxiliary Wilson sector。

### 4.2 当前一段为什么合理地没有用 GPU

R25-A/B/C 的核心任务是 2×2、4×10、10×10 Laurent 矩阵恒等、Gröbner/syzygy 思路和 28×28 小矩阵谱。它们是 CPU/SymPy 证明型工作，GPU 大网格与体渲染不会加速“是否存在局域复形”这个问题。先求结构、再长跑是合理的。

### 4.3 不合理之处在哪里

当 R25 auxiliary Wilson 候选已经出现后，仍没有立即补三件接口：

```text
evaluate_r25_candidate(params) -> gate columns
run_r25/state.json            ->统一证据 schema
dashboard_r25 panel           ->壳/同调/UV/静态/动力学四联图
```

这使计算基建从“研究仪器”退化为旧战役的陈列品。以后规定：任何候选只有同时具备符号证书、实空间 evaluator、可视化 schema，才允许从 R 阶段升级到 M 阶段。

### 4.4 可视化应该画什么

可视化不是装饰，应直接对应病灶：

- Brillouin 区的 `a(k)`、rank-drop 与第二 UV 节点地图；
- `ker E/im G` 的奇异值间隙随 k 的热图；
- J5、DOF、静态极点三者的 Pareto/不可兼容区；
- 约束率与谱预言对拍；
- Newton `h00/hbar00`、`1/r` 尾和 auxiliary dressing；
- M3 一次运行的裁判时间线与证伪炮击穿位置。

## 五、所做工作是否偏离主线

### 5.1 物理问题上：没有

R25 正面实现了纲领 C2“规范即投影核”：gauge directions 是局域规则到可观测曲率投影的核；detour complex 使该核与 walk 特征壳同源。它也服务 C1：要求局域演化与约束自洽，正在逼出一种离散“规则空间 Einstein 条件”。

### 5.2 强主张上：有偏航风险

R25 明确使用了连续 Killing/Einstein/Bianchi 代数作为构造母体。若最终只展示这个单点，我们得到的是：

> “已知 GR 结构可以被编码成一个严格局域、walk-compatible 的 QCA 型规则。”

这很有价值，但弱于最初目标：

> “从一个包含非 GR 规则的局域规则空间出发，经过数学自洽和 3+1D 实验 QA 剪枝，GR 型结构作为存活等价类涌现。”

恢复强主张需要三件事：

1. R25 只是候选生成器中的一个基点，而不是把最终答案写死；
2. Maxwell/Einstein/Yang–Mills 主要作为 IR judge 与结构 QA，而不是逐项硬编码微观演化；
3. M4 证明存活者形成非孤立流形，并量化哪些约束真正选择了 GR 通道。

在完成这三项前，报告必须使用“约束合成/存在性构造”，不能使用“已从规则空间涌现 GR”。

## 六、回到最初讨论：应如何使用已知物理、高维理论与投影

### 6.1 已验证物理不应全部成为微观硬约束

如果把 Maxwell、Einstein、Yang–Mills 的每个方程逐字写进 rule，当然会陷入一个人为选定的局部最优，也失去“涌现”的意义。更合理的是三级约束：

| 层级 | 用途 | 例子 |
|---|---|---|
| 硬门 H | 观测投影上绝不能违反 | 幺正/概率、严格局域与因果、守恒、2 个引力子 DOF、J5、Newton/Eddington |
| 结构先验 S | 缩小不可计算空间，但不指定全部动力学 | exact complex、无 anomaly、可组合投影、有限支撑、维度间一致性 |
| 探索信号 E | 不立即杀死，作为隐藏维度线索 | 投影残差、非马尔可夫记忆、KK 谱、Lorentz/SME 泄漏通道 |

实验定律约束的是 3+1D 投影后的 universality class，而不是强迫 UV rule 逐格等于连续方程。不可约残差正是防止“把现有理论拟合成唯一真理”的出口。

### 6.2 弦论可以做什么

弦论和高维场论中数学上成立的结果可以作为 S 层结构先验或候选生成器，例如 anomaly cancellation、紧化谱、模空间、duality、`beta=0 -> Einstein` 的自洽机制。不能仅因数学自洽就升级成 H 层物理硬门；只有其 3+1D 投影给出可检验后果时，才进入实验剪枝。

### 6.3 规则是否应支持不同维度与不可约投影

应该，但“维度”应进入 rule schema，而不是现在另起一个不受 QA 的宇宙：

```text
Rule = (cell complex / adjacency,
        local Hilbert fiber,
        local update,
        dimension-changing move,
        projection P_D->3+1,
        coarse-graining map)
```

评价同一条高维 rule 时，同时检查：

- 3+1D 投影是否通过 Maxwell/Einstein/Yang–Mills QA；
- 被投影自由度留下什么 P3 残差；
- 不同投影是否属于同一可观测等价类；
- 维度变化是否保持局域性、幺正性和可计算的谱透明。

这条动态维度之桥已经在纲领开放问题 #6 中，但应排在固定 3+1D M3/M4 之后。否则当前尚未解决的 gauge/constraint 问题会被更大的邻接自由度掩盖，无法归因。

### 6.4 与 Wolfram 超图的区别与可行性

Wolfram 路线把动态超图和因果不变性放在本体层，天然容纳维度与拓扑涌现，但规则到标准模型/精密实验的映射较长，计算不可约性强，定量剪枝困难。

本纲领以局域 QCA、谱透明和 `(规则×投影)` 等价类为中心，维度目前固定但每个候选都能快速导出色散、守恒、SME/GR judge，并用实验定量剪枝。它更窄，却在当前计算资源下更可执行、更可证伪。

长期最合理的关系不是二选一：让动态 cell complex/hypergraph 提供邻接与维度层，让 QCA 作为其局域 Hilbert fiber 和更新层；再用本纲领的投影残差与实验 QA 剪枝。但在固定格点的 Einstein 线尚未闭合前，这只是明确接口，不是当前主线。

## 八、最终回答

我们的主线仍然清晰：

> **在一个明确、可计算的局域 QCA 规则空间中，以数学自洽为结构先验，以 Maxwell/Einstein/Yang–Mills 及真实 3+1D 实验为 QA 剪刀，寻找投影后涌现已知场论、同时保留可诊断高维残差的规则等价类。当前北极星是先让 Einstein/自旋 2 这一条在固定 3+1D 中完整闭合。**

真正需要纠正的不是科学方向，而是工作分层：不要把 pre-M3 架构证明叫成 M3，不要把手工合成的单个 GR-compatible complex 叫成规则空间涌现，也不要让 dashboard/harness 在候选变化后继续读旧 payload。
