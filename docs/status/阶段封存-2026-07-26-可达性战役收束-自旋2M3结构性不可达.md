## 一、封存主句(PI 裁定,写死)

> **纲领四承诺(精确约束传播 + 涌现物质 + 严格局域 + 酉)全要时,自旋 2 的 M3
> 结构性不可达。不可达死于极化计数与稳定性死锁,不是残差本身。**

主句三重支撑(全部为预注册判据下的实测或从实测数据提取的论证):

1. **R36 (b) 三线全中**:无稳定清尾耦合(72 个非零反作用构型 0 稳定);耦合无关的
   受保护传播集曲率计数 **[1,1,1,1]**≠[2,2,2,2](断崖 svn₂=1.3e-10…1.5e-2);
   清尾必伤 TT₂。
2. **76.2° 运动学锚(承重件,车道A 复核提取)**:轴向判据 k 处第二 TT 极化与传播带
   主角 **76.2°**(±ω 支逐位一致)——TT₂ 根本不在涌现走行的传播带内。任何以 ker C 为
   读数核的清除动力学,其严格受保护集只能是 W±=E±∩h⁻¹(ker C)(全部 4 个耦合变体下
   不变性残差 ≤2.5e-15),在轴向其 TT 含量只有一个极化。**该论证不依赖扫描家族完备性**:
   把结论从"扫描范围内没找到"升到"运动学上无处可逃";逃逸的唯一出口是更换读数核
   (= 挑模投影 = 非局域/结构改动,rc3b C4/C5 已判死)。
3. **死锁标度性(车道A 复核提取)**:BZ 超增长随反作用强度 ∝η²(实测 η=0.002→0.005
   比值 6.8≈6.25),清除仅在 η≥0.02 出现(超增长 ≥6.5e-3,超稳定门 ~7 个量级);
   外推到稳定门 1e-9 需 η~3e-5,对应清除时标 >10¹⁰ 步 = 永不。**无调参走廊。**

## 二、封存的精确含义

**封存的是什么**:在固定 3+1D、当前冻结走行族与 R30 复形验收判据下,"涌现走行形变到
已证存在的复形上(=M3)"这条路,在四承诺全部保持时被判结构性不可达。判据链全程预注册,
无一门事后调整,负结果与正结果同等入册。

**封存不是什么(边界,红线)**:

- **不是 bit 级不可达定理**:是四可修假说全否 + 三放松候选定价 + 三半验证 + 对抗复核
  的信号链与运动学论证;其强度足以关闭战役,不足以自称数学定理。
- **不封存"放松后可达"**:RC3-(ii) 定价保留——放松任一承诺即可达 N_prop=2
  (R1 弃严格局域 / R2 弃涌现 / R3 弃精确约束),且 J5/TT 全不破;R3 的动力学实现死于
  本封存的死锁,但记账层定价不撤销。
- **不封存正资产**(见 §六)与**其他主线**(Maxwell 线、M4 参数族、标量战役资产、
  纲领 P3/P4 扩展轴)。
- **卡点④(单次联验)在封存下正式按住**;M3 checkpoint 表在北极星文档中保留为历史
  验收锚。

## 四、死因解剖:为什么是"计数 + 稳定性死锁"

1. **泄漏结构**(R28):涌现走行 12 个传播单位模有 34–49% 能量在 ker K=规范⊕TT 之外
   ⟹ 无投影动力学 N_prop=[4,4,5,5]≠2;双正控证明这是真物理,非判据口径。
2. **障碍二分**(RC3/rc3b):(a) −ω 支约束行曲率 = 真违反,**可清除**(R36 (a) 已在
   涌现走行上重认证);(b) +ω 支 gauge-主导模带 5–18% 非-gauge 尾巴,曲率全在尾上,
   且**满足约束**(ker C 内)——清除机器对它无能为力。
3. **(b) 的三道墙**:动力学墙(无稳定双向耦合,死锁标度性)、运动学墙(受保护集
   曲率=1,耦合无关)、对称性墙(TT₂ 轴向 76.2° 锁出带外)。三道墙独立成立,
   任何单独绕过其一仍撞其余两道。
4. **记账≠动力学**(R36 §三):RC3-(ii) 的 R3 读出 2 是把"待清除的违反曲率"也计入
   的记账产物;动力学真把行内容清掉后,剩余传播曲率只有 1 个 TT。**动态阴影守恒与
   谱记账不等价**——这是三半验证挖出的核心事实。
5. **方向依赖病理如实入册**:16/16 通用低对称 k 受保护计数=2(svn₂ 0.052–0.49),
   高对称判据 k 塌缩到 1——与 R29 的 k→0 方向依赖同族;判据 k 集与 [2,2,2,2]
   为预注册写死,不以通用 k 翻案。

## 五、标度证据节(R37 + 车道A 复核;措辞按 PI 采纳的收紧版)

1. **δ=12–18% 不是格子无关常数**:它是 16³ 判据点(|k|=0.79–1.36)的读数;同一冻结
   函数在 48³ 最小可分辨 |k| 处已降至 **2.1–4.4%**(轴向 0.099→0.044、面斜
   0.067→0.022、体对角 0.058→0.021,三方向单调,泄漏能量同步)。
2. **无 O(1) 常数底的证据**:三方向双模型比较幂律全部决定性胜常数
   (ΔAIC +2.7/+17.5/+25.5,含预注册点名最可疑的轴向);C-FAIL 未触发。
3. **"严格趋零(A=0)"未确证**:主判据拟合在面斜/体对角留 ≤5% 小截距;车道A 扩窗
   诊断(明示不改判)下轴向与体对角截距塌到与 0 一致,**面斜是唯一不能在 ≤48³ 内
   排除 ≤5% 小底的方向**(~2%,2.1σ 边缘);被剔除的更小 |k| 原始读数低于拟合截距
   (真常数底不允许),伪影嫌疑入册。ambiguous 维持、不升 C-PASS;≥64³ 补判另行
   预注册、非阻塞。
4. **对封存主句的意义**:残差呈幂律标度、强烈倾向有限尺寸量,但严格趋零在可及格子
   (≤48³)内未判定。**无论子形态如何,不可达死于计数+稳定性死锁,不是残差本身**
   ——该句同时有 R36 (b)、76.2° 运动学锚与死锁标度性三重支撑,不依赖 (c) 的补判。

## 六、不受封存影响的三块正资产

1. **R30 存在性定理**(独立复核):局域酉离散线性化-Bianchi 张量复形存在,
   N_prop=2 断崖;张量版 `div curl=0` 为多项式恒等式。Nielsen–Ninomiya 不杀自旋 2
   复形。——它是任何后续 M4 参数族的天然基点。
2. **R26 清除机制**:约束违反双曲输运 + sponge 吸收(~L/c、k-无关),原 12/12 证书 +
   R36 (a) 在涌现走行实测违反上重认证 8/8。——对任何带约束扇区的离散演化通用。
3. **方法论本身**:两车道 + 预注册 + 对抗复核。本役至少五次阻止在漂亮但错误的结论上
   安家:R27 判据失配假说(R28 三分钟检验证伪)、手性 N-N 假说(RC3 探测一数字裁)、
   slave 路线(R35 撞 R29)、RC3-(ii) 记账读数(R36 动力学揭穿记账≠动态)、
   分离窗质询(车道A 复核以 76.2° 锚关闭)。

## 七、战役收束语

从 R29 到 R37,这条链的每一环都是预注册判据下的实测:四个可修假说、三个放松候选、
三半验证——没有一个结论是默认的,没有一个门被事后调过,负结果与正结果同等入册。
它没有抵达北极星,但它把北极星与现实之间那道墙的坐标(轴向判据 k、+ω gauge 尾巴)、
材质(对称锁出的运动学,非残差)和厚度(死锁标度性,无调参走廊)全部测清,并立起了
三块不受封存影响的正资产。
