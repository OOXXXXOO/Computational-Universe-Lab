**The Projective Rule-Space Program** — 一个以实验剪枝为核心的计算宇宙物理学研究战役。

本仓库不是软件产品,而是一间**计算物理实验室的完整记录**:每个实验是一个自包含脚本,
跑一次模拟、写一份 `*_results.json`、落图到 `figs/`,并对应一份中文报告(`报告-*` /
`战役报告-*` / `小报告-*` / `定理笔记-*`)。报告是实验记录本体,记录了每条规则为什么
被保留或被杀死。

判据预注册:引力子恰 2 个自由度、以物质光速传播、牛顿极限 h₀₀/φ=2.00、
光偏折 Eddington=2.00、守恒 <1e-12、|c_gw/c_matter−1|<1e-2(J5/GW170817)。

**当前步骤遇到的问题**:M3"全绿一号"首攻 FAIL,撞上一个结构性硬冲突
(具名开放问题"**宽盒 vs 光锥**"):

> 给出正确自由度 N_prop=2 的几何(宽 null 盒)被稳定性钉死在 c_gw≤0.576,永远过不了

> **要正确 DOF 就得慢引力子,要光锥引力子就得错 DOF。**

这个冲突已被拆成两半:**光锥半边已解决**(R14:引力子改用与物质同一个幺正 walk 核,

de Donder 约束,而约束算子要求场放置在**半格点** h_μν@(x+½(e_μ+e_ν));整数格上任何
差分模板(中心/前向/后向)已三轮独立否证(TT 模不在算子核内,|K@TT|≠0)。
待办 = 车道 A 的 staggered-h(半格交错场)构造。次级阻塞是闭环几何能量缺真 sink:
阻尼稳定窗已定量解出(γ*≈0.066,R18),约束残差地板 6e-4 已归因于
注入次序 / measure≠enforce 口径失配,处方已开、待按 R18 五条执行。

**进展一句话**:现象学层 ✓ 关闭;标量引力 ✓ 定理级关闭(含诚实天花板);
北极星走到 M1/M2 回炉——两大阻塞一个已解一半、一个已有处方;GPU 多后端基建 ✓ 就绪。
详细状态见第二节,里程碑进度见第三节。

## 一、项目目标

### 中心问题的重设

Wolfram 问"哪条规则是我们的宇宙",这个问题原则上不可判定(实验②:无穷多 UV 规则共享
同一 IR 极限)。我们把问题换成:

> **给定我们只能看到投影(三维、低能、粗粒化),物理定律是"(规则 × 投影)等价类"的
> 什么不变量?实验每前进一步,这个等价类收缩多少、沿哪个方向收缩?**

由此建立了五条有实测证据的原理(P1 涌现保真、P2 谱透明、P3 投影残差、P4 代数选择、
P5 等价类物理)和两个中心猜想(C1 规则空间中的爱因斯坦方程、C2 规范即投影核)。
完整陈述见 `纲领-投影规则空间物理.md`。

### 北极星(当前主目标)

> **一条 3+1D 张量元胞规则,线性化引力从它动力学涌现**——不靠测量投影、不靠手写
> 波动方程。成功判据已预注册(M3 全绿一号 + M4 去孤岛,只许收紧不许放松),
> 见 `主线-实施计划-北极星.md`。

明确写死的边界:即使成功,也**不**意味着非线性 GR、量子引力或"世界是 CA"。

### 物理模型(一句话)

2-旋量 split-step Dirac/Weyl 行走者 + 局域 coin 角场 θ(x,t):涌现光速 c(x)=cos θ(x),
所以 **θ 就是度规**。θ 自身由局域算子库(Laplacian、ρ、J、restoring、damping……)
加权的二阶规则演化,权重向量 `a` 即"一条规则"。物质引导几何、几何引导物质,闭环。
当前前沿是把标量 θ 升级为对称张量 h_μν(自旋 2)。

### 诚实的天花板(三次独立确认)

标量引力不是 GR:等效原理仅超相对论极限成立(耦合 ∝(v/c)²)、相对论物质不自束缚
(R7/r8,干净负结果)、标量度规聚不出视界。**真引力需要自旋 2 张量场**——这正是
北极星战役的由来。

### 当前前沿:宽盒 vs 光锥障碍(具名开放问题)

北极星推进到 M3"全绿一号"时撞上结构性硬冲突,按预注册 FAIL 分支回 M1/M2:

- **宽 null 盒**给出正确引力子自由度 N_prop=2,但稳定性上限 c_gw≤0.576,永远够不到
  J5(GW170817)的 |c_gw/c_matter−1|<10⁻²;
- **紧致半角盒**能给光锥引力子,却把自由度顶回 5。

即"要正确 DOF 就得慢引力子,要光锥引力子就得错 DOF"。此后的进展:

- **光锥半边已解**(R14 引力子行走核):让引力子用与物质相同的幺正 split-step walk 核,
  c_gw≡c_matter 精确 1.0000、各向同性、无 doubler——宽盒永远做不到;
- **DOF 半边未解**,缺口已证书级定位(R15/R17):去唐纳约束需要**半格放置**的
  h_μν@(x+½(e_μ+e_ν));任何整数格差分模板已三轮否证(负控 dim=6、|K@TT|≠0)。
  下一步是车道 A 的 staggered-h 构造;
- 第二阻塞:闭环几何能量缺真 sink,实空间阻尼的 γ 稳定窗已定量解出
  (γ*≈0.066,R18),约束地板 6e-4 归因于注入次序/口径失配,处方已开。

细节见 `小报告-J5宽盒vs光锥-结构性确认.md`、`定理笔记-R14`、`小报告-R15/R17/R18` 系列。
