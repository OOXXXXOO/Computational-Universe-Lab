# V3-M0 fp64 Runtime Semantics Probe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans` to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让每次 fp64 enclosure protocol build/verify 都机械证明当前线程实际满足 hard
arithmetic 所需 binary64、RN-even、gradual underflow/no-FTZ/no-DAZ、nextafter 与
signed-zero 语义。

**Architecture:** 在 `fp64_protocol.py` 内新增完全 private 的 runtime observation 与
exact-bit validator；public wire/schema/函数签名不变。输入从运行时 integer bits 解包，
结果只比较 integer bits。任一 observation/运算/验证异常统一 fail-closed。

**Tech Stack:** Python 3.9、`struct`、`sys.float_info`、`math.nextafter/copy_sign`、
frozen dataclass、`unittest.mock`。

### Task 2: 实现 runtime observation 与 exact validator

**Files:**

- Modify: `rulespace_v3/fp64_protocol.py`

- [ ] **Step 1: 定义 frozen observation**

所有结果字段为 exact `int` bits，不保存布尔“pass”：

```python
@dataclass(frozen=True)
class _Fp64RuntimeObservation:
    double_byte_width: int
    radix: int
    mantissa_digits: int
    minimum_exponent: int
    maximum_exponent: int
    tie_even_lower_result_bits: int
    tie_odd_lower_result_bits: int
    half_minimum_normal_result_bits: int
    minimum_subnormal_scaled_result_bits: int
    minimum_subnormal_sum_result_bits: int
    nextafter_positive_zero_up_bits: int
    nextafter_negative_zero_down_bits: int
    nextafter_positive_minsub_to_zero_bits: int
    nextafter_negative_minsub_to_zero_bits: int
    nextafter_one_up_bits: int
    nextafter_one_down_bits: int
    positive_zero_bits: int
    negative_zero_bits: int
    copied_negative_zero_bits: int
    negative_zero_sum_bits: int
    negative_zero_product_bits: int
```

- [ ] **Step 2: 实现 runtime bit conversion 与 observation**

用 `struct.pack(">Q", bits)`→`struct.unpack(">d", ...)` 构造输入，反向转换所有输出。
DAZ factor 必须是：

```python
scale = float(1 << (sys.float_info.mant_dig - 1))
```

其中 shift 来自 runtime metadata；ties、minnormal、minsub、±0 都不得写成可折叠浮点算式。

- [ ] **Step 3: 实现 exact validator**

要求 `type(observation) is _Fp64RuntimeObservation`，逐字段与冻结 integer/bits 比较。任何
field type 非 exact int（包括 bool）或值不等都拒绝。

- [ ] **Step 4: 实现统一 fail-closed wrapper**

```python
def _require_fp64_runtime_environment():
    try:
        observed = _observe_fp64_runtime()
        return _verify_fp64_runtime_observation(observed)
    except Exception as exc:
        raise RuntimeError(
            "fp64 runtime semantics are not certified"
        ) from exc
```

不捕获 `BaseException`。

- [ ] **Step 5: public build/verify 接线**

将原构造 body 移到 `_build_fp64_enclosure_protocol_body()`。public build 先 probe 再调用
private builder；public verify 先 probe，随后保持原验证，expected 改由 private builder
生成。两个 public signature 不变，每次调用仅 probe 一次。
