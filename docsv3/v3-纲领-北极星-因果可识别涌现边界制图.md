# 纲领 v3 · 北极星：因果可识别涌现边界制图

*2026-07-30 · 承 v1 可达性封存与 v2 M3′ 30 格无牙证据 · PI 签发，已生效*

## 一、北极星

> **以严格局域的 quantum-unitary QCA 为本体主线，并把 classical-symplectic
> 限定为分栏的结构探针与构造预飞；把“目标结构是否由非目标编码的微观机制因果产生”
> 与“成品动力学离目标连续定律有多远”分开测量；在

v3 不再问一个混合问题“它有多涌现”。它分别问：

1. **因果来源**：删除显式目标编码机制后，目标响应还剩多少？
2. **几何质量**：实际传播—曲率子空间离目标复形多远？
3. **极限质量**：约束残差是否随尺度消失，还是留下有限底？

## 二、研究对象与硬公理

### 2.1 H 层与分栏权限

- 严格局域：时间步由有限支撑 primitive 组成，支撑半径与 `L` 无关；
- 量子主线：unitary QCA 是纲领本体对象与 quantum L4 的硬门；
- 经典预飞：classical-symplectic 只属分栏的 S 层结构探针与构造预飞，禁止冒名为
  quantum-unitary 证据；
- 固定实空间 factory：主证据来自真实 factory，Fourier/Floquet 只作运行后读出；
- 固定 3+1D 投影：当前为标定面，不宣称本体维度已解释；
- construction trace：每个 primitive 有稳定 mechanism ID、依赖图、局域支撑与类型，
  全图保存 `grammar_id,target_spec_id,design/search provenance,trace_sha`；
- 成对反事实：任何 `ε_causal` 必有 actual/ablated 两次同协议运行；ablated 还须从完整
  source domain 独立运行 unary geometry/σ 链。

### 2.2 底层候选空间与观测坐标

v3 没有用三个观测量替换 v2 的规则搜索空间。底层候选仍至少按

```text
target_spec × 复形族 × 物质耦合 × 微观规则参数
```

生成；`(ε_causal,δ_geom,σ)` 是对候选运行结果的观测坐标，不是候选的完整参数化。各
`target_spec` 分栏判定：spin 0 标量、spin 1 Maxwell、spin 2 Einstein，以及未来
Yang–Mills 扩展不得混合拟合。V3-M0 当前采用 spin 2 只为校准曲率商空间仪器，不把纲领
缩窄成单一自旋战役；v1 的 spin 0 54M 事实资产、R23 spin 1 与 R25/R30 spin 2 资产均按
各自冻结语义保留，待对应里程碑有限审计。

### 2.3 不再作为单一坐标的内容

- principal-angle 泄漏不是“手搭来源”；
- construction label 不是运行后测量；
- `q`、`κ_C`、层数或代码行数都不能直接代填任何物理坐标；
- 端点与目标算子相似不说明因果来源相同；
- 只看最终转移核不可能识别 construction history。

## 三、坐标与读数

### 3.1 `ε_causal`

`ε_causal` 是相对于一套冻结 grammar 的因果量，不是假装为无条件、无语言依赖的绝对
Kolmogorov 复杂度。grammar 必须在候选数据前冻结，并对等价局部分解做不变量控制。

主读数是在声明 curvature observer quotient 上冻结的 Hermitian 正定 metric 下，
以预注册 `ν_inc(k)` 去除已知 IR 齐次缩放后，actual 曲率有效响应子空间相对
matched-ablated 曲率响应 projector 的扩展补零存活谱 `s_i=cos²θ_i`：

```text
ε_causal_DOF  = #{s_i≥τ_surv}/N_curv
ε_causal_cont = mean(s_i)
```

相位、整体非零幅值与子空间内换基是明确商掉的 nuisance，不能冒充 DOF 消失。原
raw transfer-difference spectrum 被相位/增益反例拒绝；source→response 映射变化只以单个
复标量 Procrustes 辅报。`χ_extra` 必须在完整冻结 source domain 上测 ablation 额外错误模，
不能只看 actual-active source。完整 `s` 谱与 undefined reason 始终入册。

`ε_causal` 单独只宣称“DOF 子空间在干预后存活”。物理正锚与 L4 的“目标定律因果涌现”
还要求 matched-ablated 独立通过几何、标度、映射、色散及适用闭环门。

### 3.2 `δ_geom`

`δ_geom` 是成品响应的 extensional 几何量，只依赖响应子空间、目标复形与冻结 physical
metric。它必须对简并簇内换基及共同源/读出的酉/等距换基不变。一般非等距 canonical
换基只有在 physical metric 与目标子空间同步协变时才允许比较。

主读数：

```text
g_i = sv_i((I-P_kerC)S_curv), i=1..N_curv
δ_geom_DOF = #{g_i≥τ_geom}/N_curv
S_phys = orth(Π_phys^w S_curv)
P_phys = S_phys S_phys†
c_i = eig_i(U_Tphys†P_phys U_Tphys)
rank_deficit = dim(T_phys) - #{c_i≥τ_cover}
```

辅读数：

```text
δ_geom_E = rms(g_i)
```

`g_i` 是固定 actual 维数的单侧扩展谱；`P_phys` 必须在冻结 gauge quotient 中由
`S_phys` 重建，保证 gauge dressing 不改变 coverage；`c_i` 使用独立阈值/grey band，
不得用默认数值秩。
旧 `1-j_out/N_curv` 可作为 `constraint_compatibility` 显示，但不得再命名为因果涌现度。
`δ_geom_DOF=0` 仍不足以判几何完整；必须同时有 `rank_deficit=0`。对 spin 2，
`T_phys` 是 TT/gauge quotient 的物理二维空间。

### 3.3 `σ=(α,A)`

继续使用极限语言：

```text
resid(k;L,T) = A + B|k|^α + o(|k|^α)
```

主判必须报告双模型、AIC、LOO、方向与拟合窗。无噪声确定性级数执行 D-M2-6：高阶
`k^(α+2)` 模型的 `ΔAIC≥2` 与截距至少塌缩 5×、删除最大 `k` 点的 H3 半窗至少塌缩 2×，
两测同判并先过 clean-zero/true-floor 双控制方可排零；随机/采样噪声级数才使用
`|A|≤2σ_A`。`A=0` 是极限边界，不由单尺度机器零代填。

## 六、形式化与数值的权限边界

Lean 负责：

- 两套旧 `ε` 公式互补；
- extensional observer 无法识别不同 construction history；
- canonical-correlation 存活谱位于 `[0,1]` 且对冻结 nuisance 不变；
- quotient coverage 对 gauge dressing 不变；
- 局域支撑组合界；
- canonical kick/drift 的辛性；
- full-positive observer-collapse 的条件定理。

SymPy exact 证书负责：

- Laurent 支撑、卷积与伴随；
- V3-M2 候选获批后的 exact syzygy 或受控 defect 关系（不属于 V3-M0）；
- exact rank/minor；
- 势能自伴与辛矩阵恒等；
- 可重放 JSON 证书。

数值证据仍不可替代：

- 全 BZ 稳定；
- actual/ablated factory 的真实冲激响应；
- fp64 参与度、谱隙与秩阈值；
- `ν_inc(k)` 的 IR 无量纲化及 raw-noise/relative-gap 双门；
- Fejér 窗、LOO、AIC 与尺度收敛；
- 资源、SHA 和恢复态。

quantum-unitary 与 classical-symplectic 必须分层画图、分开拟合；classical 族成功不能
替代 quantum L4 的 unitary lane。

## 七、证伪纪律

每个新指标必须有：

- 已知正控；
- 已知负控；
- synthetic direct-sum 中间控；
- mechanism split/merge 与恒等插入不变量；
- 共同源/读出酉变换不变量；
- 信号地板和谱隙的非零裕度；
- `undefined` 分支。

若指标只能在某个候选上“看起来合理”，但不能对控制矩阵给出冻结答案，它不是坐标。

## 八、诚实边界

- `ε_causal` 明示为相对于冻结 grammar 的因果量；
- `δ_geom=0` 不等于“涌现”；
- `ε_causal=1` 只说明曲率 DOF 子空间存活，不等于“目标定律已涌现”或“物理正确”；
- `A=0` 不等于完整闭环；
- 三者同时良好仍须 Newton、Eddington、源、守恒、共锥与稳定炮组；
- v2 M3′ 的无牙不是失败废料，而是促成可识别性升级的 L1 事实。
- v3 不翻案 v1 封存、不追溯改写 v2 JSON，也不把 spin 2 仪器校准冒充整个多目标纲领。
