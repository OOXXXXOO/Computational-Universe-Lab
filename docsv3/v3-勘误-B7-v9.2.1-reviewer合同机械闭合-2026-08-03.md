## 2. 三项机械矛盾的裁定

### 2.1 ReviewerReceipt fresh-process 字面量

v9.2 reviewer protocol registry 已冻结
`fresh-python-s-immutable-E-venv-invocation-v2`，但继承的
`B7LabReviewerReceiptV1.field_specs[26].fresh_process_protocol_id` 仍只接受 v1 字面量，
导致合法 v9.2 receipt 不可构造。v9.2.1 仅将该 wire literal 精确替换为 v2；record 名称、
字段顺序和其余字段不变。

### 2.2 Outer runner 与 reviewer child 的静态边界

outer roots 明确冻结为 invocation identity precheck/recheck、
`run_python_environment_import_probe_v2`、`capture_environment_manifest_v2` 与
`run_frozen_reviewer_process_v2`。根测试从这 5 个 root 对实际 `compare.py` 做 AST fixed-point；冻结
closure 包括 `_require_lower_hex_v1`、legacy reachable recheck、same-fd/path helpers、bounded process
runner，以及 common 中实际可达的 canonical JSON/SHA、strict JSON、exact-record 与 environment
validator。任一 missing/extra/unresolved edge 都拒绝。

ownership 唯一：`compare.capture_environment_manifest_v2` 是 runtime producer，负责捕获 invocation
chain、target same-fd、`environment_sha` 自根与 import-probe observation；
`common.validate_environment_manifest_v2` 只是 pure observation join，只校验 detached body 和调用者
传入的 observation evidence，不得读文件、环境变量、时钟或启动进程。

两个 reviewer child role roots 和 module bootstrap 均不得可达这些 outer roots/helper；尤其
不得从 reviewer child 内调用 `run_python_environment_import_probe_v2`、
`run_bounded_reviewer_process_v1` 或 v2 frozen reviewer wrapper。任何 call/import edge 都拒绝。
这仍是受控主机 path recheck，不是 descriptor-bound 执行证明。

### 2.3 B8 diff 的完整 allowlist

冻结的 metric algorithm 要求 `difflib.unified_diff` 且先以 `str.splitlines` 构造行序列。
因此 v9.2.1 同时、且仅同时补齐：

1. common external import：`difflib`；
2. allowed external call：`difflib.unified_diff`；
3. allowed immutable method：`str.splitlines`。

只补 import 而缺少 call 或 method 仍是静态扫描失败，不得运行 D0。
