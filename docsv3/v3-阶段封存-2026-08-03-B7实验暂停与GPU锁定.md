## 3. D0 中止与 C′ framing 缺陷

完整 D0 曾从 `adf1715` 启动。运行 11 分 13 秒后，在任何固定结果发布前主动中止；
`data/results/experimental/v3m0_b7_schema_lab/d0_comparison.json` 始终不存在，因而没有可声明的
D0 survivor 或 halt。

中止原因不是门或阈值失败，而是 common C 的 D1 raw-byte join 不可满足：

1. D0 materializer 和 corpus materializer 都固定写出 project canonical JSON 加恰好一个 LF；
2. `build_d1_comparison_v1` 却要求输入字节严格等于不含 LF 的 canonical JSON；
3. D1、terminal review 与 immutable reviewer 同时要求 SHA-256 绑定含 LF 的 Git blob raw bytes；
4. 因此同一个输入无法同时通过 body equality 与 raw SHA join。

候选修复只把 D0 raw 与 fixture raw 统一为 `canonical JSON + exactly one LF`，不改变路线、
11,618 mutation、gate、metric 或阈值。当前 WIP：
