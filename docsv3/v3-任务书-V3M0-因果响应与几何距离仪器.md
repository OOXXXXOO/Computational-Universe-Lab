# v3 任务书：V3-M0 因果响应与几何距离仪器

*2026-07-30 · 状态：PI 签发，只解锁 V3-M0 实施*

## 0. 目标、范围与成功上限

本设计交付一个版本化的 V3-M0 仪器，不交付 M3 边界：

1. 关闭旧完整正频支 evaluator 的结构性退化路径；
2. 形式化旧 `ε` 的互补矛盾与 provenance 不可识别性；
3. 从真实实空间 factory 成对测量 actual / matched-ablated 响应；
4. 分别输出 `ε_causal`、`δ_geom`、`σ=(α,A)`；
5. 用 synthetic anchor triangle 和 nuisance controls 认证同一算法；
6. 只为 V3-M1 交付历史 typed-adapter 合同；R30、R23、R25 的实际重测属于 V3-M1；
7. 不在本任务内批准、构造或 pilot 任何新家族。

本轮最高状态为：

```text
READY-V3-M1-ANCHOR-CERTIFICATION
```

它只解锁串行的 V3-M1 旧锚认证，不解锁 family Round 0、30 格 pilot 或正式扫描。

## 1. 路线比较

### 路线 A：只换 Floquet 频带

对当前 Verlet 家族选某个相位簇或 Riesz window，再测主角谱。

优点是改动小；缺点是完整家族确实传播全部 `h` 坐标，频带在端点闭合，且即使选出牙齿也
不能解决 provenance/geometry 混用。只保留为诊断，不作为正式路线。

### 路线 B：只建立双轴仪器

先建立 actual/ablated 双轴 observer、机械 construction trace、冻结响应链与控制矩阵，
在任何新 family 坐标进入视野前证明仪器有牙。

优点是把 observer 病灶与 family 病灶严格分开，且不让某个候选族反向决定阈值、窗口或
坐标语义。代价是 V3-M0 完成后仍须独立通过 V3-M1，才能进入 family 设计。

**裁定：采用。**

### 路线 C：仪器与 family 同时设计

可同时试秩受限 syzygy Hamiltonian 或第一阶 unitary QCA，并以最先出牙者倒推仪器。

该路线会把构造选择、observer 选择和阈值选择重新耦合，无法区分“仪器有牙”与“只对该族
有牙”，故 V3-M0 不采用。syzygy、受控 defect 与 unitary QCA 留待 V3-M2 的独立路线比较；
若最终主张涉及 quantum L4，unitary lane 是必经门，不是可永久搁置的备线。

## 2. 组件边界

### 2.1 `ConstructionTrace`

职责：机械记录 factory 的 primitive DAG，不依赖用户手写 `hand_built=true/false` verdict。

每个 primitive 必含：

```text
grammar_id
target_spec_id
mechanism_id
production_id
kind = target_blind | target_conditioned | unclassified
depends_on[]
support_offsets[]
state_channels[]
coefficient_digest
symbolic_origin_tags[]
neutral_ablation
design_objective_tags[]
search_run_id | null
source_sha
design_provenance
```

传递依赖只要触及以下目标对象，即归为 `target_conditioned`：

```text
C, kerC, inc, TT projector/basis, R30 placed-Yee coefficients,
target N_prop repair operator
```

target-blind grammar 允许：

```text
整数平移、格对称通用混合、与目标无关的局域 canonical shear、
冻结物质 walk primitive、通用质量/色散项
```

trace 由 typed primitive 组合自动生成；runner 不能覆盖其 kind。目标依赖 taint 必须在
系数数值化之前传播，不能只看最终 primitive 类型。历史 R23/R25 适配器把源码中的
`C/κ/placed-Yee/de Donder/Wilson` 来源显式入 trace；把同一系数改写成数值 literal
不会自动获得 target-blind 身份。opaque literal 默认记 `unclassified`，不能靠人工注释
升级为 target-blind。超出冻结 grammar 的来源同样记 `unclassified`，其
`ε_causal` 不可判。最终 trace 必保存 `trace_sha`、源码 SHA、design-time objective/search
provenance；历史 typed adapter 在 V3-M1 使用前须给出与冻结原 factory 的一步核及多步响应
等价证书。

任何 coefficient/parameter 若由读取 `target_spec`、目标方程、目标 projector 或
target-aware loss 的设计、搜索、筛选、人工择优确定，其依赖 taint 必须传播为
`target_conditioned`；数值 literal、缓存、复制或重命名不得洗白。

`grammar_id` 标识整套 grammar，`mechanism_id` 标识 primitive 实例，新增
`production_id` 才标识该实例使用的冻结 production。V3-M0 grammar
`v3m0.local-linear-primitive.v1` 的 target-blind productions 仅为：

```text
integer_translation, lattice_symmetry_mix, local_canonical_shear,
frozen_matter_walk, universal_mass_term, universal_dispersion_term
```

以下 productions 固定为 target-conditioned：

```text
target_operator, target_projector, target_basis,
placed_target_coefficient, target_repair_operator
```

未知 production 为 `unclassified`。taint join 顺序固定为
`target_conditioned > unclassified > target_blind`。

`design_provenance` 不再是自由文本，而是 typed provenance DAG 的根 ID。DAG 节点至少区分
grammar primitive/constant、target spec/equation/projector read、target-aware objective、
derive、cache、copy、rename、search、selection、manual selection、opaque literal 与
unclassified。`SEARCH/SELECTION/MANUAL_SELECTION` 若没有可追踪 objective/search 祖先，
不得成为 target-blind；`CACHE/COPY/RENAME` 只能继承、不能降低 taint。独立 opaque
literal 为 `unclassified`，由 target 节点导出的 literal 仍为 `target_conditioned`。
runner 输入中没有覆盖 `kind` 的权限；`kind` 只能由 grammar registry 与两层 DAG 重算。

每个 coefficient 另有 sidecar，绑定 `mechanism_id`、冻结 variable order、受限 exact
SymPy AST、provenance root 与 `coefficient_digest`。允许的 AST 只包含整数、有理数、注册
symbol、`I/Add/Mul/Pow` 的 exact 子集；拒绝 float、NaN/Inf、未知函数。外部序列化字符串
不得交给不受限 `sympify`。Task 8 只证明 trace 内部 provenance/系数一致性；sidecar 与历史
源码/运行的一步核及多步响应等价仍由 Task 16 认证，不能由 digest 冒充。
Task 9 synthetic lowering 只接受 `variable_order=()` 的 closed sidecar，并须调用 trace
模块的受限 `evaluate_closed_coefficient` 从已验证 AST 得到 finite complex 值；caller
不得另传一个未绑定的 numeric coefficient。含变量的历史 lowering 留给 Task 16 等价证书。

完整 `ConstructionTrace` 保存 provenance DAG、coefficient sidecars、primitive DAG 与
`trace_sha=canonical_sha(body)`；primitive/layer 顺序保留，set-like 字段 canonical
排序。split/merge、恒等插入或可交换层重排允许产生不同 `trace_sha`，其响应不变量属于后续
control，而不是 Task 8 的 SHA 等价主张。

trace verifier 的一次 deep snapshot 对同一容器对象全局 memoize：每个 Mapping 的
`items()` 在整次验证最多调用一次；先完整物化父 items/sequence，再递归 child；memo 强持有
原对象并作 identity 对照，alias 复用第一次 immutable snapshot，cycle 仍拒绝。
资源界冻结为 snapshot depth/nodes `128/100_000`，DAG nodes/edges/depth
`4_096/16_384/4_096`，coefficient AST depth/nodes `64/4_096`，integer digits `256`，
Pow exact exponent 分子/分母 magnitude `≤256`；DAG 采用有界迭代拓扑序，builder 返回前
走同一完整 verifier/resource gate，越界必须在 SymPy eager 求值前统一为 `ValueError`。

Coefficient symbol 只接受标准 commutative、无 assumptions 的 `sp.Symbol(name)`，symbol
集合与 `variable_order` 必须精确相等。SEARCH 必须有真实 objective/search 祖先；
dependencyless SEARCH 不得自授权，SELECTION/MANUAL_SELECTION 的 run ID 必须来自实际
SEARCH 祖先。builder/verifier 同时拒绝 provenance/coefficient/primitive 任一集合为空。

### 2.2 `MatchedAblationFactory`

输入 actual factory 与 trace，输出成对 factory：

```text
actual(state)
ablated(state)
```

ablated 把全部 target-conditioned primitive 替换为其注册的同接口 neutral identity，保持：

- 相同状态 schema；
- 相同 dtype/backend；
- 相同 `dt`；
- 相同 target-blind 参数；
- 相同层顺序占位；
- 相同源、边界与读出；
- 相同运行长度。

禁止以 `q=0`、另一个 candidate 或重新调参后的 factory 代替 matched ablation。
neutral ablation 只能是该层接口上的恒等作用；“施加 inverse”不是消融。若需证明组合
`S∘S⁻¹` 为恒等，必须由独立组合证书完成。

若 ablated 不可逆、失稳或状态不匹配，本候选的 `ε_causal=undefined`。

#### 2.2.1 可执行 runtime 与 trace 绑定

V3-M0 synthetic runtime 的状态布局固定为 `(channel,*spatial)`、NumPy `complex128`，
边界 registry 仅允许 `periodic-v1`。`PrimitiveInterface` 冻结
`state_schema_id/spatial_ndim/channel_order/dtype/backend`；一个 synthetic
`Primitive` 是同接口的单个局域 canonical shear：

```text
destination(x) += coefficient · source(x+offset)
```

`BasisManifest` 与 `FrozenComplexTensor` 是 synthetic runtime 唯一可进入证据链的复数
容器：全部复数以 finite fp64 `(real,imag)`、row-major immutable tuple 编码，SHA 为排除
自身 SHA 字段后的 strict canonical payload；需要计算时每次生成 fresh `complex128`
数组。raw/owning ndarray 不能充当 frozen source/readout/target/kernel 证据。
Task 9 commit `39d1c1427aefa38cd46e1272affb9a10dd46a073` 的 public surface 逐名保留：
`basis_manifest_payload/verify_basis_manifest/build_basis_manifest/basis_manifest_array`、
`frozen_tensor_payload/verify_frozen_tensor/freeze_complex_tensor/frozen_tensor_array`、
`ablation_manifest_payload/dynamics_report_payload/build_dynamics_report/
verify_verified_dynamics_report`，以及
`VerifiedDynamicsReport.certificate_sha/QualifiedAblationOutcome.certificate_sha`。
Task 10 只能定向增加 certificate-backed qualification issuer/hydrator；不得改名、删除或
让 raw report builder 获得 authority。
所有 basis 的 wire shape 统一为 `(n_vector,n_channel)` 且两维非零；source/hold-out
行向量 `v_a` 定义 `J[c,a]=v_a[c]`（不共轭），readout 行向量 `w_a` 定义
`P[a,c]=conj(w_a[c])`，不得另作隐式转置/共轭。

其 `mechanism_id/production_id/support/channel/coefficient_digest` 必须逐项绑定已验证
`ConstructionTrace`，公开 coefficient 字段固定为
`coefficient_wire=(real,imag)`，且只能由 closed AST lowering 获得。对 actual shear，
source/destination 必须是不同合法通道，trace 的 channel 集精确等于二者，trace support
精确等于 `canonical({zero,offset})`，且 real/imag 不得同时为任一符号位的 fp64 zero；
否则会形成 neutral 之外的第二种 no-op 编码，必须拒绝。NumPy periodic 约定为逐轴
`roll(source,shift=-offset)`。

neutral primitive 是闭 registry 内唯一的 `neutral-identity-v1`：保留 original
mechanism/production/layer/interface/source/destination/coefficient digest，强制
`operation=neutral_identity, offset=zero, support={zero}, coefficient=(0,0)`。registry
没有 public register/callable 注入口，任何其他 no-op 编码均拒绝。其 digest/provenance
仍绑定 original trace，但 wire 只校验规范零值，不与 original 的 `±1` 等 sidecar lowering
数值比较；actual shear 才必须逐位等于 lowering。

`LinearRealspaceFactory` 保存完整 `PrimitiveInterface`、已验证 readout manifest，并保存
`factory_schema_version/factory_role/factory_id/construction_trace_sha/grammar_id/target_spec_id/
target_spec_sha/runtime_operator_sha/state_schema_id/spatial_ndim/channel_order/factory_sha`；
重复字段须与 interface 逐位相等。`state_shape` 精确为
`(len(channel_order),*spatial_shape)`。

公开 factory payload 不能直接执行。`verify_factory/build_factory_from_trace` 必须重新验证
trace、target、closed coefficient lowering、operator wire 和全部 SHA，返回带模块私有
构造 token 的 `VerifiedFactory`；它内部持有 factory、trace 与 frozen target。所有 runtime
入口只接受 `VerifiedFactory`，模块侧签发注册表另存不可由 wrapper slot 改写的完整 seal；
每次执行前重算 factory/trace/target/role fingerprint 并与 seal 对拍。通过
`object.__setattr__` 改 private slot 必须 fail-closed，因而 caller 不能通过直接实例化或
反射改写 factory 把任意 numeric wire 送入执行器。单 primitive kernel `_apply_primitive` 必须是模块私有，
由 interface 唯一映射通道；公开只保留接受 `VerifiedFactory` 的 `apply_factory_step`。
Task 10 必须复用该 executor，禁止另造 evaluator-only symbol。
public builder/verifier 只接受全为 actual shear 的 payload，只签发
`VerifiedFactory(role=actual)`；caller 提供 neutral 一律拒绝。只有 `matched_ablation`
内部可签发 `role=matched_ablated`，且 `matched_ablation` 只接受 actual role。

`runtime_operator_sha` 不是 caller 标签，而是把有序 primitives 投影为完整 runtime
operator wire 后重算；消融后必须对 ablated factory 重新计算。只有 wire `full` actual factory
要求该 SHA 与 calibration seed/target 三者相等。public `PrimitiveOperatorWire` 只表达
actual shear；neutral opcode 只存在于 matched-ablation 内部生成的 runtime payload。

factory 是**一次宏步**算子，保留的历史 `run_length` 字段在本 schema 中必须等于 `1`。
canonical full-state impulse kernel 永远测一次宏步得到 square `M_full(k)`；full-state
随机多步属于独立 `FullStateBridgeSpec`，Fejér 与 source/readout 多步属于后续
`ResponseRunSpec`，都通过 `M_full(k)^t` 或重复同一 executor 实现，不是 factory 固有属性。
actual/ablated 的 paired response 必须共享同一 `ResponseRunSpec`。

factory 与 trace 的 SHA/grammar/target ID+SHA/mechanism 顺序/production/support/channel/
coefficient/runtime operator 任一不匹配返回 `MANIFEST_MISMATCH`。
`build_factory_from_trace` 可以接收 placement/operator wire，但 coefficient 必须从 trace
重新 lower 且只接受逐位相等。`matched_ablation` 不接受 caller 提供 ablated factory：
target-blind primitive 逐对象保留，target-conditioned primitive 只能由闭 registry 生成
上述唯一 no-op，故 q=0、另一个 candidate、inverse、删层与 blind 重调参在 API 层均不可表达。

所有自哈希 schema——basis/tensor/calibration seed/observation/target/factory/ablation
manifest/dynamics report/run spec/response——均以排除自身 SHA 字段后的**完整 body**计算，
严格拒绝未知字段并可独立重签验证；语义 ID 不能代替 digest。construction 返回带
`BlockStatus` 的 `AblationConstructionOutcome`，成功时含 actual/ablated pair、逐 slot
`AblationReplacement`、
`AblationManifest` 及其 canonical SHA。Task 9 只裁定 construction：
unclassified → `TRACE_UNCLASSIFIED`，无合法 no-op → `ABLATION_NOT_REVERSIBLE`，接口/元数据
不匹配 → `STATE_SCHEMA_MISMATCH`。全 BZ/shell 动力学稳定不由 metadata 猜测。
`AblationDynamicsReport` 只是不可执行 wire，必须绑定 ablated `factory_sha` 与后续
`DynamicsCertificate.certificate_sha`；caller 自报的布尔值或任意 certificate ID
不得进入 qualification。Task 9 不得留下可导入 capability 或“测试专用成功 issuer”；
只有 Task 10 的 public certificate bridge 完整调用 `verify_dynamics_certificate` 后，才可
签发 opaque `VerifiedDynamicsReport`，再由 qualification 函数生成同样 opaque、可重验且
暴露稳定 `qualification_sha` 的 `QualifiedAblationOutcome`。presence invariant 为：
construction defined 当且仅当 pair
非空；其失败进入 qualified 后 pair/report 均空；construction 成功则 qualified
pair/report 均非空。首错顺序固定为 trace binding → classification → neutral construction
→ schema/shape/dtype/backend/dt/metadata → report SHA/factory binding → report schema
→ reversibility → stability，并分别传播 `MANIFEST_MISMATCH/TRACE_UNCLASSIFIED/
ABLATION_NOT_REVERSIBLE/STATE_SCHEMA_MISMATCH/UNSTABLE`。最终
`ε_causal` 的 API 只接受并在入口重验 `QualifiedAblationOutcome`，不能把 construction
成功、raw report 或自哈希布尔声明误当动力学合格。

`AblationManifest.replacements` 仅覆盖 target-conditioned primitive，严格保持其原 layer
顺序；blind slot 不生成伪 replacement。Replacement 与 Pair 的完整 payload 由
`manifest_sha` 递归绑定，自身不另设 SHA 字段。

runtime actual primitive 的 coefficient wire 即使是 public 字段，也必须由 pair/factory
verifier 逐位等于对应 `CoefficientRecord` 经 `evaluate_closed_coefficient` 后的
complex128 `[re,im]`；neutral 则执行上面的规范零值分支。改 actual numeric 而沿用 digest
必须失败。

#### 2.2.2 synthetic control 的两阶段冻结

full/zero/direct-sum 的参数 `mode_count=N` 必须为正整数。每个 mode 的 channel 顺序冻结为
`(x.000,y.000,x.001,y.001,...)`；direct-sum 的 blind 对使用全局编号 `0..N-1` 的
`(x.b.NNN,y.b.NNN)`，conditioned 对使用全局编号 `N..2N-1` 的
`(x.c.NNN,y.c.NNN)`，不得复用 channel ID。
canonical source basis 逐列注入每个 `x`，readout basis 逐行读取对应 `y`。每对不使用
单 shear，而固定三个零偏移 shear

```text
y += x
x -= y
y += x
```

合成为稳定 quarter-turn `(x,y)↦(-y,x)`。wire `full` 每对三层全 blind；`zero` 每对三层全
target-conditioned；`direct_sum` 是 blind 与 conditioned 两块的直和。消融后 conditioned
三层均变为 no-op，因此响应秩分别为 `N/N`、`N/0`、`2N/N`。generic executor/rank 算法
的参数、分支与 payload 均不得含 control label；只有 control builder 可以按预注册 kind
组装相同 primitive API。

wire `full` 的 target 采用两阶段协议，消除“先有 target 才能建 trace、又要先测响应才能冻结
target”的循环：

1. 建立无 `target_spec_id` 的 blind `CalibrationSeed`，冻结 interface/state/dt/source/
   hold-out source/readout/boundary、target-blind 参数与 target-free
   `PrimitiveOperatorWire` runtime payload；`runtime_operator_sha` 只哈希 operator payload，
   `seed_sha` 哈希排除自身后的完整 seed；
2. 唯一 calibration executor 复用 production primitive 内核，在 seed 内的 hold-out
   basis 每个 vector 的空间原点注入单位 delta，运行一次有序 seed operator，并以 seed
   readout 读取 full periodic 输出；tensor shape 为
   `(n_readout,n_holdout,*spatial_shape)`，原点、signed support 与 no-wrap 规则完全复用
   Task 10，得到不可变且自哈希的 `CalibrationObservation`；
3. `FrozenSyntheticTarget` 内嵌完整 observation，并保存
   `target_spec_id,target_spec_sha,calibration_protocol_id,seed_sha,target_response,
   runtime_operator_sha`；必须有
   `target.seed_sha=observation.seed_sha=seed.seed_sha`、
   `target.observation=observation`、`target_response=observation.response_tensor`，
   而不是只保存无法重建的 ID；
4. 用该 target 重建最终 trace/factory，并证明 `runtime_operator_sha` 与 calibration seed
   及 frozen target 三者逐位相同，同时 factory 保存 target ID 和 target SHA；final trace
   的每个 primitive 还必须机械分类为 `target_blind`，相同 operator wire 不能掩盖
   target-conditioned provenance；
5. 只有最终对象进入 matched/evaluation。API 不接受 raw projector/response ndarray。

Task 9 的 `SyntheticControlBundle` 保持 commit `39d1c14` 已提交 wire：
`control_id∈{"full","zero","direct_sum"}`、保留
`expected_actual_rank/expected_ablated_rank`，且不新增 readout 字段；readout 只能从
`VerifiedFactory` 内重验取得。

Task 10 才把三个 verified bundles 封入 registry。raw `ClosedControlRegistry.entries` 的
唯一 wire 顺序为 `("full","zero","direct_sum")`，没有 public register/append；大写
`FULL/ZERO/DIRECT_SUM` 只可作 UI 展示标签。每个 `ControlRegistryEntry` 从 bundle/factory
重算 builder ID、factory SHA、完整 source/readout、mode count、parent freeze；V3-M0
synthetic 的 h/curv actual/ablated 四个先验秩由 bundle 现有两个 expected rank 机械复制，
API 不接受 caller rank。

entry 还递归内嵌 `ControlReadoutCalibrationSpec`。synthetic issuer 按 factory readout 维数
构造 bit-exact identity h whitener、curvature incidence、curvature whitener 与 identity
normalizer，证明 V3-M0 control 的 h/curv 是独立命名但机械相等的冻结映射。raw registry
仅可序列化；`build/verify_closed_control_registry` 必须重验三个 bundle、factory seal 与
全部 SHA，返回内部绑定这些 snapshots 的 opaque `VerifiedControlRegistry`。structure、
expected-rank issuer 与 calibrator 每次入口都重验该 opaque seal，caller 重签 raw registry
不能冒充 closed issuer。三个 synthetic control 的 structure lane 固定
`synthetic-classical`，不得升级 quantum。

结构 stencil support 必须包含零偏移：一宏步取有序各层 support 的 Minkowski 和，多宏步

### 2.4 `CausalSurvival`

本 evaluator 只接受 actual/ablated `VerifiedResponseBlock` 与
`VerifiedSurvivalThresholdCalibration`；raw block、raw threshold 或 window calibration
不能替代存活阈 capability。actual block 的 `Q_curv` 固定被比较 sector；`Y₀` 必须对
matched-ablated branch 的完整 response 作用同一 `Q_curv_actual`，不能借用 actual response。

`ε_causal` 的主估计对象是“actual 的曲率有效响应 DOF 在 matched ablation 后是否仍由
native 机制张成”，不是 exact transfer waveform 是否逐位不变。对同一 source/readout
规范下的 `R₁,R₀`，均取上述 `R_h`。先按 actual 响应冻结：

令 `G_source,G_h,G_curv` 是相应声明 observer 空间上的冻结 Hermitian 正定 metrics，
`W_h†W_h=G_h`、`W_curv†W_curv=G_curv`；source 先按 `G_source` 白化。若原空间含
metric-null kernel，必须先用冻结 quotient/support map 移除，再在商空间冻结正定 metric；

6. `Y₀=Y₁A` 的可逆非标量内部混合 → 主存活 1 而 `κ_map<1`；
7. 构造性/破坏性干涉对 → 存活、`χ_extra` 与 Procrustes 辅报按预言分离；
8. rank-`r` target-conditioned 缺模 → 恰有 `r` 个补零 `s`；
9. pure-gauge `h` dressing 任意放大 → 曲率 `s` 谱不变；
10. ablated 仅在 actual-inactive source 新生正交模式 → full-source `χ_extra` 精确报出；
11. 幅值跨越 null/grey/signal 三段 → 分别得到 `0/undefined/1`；
12. `ν_inc(k)` 归一化控制跨全部冻结方向与 `L/k` 窗保持 `N_curv`，raw noise 双门不误放；
13. actual=ablated=0 → 三坐标 `undefined`；
14. ablated unstable 或 trace unclassified → `ε_causal=undefined`；actual shell 闭隙或
    actual 响应秩为零 → 三坐标 `undefined`；
15. TT、TT⊕row、full-h 与低秩 TT 子空间 → 冻结长度 `N_curv` 的 `g` 谱；
16. `c=0.25/0.75` 物理覆盖 controls → `rank_deficit` 在线两侧且 grey 分支正确；
17. `S_curv=span(t+ag)` 的任意 gauge dressing → quotient `c` 谱与 `span(t)` 逐位相同；
18. `R₀` 在独立源域的 geometry/σ unary chain → 新生源方向不漏报；
19. 完整正频满 `h` → observer-collapse 证书触发；
20. clean-zero / true-floor 确定性级数 → D-M2-6 两侧全判对。

### 5.4 表示不变量

- layer split/merge；
- 插入 `S S⁻¹`；
- 重排可交换层；
- 保持物理邻接图不变的 q label 置换；
- `G_source` 同步协变的共同 source 等距换基；
- `G_h,inc,G_curv,Π_phys,G_phys` 与目标子空间全部同步协变的共同 readout 等距换基；
- 相对相位翻转与越过绝对门的整体非零幅值重标；
- 仅当 physical metric、source metric 与目标子空间同步协变时的局域 canonical 换基；
- 两个无 wrap 体积的同一支撑。

不变量指 `K_surv` 的 eigenvalue multiset、trace 与阈值计数；基变化下矩阵本身只要求酉
相似，不要求逐项相等。`s`/主角谱的漂移门为 `≤1e-12`，且预期漂移必须由 controls
证明远离判别线。
Procrustes gain/phase 对 actual/ablated 的相对幅值或相位本来就可变，不列为主轴不变量。

## 6. 串行交接边界

### 6.1 V3-M1 的有限合同

V3-M0 只允许把以下合同交给下一任务书，不在本设计内执行：

1. R30/R23/R25 通过 typed adapter 由同一成对接口重测；
2. 在任何数值重测前冻结现有仓库中可审计的 target-blind 资产清单、SHA 与固定顺序；
3. 只审计该有限清单，不新增生成式搜索、不边看结果边调参；
4. 若没有通过下述布尔谓词的物理正锚，返回
   `HALT-V3M1-NO-PHYSICAL-CAUSAL-ANCHOR`，阻止 V3-M2 与 L2–L4 边界主张；
5. 新增搜索预算只能由另一份预注册补丁授权。

`PHYSICAL-CAUSAL-ANCHOR-PASS` 当且仅当：

1. actual/ablated 的全部预注册 shell block 均 defined，response/rank/threshold margin 全过；
2. `ε_causal_DOF=1`、`min_i s_i≥0.99`、`ε_causal_cont≥0.99`；
3. `χ_extra≤τ_extra`，其中
   `projector_bridge_max` 是 repeatability、realspace↔symbol 与表示不变量 controls 的最大
   projector operator-norm 漂移，`τ_extra=max(1e-10,100·projector_bridge_max)`；
   extra-mode 负控须至少在其外 `10³` 倍；
4. actual 与 ablated 均满足 `δ_geom_DOF=0,max g_i≤0.025`，
   `rank_deficit=0,min c_i≥0.99`；
5. actual 与 ablated 的 `σ` 均按 deterministic/noisy 对应协议排零；
6. 该 sector 冻结的映射、色散、源、守恒、稳定与闭环门在 actual/ablated 两支均 PASS。

因此这里的“正锚”不是浮点精确等式，也不以仅存活同一个 span 代替目标定律闭环。

V3-M1 全过的最高状态为 `READY-V3-FAMILY-DESIGN`。

### 6.2 V3-M2 的非约束性候选

本设计**不批准任何新 family**。后续独立设计至少比较：

- 受控 defect 的 classical-symplectic 插值；
- 只把 exact syzygy 用作目标端点的秩受限 Hamiltonian；
- 第一阶 unitary QCA。

一个可研究但未获批的 classical 假说是

```text
D_q = (1-λ_q)D_walk + λ_q Z_target
C Z_target = 0
```

而不是对所有 `q` 强制 `CD_q=0`。后者会令整条族理论上
`δ_geom=0`，既无法忠实复现 frozen R25 的非零几何距离，也没有几何谱牙。任何 q=0…4
合同、endpoint bridge、局域支撑、辛性/酉性、Floquet 稳定和 pilot 表都必须在 V3-M2
任务书中重新比较与冻结。

## 10. 失败处理

- Lean 证明失败：不以 SymPy 浮点替代定理；
- construction trace 可被 relabel 绕过：`HALT-V3M0-IDENTIFIABILITY`；
- controls 无 `10³` 信号分离：不冻结阈值；
- 无公共 Fejér `T` 在 closed registry 全部 controls 上同时满足 shell、两读出与 bridge：
  calibrator 返回 `WINDOW_UNRESOLVED`，仅 orchestrator 映射 `HALT-V3M0-WINDOW`；
- `ν_inc` 归一化在预注册 IR 窗改变合法秩，或 raw noise 双门失效：仪器 FAIL；
- phase/amplitude controls 改变主 `s` 存活 verdict：因果仪器 FAIL；
- 单侧 `g` 或 coverage `c` 落入 grey band：对应 verdict `undefined`，不得默认求秩；
- ablated full-source unary chain 不可执行：物理正锚谓词 FAIL；
- synthetic control 需要 family-specific `ε_causal` 特判：仪器 FAIL；
- D-M2-6 clean-zero / true-floor 任一误判：`σ` 仪器 FAIL；
- 任一失败都不得跳到 V3-M1，更不得借候选 family 反调仪器。
