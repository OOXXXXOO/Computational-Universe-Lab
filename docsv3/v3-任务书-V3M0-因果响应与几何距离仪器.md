# v3 任务书：V3-M0 因果响应与几何距离仪器

*2026-07-30 · 状态：PI 签发，只解锁 V3-M0 实施*

## 0. 目标、范围与成功上限

本设计交付一个版本化的 V3-M0 仪器，不交付 M3 边界：

1. 关闭旧完整正频支 evaluator 的结构性退化路径；
2. 形式化旧 `ε` 的互补矛盾与 provenance 不可识别性；
3. 从真实实空间 factory 成对测量 actual / matched-ablated 响应；
4. 分别输出 `ε_causal`、`δ_geom`、`σ=(α,A)`；
5. 用 synthetic anchor triangle 和 nuisance controls 认证同一算法；
6. 只为 V3-M1 交付历史 typed-adapter 合同；R30、R23、R25 的实际重测属于 V3-M1；
7. 不在本任务内批准、构造或 pilot 任何新家族。

本轮最高状态为：

```text
READY-V3-M1-ANCHOR-CERTIFICATION
```

它只解锁串行的 V3-M1 旧锚认证，不解锁 family Round 0、30 格 pilot 或正式扫描。

## 1. 路线比较

### 路线 A：只换 Floquet 频带

对当前 Verlet 家族选某个相位簇或 Riesz window，再测主角谱。

优点是改动小；缺点是完整家族确实传播全部 `h` 坐标，频带在端点闭合，且即使选出牙齿也
不能解决 provenance/geometry 混用。只保留为诊断，不作为正式路线。

### 路线 B：只建立双轴仪器

先建立 actual/ablated 双轴 observer、机械 construction trace、冻结响应链与控制矩阵，
在任何新 family 坐标进入视野前证明仪器有牙。

优点是把 observer 病灶与 family 病灶严格分开，且不让某个候选族反向决定阈值、窗口或
坐标语义。代价是 V3-M0 完成后仍须独立通过 V3-M1，才能进入 family 设计。

**裁定：采用。**

### 路线 C：仪器与 family 同时设计

可同时试秩受限 syzygy Hamiltonian 或第一阶 unitary QCA，并以最先出牙者倒推仪器。

该路线会把构造选择、observer 选择和阈值选择重新耦合，无法区分“仪器有牙”与“只对该族
有牙”，故 V3-M0 不采用。syzygy、受控 defect 与 unitary QCA 留待 V3-M2 的独立路线比较；
若最终主张涉及 quantum L4，unitary lane 是必经门，不是可永久搁置的备线。

## 2. 组件边界

### 2.1 `ConstructionTrace`

职责：机械记录 factory 的 primitive DAG，不依赖用户手写 `hand_built=true/false` verdict。

每个 primitive 必含：

```text
grammar_id
target_spec_id
mechanism_id
kind = target_blind | target_conditioned | unclassified
depends_on[]
support_offsets[]
state_channels[]
coefficient_digest
symbolic_origin_tags[]
neutral_ablation
design_objective_tags[]
search_run_id | null
```

传递依赖只要触及以下目标对象，即归为 `target_conditioned`：

```text
C, kerC, inc, TT projector/basis, R30 placed-Yee coefficients,
target N_prop repair operator
```

target-blind grammar 允许：

```text
整数平移、格对称通用混合、与目标无关的局域 canonical shear、
冻结物质 walk primitive、通用质量/色散项
```

trace 由 typed primitive 组合自动生成；runner 不能覆盖其 kind。目标依赖 taint 必须在
系数数值化之前传播，不能只看最终 primitive 类型。历史 R23/R25 适配器把源码中的
`C/κ/placed-Yee/de Donder/Wilson` 来源显式入 trace；把同一系数改写成数值 literal
不会自动获得 target-blind 身份。opaque literal 默认记 `unclassified`，不能靠人工注释
升级为 target-blind。超出冻结 grammar 的来源同样记 `unclassified`，其
`ε_causal` 不可判。最终 trace 必保存 `trace_sha`、源码 SHA、design-time objective/search
provenance；历史 typed adapter 在 V3-M1 使用前须给出与冻结原 factory 的一步核及多步响应
等价证书。

任何 coefficient/parameter 若由读取 `target_spec`、目标方程、目标 projector 或
target-aware loss 的设计、搜索、筛选、人工择优确定，其依赖 taint 必须传播为
`target_conditioned`；数值 literal、缓存、复制或重命名不得洗白。

### 2.2 `MatchedAblationFactory`

输入 actual factory 与 trace，输出成对 factory：

```text
actual(state)
ablated(state)
```

ablated 把全部 target-conditioned primitive 替换为其注册的同接口 neutral identity，保持：

- 相同状态 schema；
- 相同 dtype/backend；
- 相同 `dt`；
- 相同 target-blind 参数；
- 相同层顺序占位；
- 相同源、边界与读出；
- 相同运行长度。

禁止以 `q=0`、另一个 candidate 或重新调参后的 factory 代替 matched ablation。
neutral ablation 只能是该层接口上的恒等作用；“施加 inverse”不是消融。若需证明组合
`S∘S⁻¹` 为恒等，必须由独立组合证书完成。

若 ablated 不可逆、失稳或状态不匹配，本候选的 `ε_causal=undefined`。

### 2.3 `MeasuredResponse`

权威输入来自真实 factory：

1. 在无 wrap 体积对全部 canonical source 通道做单位 delta；
2. 对 actual 与 ablated 分别运行；
3. 收集紧支撑 kernel、运行计量与 SHA；
4. 用独立 plane-wave 生产运行桥接，误差 `≤1e-12`；
5. 运行后用有限和构造 `M(k)`；
6. 以固定 Fejér shell filter 形成 source-coupled response `R(k)`；
7. 用冻结随机多步实空间运行对拍 `M(k)^t`，确认响应不是单步 bridge 的实现伪影。

Fejér filter 是 `M` 的多项式，不挑简并簇内本征向量。窗口中心来自每个 actual candidate 在
主跑前冻结的实际 Floquet shell；actual 与 ablated 使用同一中心与同一 `dt`。对线性
factory，令 canonical source injection 为 `J`、physical-h readout 为 `P_h`：

```text
F_T(M;ω) = (1/Z_T) Σ_{t=0}^{T-1} (1-t/T) exp(-iωt) M^t
R_h(M;k) = P_h F_T(M(k);ω_shell(k)) J
```

`Z_T` 由同一权重和固定。V3-M0 只认证线性切空间响应；非线性有限振幅因果指标另行设计，
不得从本仪器外推。

窗口不得逐 candidate 人工挑选。V3-M0 只在 synthetic controls 上冻结算法；未来 family
使用按物理参数邻接定义、与 `q` 标签及遍历顺序无关的 tracking graph：

1. 在 endpoint control 的预声明物理频段内，以 canonical-source 响应峰初始化；
2. 相邻 cell 选择与已认证邻点 Fejér 响应子空间重叠最大的连续峰；
3. 唯一峰、绝对参与度、相位间隔与 overlap margin 必须同时过线；
4. 每个基本回路从不同路径得到的 shell ID、中心频率与 projector 必须在冻结容差内一致；
5. 交叉、闭隙、并列或路径 holonomy 时返回 `undefined`。

tracking manifest 在任何新 family 坐标输出前写出并哈希；禁止看见 `ε/δ/σ` 后换窗。

Fejér 候选阶数只从冻结升序表

```text
T_candidates = {256,512,1024,2048,4096,8192}
```

选择；`T=16384` 只作为候选 `T=8192` 的 `2T` 稳定性对拍，不是独立候选，因而不要求
未预注册的 `32768` 对拍。频率搜索网格固定为 `2π/(16T)`。每个候选 `T` 必须与下述
信号线、秩谱隙联合冻结，并在所有 controls 上同时满足：

1. 到最近竞争峰的相位间隔 `Δω≥8π/T`；
2. 第一、第二候选的 projector-overlap 分差 `≥0.2`；
3. `T` 与 `2T` 的选中 projector operator-norm 距离 `≤1e-10`；
4. 下述 signal/noise 分离与秩谱隙成立；

才可用；取最小合格 `T`。无合格项则 V3-M0 FAIL，不向上扩表。

曲率读出必须先去除目标算子在 IR 的已知齐次缩放。对当前 spin-2 标定面冻结

```text
ν_inc(k)=khat²=4 Σ_j sin²(k_j/2),  k≠0
R_curv_hat = W_curv inc(k) R_h / ν_inc(k)
```

`k=0` 不进入 rank/标度窗。其他 sector 必须在自己的 `target_spec` 中先验冻结解析
`ν_inc(k)`，不得从候选数据拟合。所有预注册方向与 `L/k` 窗都必须过门，防止合法
`inc(k)~k²` 响应在 IR 被固定有量纲线伪造为降秩。
这里的除法是在 `ν_inc(k)≠0` 的逐点局部化/有理函数域中定义，只表达已知径向阶数；
不声称 `ν_inc` 在 Laurent 多项式环中逐项整除 `inc`。

绝对信号秩线不从新 family 数据调。对白化 `h` 与无量纲 `curv_hat` 两种读出分别用
V3-M0 null/signal/bridge controls 标定。每个 control 在读取数值前必须声明
`expected_rank`；`signal_min,r` 只取该先验秩内的最小有效奇异值，禁止先用
`matrix_rank` 或结果依赖阈值反推 expected rank：

```text
scale_ref,r  = 正响应控制的最大奇异值
null_max,r   = 零响应/禁耦合控制的最大伪信号
bridge_max,r = 重复运行及 realspace↔symbol bridge 的最大差异
noise_ref,r  = max(null_max,r, bridge_max,r, eps_fp64·scale_ref,r)
signal_min,r = 正响应控制的最小有效奇异值
τ_sig,r      = sqrt(noise_ref,r·signal_min,r)
```

`eps_fp64=2^-52`，因此即使 exact null 为零，对数中点仍有定义。`T`、两读出的
`noise_ref/τ_sig` 与秩谱隙是同一次 controls 审计的联合冻结对象，不得先选窗后循环调线，
也不得先调线后换窗。只有两个读出都满足
`signal_min,r/noise_ref,r≥10³` 才冻结；平方 Gram 矩阵使用
`τ_sig,H,r=τ_sig,r²`。无量纲存活阈独立固定为 `τ_surv=0.5`，由 squared canonical
correlation `s≤0.25` 与 `s≥0.75` 的 synthetic angle controls 认证；任一物理 `s_i` 距 `0.5`
小于 `0.1` 时，DOF 计数记 `ambiguous`。几何阈独立继承 `τ_geom=0.05`，只由
`g≤0.025/g≥0.075` synthetic geometry controls 重新认证；`|g-0.05|<0.01` 时几何计数
为 `ambiguous`。目标物理覆盖另用
`τ_cover=0.5`，由 squared projection `c≤0.25/c≥0.75` controls 认证，`|c-0.5|<0.1`
时 coverage verdict 为 `ambiguous`。四类阈值不得共用一套校准。
对任一读出，奇异值 `≤noise_ref,r` 才认证为 null，`≥τ_sig,r` 才认证为 signal；
二者之间是 grey band，返回 `undefined`。曲率 active rank 还须同时满足：未除
`ν_inc(k)` 的 raw singular value 高于 raw bridge noise，且最小 active 与最大 inactive
奇异值之比 `≥10³`；这是“绝对噪声门 + 无量纲秩/相对谱隙”双门。

### 2.4 `CausalSurvival`

`ε_causal` 的主估计对象是“actual 的曲率有效响应 DOF 在 matched ablation 后是否仍由
native 机制张成”，不是 exact transfer waveform 是否逐位不变。对同一 source/readout
规范下的 `R₁,R₀`，均取上述 `R_h`。先按 actual 响应冻结：

令 `G_source,G_h,G_curv` 是相应声明 observer 空间上的冻结 Hermitian 正定 metrics，
`W_h†W_h=G_h`、`W_curv†W_curv=G_curv`；source 先按 `G_source` 白化。若原空间含
metric-null kernel，必须先用冻结 quotient/support map 移除，再在商空间冻结正定 metric；
普通 gauge 方向不自动删除，仍按 `target_spec` 进入几何分解。不能做到则三坐标
`undefined`。所有 SVD、orth 与 projector 均在这些白化坐标内完成：

```text
Q_all          = 冻结的完整 canonical source basis
Q₁             = range_{τ_sig,H,h}(R₁†G_hR₁) 的 source-active basis
Y₁(Q₁)         = W_curv inc R₁Q₁ / ν_inc = U Σ V†
V_curv         = {V_i : Σ_i≥τ_sig,curv_hat 且通过 raw/gap 双门}
Q_curv         = Q₁ V_curv
Y_a            = W_curv inc R_a Q_curv / ν_inc, a∈{1,0}
U_a^c          = orth_{τ_sig,curv_hat}(Y_a)
P_a^c          = U_a^c (U_a^c)†
K_surv         = (U₁^c)† P₀^c U₁^c
K_surv v_i     = s_i v_i
j_surv          = #{s_i≥τ_surv}
ε_causal_DOF    = j_surv/N_curv
ε_causal_cont   = mean_i(s_i)=Re tr(K_surv)/N_curv
```

`s_i∈[0,1]` 定义为相对 actual 维数扩展、补零后的 squared canonical correlations：
标准主角只返回较小秩项时，缺失方向补 `θ=π/2,s=0`。`K_surv` 固定为
`N_curv×N_curv`，所以 ablated 秩亏自动产生零特征值，不能用只返回
`min(rank U₁^c,rank U₀^c)` 项的 SVD 漏掉它们。必须验证
`rank(Y₁)=N_curv>0` 以及 `||(U_a^c)†U_a^c-I||₂≤1e-12`，否则响应链不一致并返回
`undefined`。因果 projector 位于曲率 observer quotient，而不是 `h` 空间；pure-gauge
`h` 分量即使很大，也不能冒充曲率 DOF 存活。
`K_surv` 的 Hermitian residual 必须 `≤1e-12`，随后只用 Hermitian `eigh`；禁止 generic
eig 或先静默对称化再掩盖残差。

因此 `R₁=-R₀`、`R₁=cR₀(c≠0)` 和共同 source/output 等距换基在越过绝对信号门后均给
存活 1，而真正被消融掉的方向给零。这里明确把相位、整体幅值和子空间内基变换商掉；它们
不再冒充“DOF 被删除”。幅值不变性只在线上成立：ablated 在 null 线以下定义为零，落入
null/signal 灰带则 `undefined`。

主存活率有意非对称。为防止 ablation 在 actual-inactive source 上额外张出错误模，另在
完整冻结源域计算：

```text
U₀,all^c = orth_{τ_sig,curv_hat}(W_curv inc R₀Q_all / ν_inc)
P₀,all^c = U₀,all^c (U₀,all^c)†
χ_extra  = 0                                           if rank(U₀,all^c)=0
χ_extra  = 1-Re tr(P₀,all^c P₁^c)/rank(U₀,all^c)      otherwise
```

`χ_extra` 不得只在 `Q_curv` 上计算。物理正锚必须达到 §6.1 的存活/extra 数值裕度，并由
§2.5 的独立 unary 链证明 ablated 几何、标度与该 sector 必需的映射/色散门合格。
`U₀,all^c` 的每个 active mode 还必须通过与主曲率链相同的 raw-noise/relative-gap 双门。

exact source→curvature-response 映射变化只作辅助诊断。若 `Y₀≠0`，冻结单个复标量
Procrustes：

```text
c_*        = tr(Y₀†Y₁)/||Y₀||_F²
κ_map      = |tr(Y₀†Y₁)|²/(||Y₀||_F²||Y₁||_F²)
d_proc²    = 1-κ_map
gain_ratio = ||Y₀||_F/||Y₁||_F
phase_shift= arg(c_*)
```

不允许事后拟合完整 output unitary。旧 raw transfer-difference pencil 被相位翻转和纯增益
反例击穿，不进入 v3 schema。synthetic controls 必含相位翻转、纯幅值重标、可逆非标量
内部混合、构造/破坏性干涉、正交错误空间与真正缺模，证明主存活谱、`χ_extra` 和
Procrustes 辅报回答不同问题。

若预注册包含多个 shell block，只允许按实际 DOF 直和聚合：

```text
ε_cont = Σ_b Re tr(K_surv,b) / Σ_b N_curv,b
ε_DOF  = Σ_b j_surv,b      / Σ_b N_curv,b
```

任一必需 block 为 `undefined`，总坐标也为 `undefined`，不得静默丢块或等权平均各 shell。

### 2.5 `GeometricDistance`

冻结唯一数据链：

```text
canonical sources + source metric
  → deterministic Fejér window
  → Q₁(actual source-active)
  → W_h R_h Q₁ 的绝对 physical-h signal gate
  → W_curv inc(R_h Q₁)/ν_inc(k) 的 curvature SVD/rank 与 V_curv
  → Q_curv=Q₁V_curv
  → S_curv=orth(W_h R_h Q_curv), P_curv=S_curv S_curv†
```

`N_response=rank(W_hR_h)`，`N_curv=rank(W_curv inc R_hQ₁/ν_inc)`，二者允许不同并各自
保存。令 `U_K=orth(W_h ker C)`、`P_K=U_KU_K†`。另冻结 target-specific gauge quotient
map `Π_phys:h→h/Gauge`、商空间正定 metric `W_phys`，以及白化坐标中的
`Π_phys^w=W_phys Π_phys W_h^{-1}`。将 actual 子空间先商掉 gauge 再重正交：

```text
g_i = singular_values((I-P_K)S_curv), i=1..N_curv
S_phys = orth(Π_phys^w S_curv)
P_phys = S_phys S_phys†
U_T = orth(W_phys Π_phys T_phys_representatives)
K_cover = U_T† P_phys U_T
c_i = eigenvalues(K_cover), i=1..dim(T_phys)
N_cover = #{c_i≥τ_cover}
coverage_phys = N_cover/dim(T_phys)
rank_deficit = dim(T_phys)-N_cover
```

输出：

- 全 `g_i` 与 `c_i`；
- `δ_geom_DOF`；
- `δ_geom_E`；
- max/RMS/Frobenius；
- `N_curv`；
- `coverage_phys` 与 `rank_deficit`；
- 绝对参与度与秩谱隙；
- 三次简并簇内共同酉旋转漂移。

`g_i` 等价于相对 actual `S_curv` 的扩展主角正弦；其长度固定为 `N_curv`，非法方向不会因
标准 principal-angle API 只返回较小维数而漏掉。`c_i` 使用 `τ_cover` 与 grey band，
禁止调用默认 `matrix_rank`；`K_cover` 同样须先过 Hermitian residual 再用 `eigh`。
coverage 不得直接使用 full-`h` 的 `P_curv`：`t+ag` 与 `t` 在 gauge quotient 中必须给
同一 `c` 谱。

`δ_geom_DOF=0` 但 `rank_deficit>0` 时是“无泄漏但缺模”，不得记几何 PASS。对 spin 2，
`T_phys` 固定为 TT/gauge quotient 的物理二维代表，不以整个六维 `ker C` 代替。
`δ_geom` 与 `ε_causal` 必须共享同一个 response manifest ID、`Q₁`、`Q_curv`、
`S_curv` 与 source metric。

该 evaluator 是 unary：对 `R₁` 输出 actual `δ_geom¹,rank_deficit¹,σ¹`；对 `R₀` 必须从
完整 `Q_all` 独立重建自己的 `Q₀,Q_curv⁰,S_curv⁰`，输出
`δ_geom⁰,rank_deficit⁰,σ⁰`，不得复用 actual 的 `Q_curv` 隐藏 ablation 新生源方向。
`ε_causal` 本身只宣称 DOF 子空间存活；任何物理正锚或 L4 因果定律主张还必须让 ablated
通过其适用的映射、色散、源、守恒与稳定闭环门。

### 2.6 `SigmaFit`

沿 R37 协议读取同一 `S_curv` 的唯一冻结主观测量
`y(k)=max_i g_i`；`rms(g_i)` 只辅报。保存：

- 常数/幂律两个模型；
- `A,α,σ_A,σ_α,ΔAIC`；
- LOO；
- 拟合窗、扩窗与方向；
- `alpha_identifiable`。

常数模型胜出、谱饱和或 LOO 非有限时，`α=null`。

对带随机/采样噪声的级数，保留 R37 的 `|A|≤2σ_A`。对本项目默认的无噪声确定性级数，
该统计排零线不适用，必须执行已生效的 D-M2-6 截断稳健双测：

1. 在 R37 同一冻结 `α=0.05..4.00/0.01` 网格全重拟合
   `y=A′+Bk^α+Ck^(α+2)`；只有 `ΔAIC(power-high)≥2` 且
   `|A′|≤|A|/5` 才判高阶截断污染；
2. 半窗采用已由双控制选定的 H3：删除最大 `k` 点、保留三个最小 `k` 点并全网格重拟合；
   只有 `|A_half|≤|A|/2` 才判半窗塌缩；
3. 两测同判污染，且 synthetic clean-zero / true-floor 双控制均判对，才允许写
   “`A` 与零一致”；任一不满足则有限底维持，不以 `σ_A` 通融。

### 5.4 表示不变量

- layer split/merge；
- 插入 `S S⁻¹`；
- 重排可交换层；
- 保持物理邻接图不变的 q label 置换；
- `G_source` 同步协变的共同 source 等距换基；
- `G_h,inc,G_curv,Π_phys,G_phys` 与目标子空间全部同步协变的共同 readout 等距换基；
- 相对相位翻转与越过绝对门的整体非零幅值重标；
- 仅当 physical metric、source metric 与目标子空间同步协变时的局域 canonical 换基；
- 两个无 wrap 体积的同一支撑。

不变量指 `K_surv` 的 eigenvalue multiset、trace 与阈值计数；基变化下矩阵本身只要求酉
相似，不要求逐项相等。`s`/主角谱的漂移门为 `≤1e-12`，且预期漂移必须由 controls
证明远离判别线。
Procrustes gain/phase 对 actual/ablated 的相对幅值或相位本来就可变，不列为主轴不变量。

## 6. 串行交接边界

### 6.1 V3-M1 的有限合同

5. 新增搜索预算只能由另一份预注册补丁授权。

`PHYSICAL-CAUSAL-ANCHOR-PASS` 当且仅当：

1. actual/ablated 的全部预注册 shell block 均 defined，response/rank/threshold margin 全过；
2. `ε_causal_DOF=1`、`min_i s_i≥0.99`、`ε_causal_cont≥0.99`；
3. `χ_extra≤τ_extra`，其中
   `projector_bridge_max` 是 repeatability、realspace↔symbol 与表示不变量 controls 的最大
   projector operator-norm 漂移，`τ_extra=max(1e-10,100·projector_bridge_max)`；
   extra-mode 负控须至少在其外 `10³` 倍；
4. actual 与 ablated 均满足 `δ_geom_DOF=0,max g_i≤0.025`，
   `rank_deficit=0,min c_i≥0.99`；
5. actual 与 ablated 的 `σ` 均按 deterministic/noisy 对应协议排零；
6. 该 sector 冻结的映射、色散、源、守恒、稳定与闭环门在 actual/ablated 两支均 PASS。

因此这里的“正锚”不是浮点精确等式，也不以仅存活同一个 span 代替目标定律闭环。

V3-M1 全过的最高状态为 `READY-V3-FAMILY-DESIGN`。

### 6.2 V3-M2 的非约束性候选

本设计**不批准任何新 family**。后续独立设计至少比较：

- 受控 defect 的 classical-symplectic 插值；
- 只把 exact syzygy 用作目标端点的秩受限 Hamiltonian；
- 第一阶 unitary QCA。

任务书中重新比较与冻结。
