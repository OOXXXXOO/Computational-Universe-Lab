# v3 裁定：从单 `ε` 到因果可识别双轴

*Computational Universe Lab · 2026-07-30 · 状态：PI 签发，已生效*

## 0. 裁定

PI 已于 2026-07-30 授权：确认北极星无漂移后签发并开工。经 v1/v2/v3 逐条对照与独立
审计，v3 保留量子酉 QCA 本体主线、严格局域、固定 3+1D 标定面、多 target 分栏、
L4 非孤点与双车道终审，不翻案历史结论。签发前已封闭 target-aware 搜索洗白和冗余
target 编码冒充 L4 两个语义接口，审计结论为 `PASS`。

现裁定结束 v2 单 `ε` 口径的继续实现，建立 v3：

```text
(ε, σ)  →  (ε_causal, δ_geom, σ)
```

理由不是 M3′ pilot 没有得到想要的数，而是同一代码库中的 `ε` 已不再指向同一个估计对象。
继续沿 v2 改正频支或改构造参数，即使得到“牙齿”，也不能说明横轴究竟测到了因果涌现、
最小修复成本还是约束兼容度。

## 1. 决定性证据

### 1.1 两条公式在同输入下严格互补

M0′、冻结 walk 整改口径与 M3′ pilot 使用：

```text
j_out = #{sin θ_i(S_curv, ker C) ≥ 0.05}
ε_A   = 1 - j_out/N
```

M2 的 R30 实测路径使用：

```text
j_hand = N - j_out
ε_B    = 1 - j_hand/N = j_out/N
```

所以对任意 `0≤j_out≤N`：

```text
ε_A + ε_B = 1
```

这是公式级矛盾：M0/M3 与 M2 的实际模选择还不完全相同，不能把两条历史流水线的任意
输出逐位直接相加；但只要喂入同一个 `S_curv,j_out,N`，语义必然反转。

若 `S_curv⊂ker C`，`ε_A=1` 而 `ε_B=0`；若 `S_curv⊥ker C`，两者反转。当前 M3′ pilot
的主角正弦谱为机器精度下的：

```text
(0, 0, 1, 1, 1, 1)
```

因此 M3 口径给 `1/3`，M2 口径会给 `2/3`。两者都不是浮点误差。

### 1.2 完整正频支存在条件性 observer-collapse

当前 M3′ 家族是 14 坐标的稳定二阶 Hamiltonian/Verlet 系统。evaluator 选取全部正频模，
再把它们投影到 `h[10]` 并取 span。对这一类系统，正频正常模的 `h` 投影张满
`C^10`。满张本身只推出输出侧
`range(inc∘B_h)=range(inc)`；它不无条件固定把非零右奇异支撑经 `B_h` 映回后的
`h` 子空间。完整修正见
`v3-勘误-observer-collapse-coisometry-2026-07-30.md`。

当前 evaluator 在 full rank 时先把 `raw_h` 正交化成 `10×10` 方阵，故在冻结白化
metric 下满足 `B_hB_h†=I_h`。再加上完整选择 `inc∘B_h` 的非零右奇异支撑、
`rank inc=6`、`Gauge=ker inc`、`TT₂⊕Gauge₄⊕Row₄` 正交分解和
`ker C=TT⊕Gauge`，才有条件链：

```text
(q, κ_C)
  → span(B_h⁺)=C^10
  → B_h B_h†=I_h                         [冻结白化/正交化桥]
  → range(B_h (inc B_h)†)=range(inc†)   [完整非零谱选择]
  → S_curv=range(inc†)
  → sin²θ=(0,0,1,1,1,1)
```

所以 30 格均实测 `N_curv=6`、`j=4` 与常数 `max sin θ=1`，并且在上述冻结条件下是
条件性结构事实。30 个 kernel SHA 全部不同，说明动力学并非逐位相同；被商掉的是极化与
权重信息。不得再把这一结论表述为任意满射 `B_h` 下的无条件结构必然。

### 1.3 构造来源对黑箱 observer 不可识别

若 observer 只有最终转移算子 `M`：

```text
obs : M → value
```

那么两个 construction history 只要产生相同 `M`，observer 必给相同值。它不可能同时把
“直接手搭的 R30”判为因果涌现度 0，又把“由 target-blind 规则搜索偶然产生的同一算子”
判为 1。

所以 provenance-sensitive 指标必须显式包含冻结构造 grammar 与干预；它不能从
`M(k)` 单独恢复。

## 3. v3 三坐标

### 3.1 因果涌现度 `ε_causal`

每个候选必须给出同一 factory 产生的成对规则：

```text
M₁：actual
M₀：只消融 target-conditioned 生成元的 matched counterfactual
```

两者保持同状态空间、同 `dt`、同 target-blind 参数、同源、同读出与同运行协议。由真实
实空间冲激得到响应矩阵 `R₁,R₀`。先用绝对信号线取 actual 的 source-active 子空间
`Q₁`，再对 `inc R₁Q₁` 作曲率 SVD，得到实际曲率有效源空间 `Q_curv` 与
`Y_a=W_curv inc R_aQ_curv/ν_inc(k)`。其中 `W_curv†W_curv=G_curv` 是声明 curvature
observer quotient 上冻结的 Hermitian 正定 metric 白化因子；metric-null 方向必须先由
冻结 quotient 移除，普通 gauge 方向不自动删除。`ν_inc(k)` 去除目标曲率算子已知的 IR
齐次缩放，spin 2 使用 `4Σ_j sin²(k_j/2)`。令
`U_a^c=orth(Y_a),P_a^c=U_a^c(U_a^c)†`：

```text
K_surv = (U₁^c)†P₀^cU₁^c
s_i = eigenvalues(K_surv) = 扩展并补零的 cos²θ_i
j_surv = #{s_i ≥ τ_surv}
ε_causal_DOF  = j_surv/N_curv
ε_causal_cont = mean_i(s_i)
```

主坐标因此测量“actual 曲率有效 DOF 在 ablation 后的子空间存活”，而不是 exact transfer
waveform 的逐位一致。它显式商掉相位、整体非零幅值与子空间内基变换：
`R₁=-R₀` 或 `R₁=cR₀(c≠0)` 在信号门以上都给存活 1；真正被消融掉的方向补零。
`ε_causal_cont=Re tr(P₁^cP₀^c)/N_curv`。`K_surv` 的维数固定为 `N_curv`，不可用只返回
较小秩个数的 SVD 漏掉 ablated 秩亏所产生的零。

由于主率有意只问 actual DOF 的存活，另在完整冻结 source domain `Q_all` 报 ablation
新增错误模：

```text
P₀,all^c = projector(range_{τ_sig,curv_hat}(W_curv inc R₀Q_all/ν_inc))
χ_extra = 0                                                   if rank(P₀,all^c)=0
χ_extra = 1-Re tr(P₀,all^cP₁^c)/rank(P₀,all^c)               otherwise
```

它不能只在 `Q_curv` 上算，否则会漏掉 ablation 从 actual-inactive source 新生的错误模；
其 active modes 同过 raw-noise/relative-gap 双门。
source→curvature-response 映射保真只用单个复标量 Procrustes 辅报
`κ_map,d_proc,gain_ratio,phase_shift`；不允许事后拟合完整 output unitary。原 raw
transfer-difference pencil 被相位翻转和纯增益反例击穿，v3 拒绝使用。actual 无曲率有效
响应、反事实失稳、秩/存活谱隙不足或 trace 未分类时返回 `undefined`，禁止代填。
`ε_causal` 单独只宣称 DOF 子空间存活；物理因果正锚和 L4 还要求 ablated 独立通过几何、
标度、映射、色散及适用闭环门。

### 3.2 几何距离 `δ_geom`

在同一个响应限定的传播—曲率子空间正交基 `S_curv` 上，令 `P_K` 是白化
`ker C` projector。另以冻结 `Π_phys:h→h/Gauge` 和商空间正定 metric 将
`S_curv` 商掉 gauge 后重正交成 `S_phys`，令 `P_phys=S_physS_phys†`、`U_T` 是
`T_phys` 的 quotient 正交基：

```text
g_i        = singular_values((I-P_K)S_curv), i=1..N_curv
δ_geom_DOF = #{g_i ≥ τ_geom}/N_curv
δ_geom_E   = sqrt(mean_i g_i²)
K_cover    = U_T†P_physU_T
c_i        = eigenvalues(K_cover), i=1..dim(T_phys)
N_cover    = #{c_i≥τ_cover}
coverage_phys = N_cover/dim(T_phys)
rank_deficit  = dim(T_phys)-N_cover
```

`g_i` 是相对 actual 维数的单侧扩展主角正弦，避免标准 API 只返回较小维数而漏掉非法方向；
`c_i` 用独立冻结阈值和 ambiguity band，禁止默认数值秩。全谱、最大值、RMS、Frobenius
泄漏、目标覆盖与谱隙全部入册。只有
`δ_geom=0` **且** `rank_deficit=0` 才表示目标物理扇区既不泄漏又不缺模；低秩零子空间不能
冒充完美几何。对 spin 2，`T_phys` 是冻结的 TT/gauge quotient 物理二维空间，不以整个
六维 `ker C` 代替。几何读数不说明响应是如何产生的。actual 与 ablated 都必须从完整
canonical source domain 独立运行同一 unary geometry/coverage/σ 链，不能让 ablated
复用 actual 的 active source selector。
coverage 只在 quotient projector `P_phys` 上计算；`t+ag` 与 `t` 必须给同一 `c` 谱。

### 3.3 约束标度 `σ=(α,A)`

R37 的双模型、AIC、LOO 与极限窗纪律继续继承，但输入必须与 `ε_causal/δ_geom` 使用同一个
source-qualified 响应子空间。常数模型胜出时 `α=undefined`，不得保留有限网格落点作解释。
无噪声确定性级数必须继承 D-M2-6：高阶 `k^(α+2)` 模型同时满足
`ΔAIC≥2, |A′|≤|A|/5`，且删除最大 `k` 点的 H3 半窗满足
`|A_half|≤|A|/2`，两测同判并先过 clean-zero/true-floor 双控制才可排零；有噪声级数才使用
`|A|≤2σ_A`。

## 4. V3-M1 旧锚重测面

v3 不继承旧的因果端点标签。R23 源码本身明确构造 Maxwell/Lorenz/Yee 对象，R25 也显式
使用 de Donder/Wilson 目标结构；它们可以继续充当几何与流水线控制，但不能在 construction
trace 之前预填 `ε_causal=1`。

| 旧对象 | `ε_causal` 处理 | `δ_geom` 预期 | v3 身份 |
|---|---|---:|---|
| R30 手搭复形 | 由 trace + ablation 实测；假设为低，不代填 | 0 | target-aware 几何正控 |
| R23 Yee/Maxwell | 由 trace + ablation 实测；不再继承旧值 1 | 0 | Maxwell 几何/流水线正控 |
| frozen R25 walk | 由 trace + ablation 实测；不再继承旧区间 | 旧计数的互补范围 `[0.5,0.75]`，全连续谱逐位对拍 | 构造—几何混合历史控 |

因果端点改由无歧义的 synthetic controls 冻结：

| synthetic control | `ε_causal` | `δ_geom` |
|---|---:|---:|
| 先生成 target-blind rank-`N` 响应、再以 hold-out span 冻结 synthetic target | 1 | 0 |
| 全 target-conditioned 且完全合法的 rank-`N` 响应 | 0 | 0 |
| 两者 rank 相等的直和 | 1/2 | 0 |

现阶段仓库中**没有已由成对因果运行认证的
物理正锚**。正锚布尔门要求：全部 block defined；`ε_causal_DOF=1`、
`min s_i≥0.99`、`ε_causal_cont≥0.99`；
`χ_extra≤max(1e-10,100·projector_bridge_max)`；actual/ablated
均有 `δ_geom_DOF=0,max g_i≤0.025,rank_deficit=0,min c_i≥0.99`；两支 `σ` 排零且适用的
映射、色散、源、守恒、稳定/闭环门全过。V3-M1 的任务之一正是
从现有资产中寻找并认证它；在此之前不得把 R23 的旧元数据当作替代。该审计必须先冻结
仓库内 eligible asset 的有限清单、SHA、顺序与总预算，不新增候选、不循环调参；清单耗尽
仍无锚则返回 `HALT-V3M1-NO-PHYSICAL-CAUSAL-ANCHOR`，阻止 V3-M2 与 L2–L4。扩展搜索须
另行预注册。

## 5. 触发与停手

以下任一项失败，V3-M0 停手：

- construction grammar 不能机械区分 target-blind / target-conditioned；
- 分层、合并、插入恒等层、相位/非零幅值 nuisance 或共同酉/等距换基改变主 `s` 谱；
  一般 canonical 换基只有在
  physical metric 与目标子空间同步协变时才可比较；
- actual/ablated 不能同时以真实严格局域 factory 运行；
- synthetic anchor triangle 不能由同一算法处理；
- 响应信号地板无至少 `10³` 的有量纲 signal/null 分离，或无量纲
  `τ_surv=0.5` / `τ_geom=0.05` / `τ_cover=0.5` 各自无冻结控制裕度；
- `ν_inc(k)` 归一化与 raw-noise/relative-gap 双门不能在全部预注册 `L/k` 窗保持合法秩；
- 冻结 Fejér 阶数表中没有同时满足峰分离、`T→2T` 稳定与 bridge 的项；
- `ε_causal` 与 `δ_geom` 使用了不同的模、源或窗口；
- ablated 的 full-source unary geometry/σ 链无法执行。

失败不得通过 relabel mechanism、改阈值或只挑一个方向恢复。

## 6. 主张上限

v3 只把观测对象分清，不自动增强任何物理主张。V3-M0 的最高主张为 L0 仪器级，最高状态
仅为 `READY-V3-M1-ANCHOR-CERTIFICATION`；R30/R23/R25 的成对重测与有限物理正锚审计属于
V3-M1。30 格 pilot 的最高主张为“存在可识别坐标变化”；只有另行预注册的
`10²–10³` 正式扫描
才能形成边界级主张。

本裁定不翻案 v1，不把 v2 M3′ 记为物理失败，也不恢复“GR 已涌现”。

## 7. 签发权限与唯一解锁

本裁定只解锁 V3-M0 仪器迁移。V3-M0 最高状态是
`READY-V3-M1-ANCHOR-CERTIFICATION`；R30/R23/R25 物理重测、新 family、Round 0、
30 格 pilot、`10²–10³` 扫描与 GPU 长跑均继续锁定，须由后续串行任务书另行签发。
L4 恢复仍保留双车道对抗复核与 PI 终审，不因本次范式签发自动获得。
