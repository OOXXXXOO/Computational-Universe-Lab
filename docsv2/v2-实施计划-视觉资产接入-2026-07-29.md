# Computational Universe Lab 视觉资产接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将用户已生成的 Logo 与 repo cover 接为正式资产，并让当前入口文档、v2 仪表及代理说明共享同一套可审计视觉标准。

**Architecture:** 正式位图只在 `visualizations/assets/` 保留一份权威文件；Markdown 与仪表按相对路径引用，不复制二进制。冻结的 v1 `docs/` 证据链不批量改写，当前入口和 v2 活跃表面更新品牌层级。生成脚本改为 legacy 输出，避免未来误覆盖正式 cover。

**Tech Stack:** Markdown、HTML/CSS、Python/Pillow 资产探针、Git。

### Task 1: 安装正式二进制资产

**Files:**
- Create: `visualizations/assets/logo.png`
- Modify: `visualizations/assets/repo_cover.png`
- Modify: `.gitignore`

- [ ] **Step 1: 验证用户资产尺寸、色彩模式和画幅**

Run:

```bash
.venv/bin/python - <<'PY'
from PIL import Image
for path in ("logo.png", "repo cover.png"):
    im = Image.open(path)
    print(path, im.size, im.mode, round(im.width / im.height, 3))
PY
```

Expected: `logo.png` 为 `2172×724 RGB 3.0`；`repo cover.png` 为 `1774×887 RGB 2.0`。

- [ ] **Step 2: 移入唯一权威资产路径**

Run:

```bash
mv logo.png visualizations/assets/logo.png
mv "repo cover.png" visualizations/assets/repo_cover.png
```

Expected: 根目录不再有同名副本，两个目标文件可由 Pillow 打开。

- [ ] **Step 3: 忽略本地视觉伴随工具运行态**

在 `.gitignore` 追加：

```gitignore
# Local visual companion runtime
.superpowers/
```

- [ ] **Step 4: 提交资产**

```bash
git add .gitignore visualizations/assets/logo.png visualizations/assets/repo_cover.png
git commit -m "接入 Computational Universe Lab 正式视觉资产"
```
