# v2 审定:M2′ 任务书(车道A 终审,2026-07-27)—— 批准框架,附六条修订后签发

*承 `v2-任务书草案-M2-自旋2耦合闭环.md` 与 M1′ 收口(7466d44/15469d5,D2 串行硬门
解除)。审定结论:**草案框架批准;下列六条修订编入终稿后即视为签发**,终稿与草案的
diff 仅限本件条款;lane B 编稿入库(`v2-任务书-M2-自旋2耦合闭环.md`)后轮 1 开工。*

## 一、三个审定重点的判定

1. **G6 分层归纳版(§3 M2-G6):批准,加一道牙。** 单层不等式 + 层间引理 + σ 双分支
   预写(无源段 A=0 精确线 / 有源段 D3 干净档,弱档 FAIL 不通融)忠实落实了改革。
   缺的一道:**ρ 的预言值**——ρ<1 是单边阈,物理预期值必须先行声明(修订 R1)。
2. **边界骑线禁令全表核查:草案先于禁令写就,全表裕度声明缺位。** 逐门逐炮扫过:
   多数判据裕度充裕(锥外 1e-12 vs 实测位级零;C4 预期 0.23 vs 线 1e-12;G1 断崖
   0.79/1e-15 vs 0.05),但**必须成表入册**;两处需要特别处理:G6 的 ρ(见 R1)与
   带型判据的禁令适用口径(见 R2)。
3. **R36 死锁规避论证(§2.3):批准,补一个新风险的哨兵。** 单向源耦合 + 测试场
   读数在结构上同 R26 块三角(v1 已证稳定型),死锁哨兵设计正确。但单向受迫系统有
   一个 v1 未曾遭遇的**新风险:受迫共振/秒差增长**——源以几何带内频率持续驱动导致
   场范数超线性增长,谱半径(齐次稳定性)对它是盲的。补哨兵(修订 R3)。

## 二、六条修订(编入终稿,逐条落位)

- **R1(G6 加牙)**:构造冻结时,由符号分析/预飞标定给出**单层压缩比 ρ 的预言值**
  与推导,写死在 `v2m2_coupled_loop.py` 脚本头(同 T_cross 纪律:先算后跑);
  预言 ρ 对 1 的分离须 ≥1.5×(即 ρ_pred ≤ 0.67)或给出分离论证;实测 ρ 落预言
  ±30% 方计该列 PASS。b_layer 同理声明预期量级(机器底)与线。
- **R2(裕度声明表,禁令首次全表执行)**:`v2m2_coupled_loop.py` 与 `v2m2_guns.py`
  脚本头各含 `margin_declarations` 全表——**每门每炮**一行:预期信号值(或带型判据
  的预期测量散布)、阈值/带宽、裕度、依据。适用口径写死:**单边阈**要求预期值与阈
  分离 ≥1.5×;**带型判据**(如 2.00±0.02)要求预期测量散布 ≪ 半带宽(声明依据,
  如 v1 实测 2.000000);零裕度判据在预飞阶段拦截重设计(M1′ P0(a) 先例)。
- **R3(受迫共振哨兵)**:M2-G7 增列——有源段场范数增长须有界于**线性包络**
  (稳态辐射 + 传播);超线性增长 = FAIL 走追因。候选证书增"无 Cherenkov 相配"
  声明:源速上限明确为 **v/c ≤ 0.5(即格点单位 v ≤ 0.25,c=cos θ_g=0.5)**,
  亚声速于几何锥,无相位匹配增长通道——草案 "v≤0.5c" 的歧义(0.5c vs 0.5 格点
  单位)就此钉死。
- **R4(D-M2-1 裁定)**:基线物质载体 = **v1 冻结走行物质半**(I 类资产,证书链
  最全;其他局域酉 Dirac 载体归 M3′ 族参数,不进 M2′)。单向 + 测试场基线批准;
  双向反作用探测项:预算 ≤ 单轮计算时间 10%、哨兵必备、任何不稳即停,结果只入册
  不进判定。
- **R5(D-M2-5 裁定,哨兵定量线)**:(i) 基线段任何 BZ 超增长 >1e-9 = G7 FAIL
  (与门同线,无另设);(ii) 双向探测段:η 与 2η 两点超增长比 ∈ [3.2, 4.8]
  (∝η² 指纹 ±20%)**且**绝对超增长 >1e-12 → 死锁指纹判定,立即停手走 §6 封存式
  追因;两条件缺一不判(防噪声底误触发)。
- **R6(D-M2-2/D-M2-3 机制裁定)**:候选证书(交付物 2)增布尔字段
  `trace_row_processing_present`;构造冻结时该字段自动裁定 T 行三元组升炮/记名退役
  (条件写入 `v2m2_guns.py` 头,同滞后阻尼炮先例)。G2/G3 收敛阶 p 于**构造冻结
  时点**由符号分析预注册写死(主跑前;签发不阻塞)——构造冻结即 M2′ 的"预言时点",
  R1 的 ρ 预言同批交付。

**D-M2-4(判据 k 集)**:按草案名单批准为终版(3 轴向 + 面斜 + 棱斜 + 体对角必含 +
Nyquist,n 随 L 重标),只许收紧。
