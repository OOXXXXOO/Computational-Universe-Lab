*状态：执行设计，依 PI 指令“直接开始做”与既有自审授权生效。承
`v2-任务书-M3-涌现边界制图.md` 的 Round 0 家族准入门。本件只设计 H0 家族与重新准入，
不把构造旋钮代填为测量坐标，也不预判 30 格 pilot。*

## 1. 方案裁定

审计后保留三种路线：

| 路线 | 内容 | 裁定 |
|---|---|---|
| A | 在 R25 保守 walk 刚度与 R30 Yee 刚度之间，用四个显式局域 canonical kick shear 建同状态空间族；约束端用保守辅助波耦合 | **采用**：同时复用冻结实空间基元、保持严格局域与辛性 |
| B | 新建速度通道量子 lattice-gas / QW，再从它重建张量复形 | 不采用：酉性直接，但会切断现有 R30/M2 evaluator 与证书链 |
| C | 截断 `P_kerC(k)` 或把 RC3-(ii) R2 逆 FFT 成有限核 | 禁止：仍以逐 `k` 投影定义时间步，且支撑随截断/体积变化 |

路线 A 不声称复现 RC3-(ii) 的逐模 partial Yee 操作。它交付的是一个新的、可执行的严格
局域构造族；两者只共享“从 frozen-walk 端向 R30 端移动”的研究方向。新族的 `ε_geo`
必须在 pilot 中重新测量。

## 2. 统一状态空间

所有 `q∈{0,1,2,3,4}` 与全部 `κ_C` 共用：

```text
X = (h[10], p_h[10], ζ[4], p_ζ[4])
```

每个分量定义在同一个三维周期格点上。`h` 是 packed 对称 `h_{μν}`；`ζ_ν` 是四个辅助
约束波通道。总计 14 个 canonical 坐标和 14 个 canonical 动量。任何 `q` 都不删通道、
不换 basis、不使用从属变量消元。

正式 factory 接口：

```python
realspace_step_factory(q: int, kappa_c: float) -> LocalFamilyStep
step(state: LocalFamilyState) -> LocalFamilyState
```

factory 返回的对象只调用 `np.roll`、逐点线性组合和冻结的 R25 walk 卷积基元；运行路径不调用
FFT，也不读取 `k`。

## 3. 几何端：四个显式局域 counter-kick

定义两个实空间自伴刚度：

```text
A_walk = r25_realspace_step.aw_op
A_R30  = c²(-Δ),  c=cos(π/3)=1/2
ΔA     = A_R30 - A_walk
```

冻结探针已经测得 `A_walk` 的 fp64 adjoint residual 为 `3.22e-16`，Chebyshev 支撑半径为
3；`A_R30` 半径为 1。因此 `ΔA` 半径为 3，与 `L` 无关。

把 `ΔA/4` 写成四个有名字的 canonical momentum kick：

```text
counter_1, counter_2, counter_3, counter_4
```

`q` 只控制前缀：

```text
A_q = A_walk + Σ_{r=1..q} ΔA/4
```

每个 half-kick 都是 `p_h ← p_h - (dt_q/2) force(h)`；四层虽然共享同一个局域生成元，
但在实现、描述符与审计记录中逐层列名，禁止把 `q` 直接解释成 `ε_geo`。

端点语义：

- `q=0`：冻结 walk 的保守自由刚度骨架，不包含 R25 的耗散 `μK†K`；
- `q=4`：R30 placed-Yee 刚度端点；
- `q=1…3`：严格局域的四分之一 counter-kick 前缀。

## 4. 约束端：保守辅助波耦合

现有 R26 `p_ζ←(1-κ)p_ζ-Sζ` 在 `κ>0` 时行列式为 `1-κ`，不能进入要求辛性
`≤1e-12` 的 H0 核心族。它继续作为历史清除/开放边界资产保留，但本族不调用该阻尼项。

本族采用 Hamiltonian potential：

```text
V_q,κ(h,ζ)
 = 1/2 <h,A_q h>
 + 1/2 <ζ,Sζ>
 + κ_C <ζ,C_sp h>

S = c²(-Δ)
```

`C_sp` 是 placed spatial de-Donder 行，只含半径 1 的前向差分；`C_sp†` 由同一 packed
tensor 系数表和差分伴随生成。一次 potential kick 同时执行：

```text
p_h ← p_h - τ(A_q h + κ_C C_sp† ζ)
p_ζ ← p_ζ - τ(Sζ + κ_C C_sp h)
```

交叉块严格使用 `C_sp/C_sp†`，所以 potential Hessian 自伴。`κ_C` 在 H0 中是“约束波
保守耦合强度”，不是阻尼率。它是否降低实测 `σ=(α,A)` 由 pilot 决定；不能因名字含
“清除”而预设有效。

## 5. 宏步与实际 Floquet shell 重调参

每个宏步使用对称 Störmer–Verlet：

```text
half potential kicks:
  base_walk + counter_1..counter_q + constraint coupling
full canonical drift:
  h ← h + dt_q p_h
  ζ ← ζ + dt_q p_ζ
reverse half potential kicks at new coordinates
```

所有层都是局域 canonical shear，故组合在精确算术中辛。两次半 kick 会把宏步最大支撑扩到
半径 6；准入证书必须在至少两个无 wrap 的体积 `L=17,21` 上由 delta response 实测并确认
相同。

`dt_q` 不从 continuum 公式手填。冻结参考壳为：

```text
L_ref = 32
k_ref = (2π/L_ref, 0, 0)
ω_target = r15_walk_dedonder.shell_omega(k_ref, c=1/2)
```

对实际 `A_q(k_ref)` 解：

```text
cos ω_target = 1 - dt_q² A_q(k_ref)/2
```

所得五个 `dt_q` 在主跑前写入证书；预探针给出约
`[0.99986659,0.99989994,0.99993329,0.99996664,1.0]`。正式值必须由实现重新计算，
不得复制这组近似数。

## 6. Round 0 实测证书

新模块 `rulespace_v2/m3_local_family.py` 交付：

1. `LocalFamilyState` 与 `LocalFamilyStep`；
2. `realspace_step_factory(q, kappa_c)`；
3. `C_sp/C_sp†` 的随机 adjoint probe；
4. 两体积 delta-response 支撑半径；
5. 全 `5×6` 构造表上的小规模 fp64 辛证书；
6. 实际 Floquet 壳 `dt_q` 与频率残差；
7. 同状态 schema、无 FFT/逐 `k` 运行路径的描述符。

辛证书采用两层证据：

- 结构证据：每一层是由自伴 potential 或 canonical drift 生成的 shear；
- 数值证据：在冻结的轴/面/体和 UV 样本上构造实际平移不变符号的实表示，测
  `max ||MᵀJM-J||∞ ≤ 1e-12`；同时检查势能块 Hermitian defect 和稳定带
  `max |||λ|-1||`。

Fourier/symbol 只用于离线证书，绝不进入 `LocalFamilyStep.__call__`。

## 8. 测试与停手条件

测试先行覆盖：

- 四个 `q` 前缀加端点等式；
- 全 `q,κ_C` 状态 shape/dtype 不变；
- `C_sp/C_sp†` adjoint；
- factory 直接可调用；
- 不可解析 factory、注入测量坐标、逐 `k` 标志仍被准入器拒绝；
- 两体积支撑半径相同且 `≤6`；
- fp64 辛缺陷 `≤1e-12`；
- Floquet 参考壳残差 `≤1e-12`；
- 旧 RC3-(ii) 描述符仍失败；
- 新描述符若任一实测证书超线，预飞不得返回 `READY-PILOT`。

若 `A_walk` 与 `A_R30` 的插值在任一 `q,κ_C` 样本上越过稳定带，禁止缩小采样集或改
`1e-12` 门；状态保持 `HALT-FAMILY-ADMISSION`，报告具体 `(q,κ_C,k)` 病灶。若家族通过，
下一件才是 30 格 pilot evaluator 与测量协议，不在本设计中夹带实现。
