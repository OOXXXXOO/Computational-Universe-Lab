3. **固定尺度控制行**:null_damped/teeth/R30 决定性跑/G4/G5 载体是冻结 v1 实空间

## 9. state schema 说明(`data/runtime/v2m0_state.json`,v2m0_state v1)

顶层键(文件内 `_doc` 有同文说明,dashboard agent 以此为准):

- `m0_status`:`{control_matrix_pass: "8/8", overall: "PASS"|"HALT"}` → 总牌。
- `control_matrix[]`:8 行,每行 `{id, name, gates[], status: green|red, tol,
  max_abs_diff, remeasured{...}, frozen{...含 source}, seconds}` → 绿/红牌面板直读。
- `epsilon_sigma_anchors[]`:(ε,σ) 平面散点。每项 `{id, sector, swimlane,
  epsilon_dof | epsilon_dof_range, epsilon_E(_range), sigma{by_direction{A,σ_A,α,
  ΔAIC,verdict,band_D3} | note}, source}`。ε 轴 [0,1];σ 建议画 (α, A) 双读数。
  spin0 泳道为 v1 封册事实留位(`epsilon_dof: null`),M0′ 不重测。
- `gate_readings{}`:candidate_id → GateColumns(每门 `{raw, per_L, limit_fit,
  verdict, diagnostics}`;verdict=`CONTROL` 为对答案行,面板应与 PASS/FAIL 区分显示)。
- `sigma_calibration_64`:占位节,σ 校准 agent 回填。
- `hashes`:冻结件校验册(`checked` 为有先行记录并逐位比对;`record_only` 如实标注)。
