# v2 裁定:M1′ 轮 3 —— G6 观测窗重签(2026-07-26,车道A 行使授权)

*承 M1′ 轮 2:7/8 门 PASS + ε_DOF=1.0 首次实测落位(光子恰 2、σ 落 A=0、p=2.0019、
锥外泄漏位级零);G6 唯一 FAIL 于任务书强化残余线 1e-12(L≥32 差 2.3%–8×),追因初判
= 观测窗按试飞 e-fold 标定、实测迟时 e-fold 长 2–3×。lane B 报三选项,本文件裁定。*

## 一、裁定

**取 ①:重签更长观测窗的预注册,门线 1e-12 一字不动,轮 3 重跑。**

理由:轮 2 的 FAIL 曲线**纯指数无底板**,且同机器已证线可达——物理在说"能到",
是观测窗在物理时标前关门。这是仪器病不是物理病,病根与本纲领 v2 的核心教训同构:
**观测窗必须与实测物理时标联动,不得用一次性试飞数字写死**(DHM 极限语言的时域面;
先例:R18 重定稳定窗、44g 耐力窗修正)。改窗不改门,不触"调阈值掩盖失败"红线。

**驳回 ②(加宽 sponge)**:构造侧重冻结不得用于修仪器归因的失败。仅当 §三 分支 B
触发(残余出现底板且与 sponge 反射签名相关)时再议。

**③ 降为存档审计,本轮不生效**:1e-12 确是任务书对 R36 自带 1e-3 门的 9 个量级自行
强化,但其依据成立——M1′ 是 Maxwell 正控闭环,轮 2 其余守恒类读数已实测机器零,
fp64 门 1e-12 是该扇区的正确期望;且**已有一轮在此线上 FAIL,此时放线即移球门**。
审计结论入册:线保留;若 §三 分支 B 触发,③ 升为活议题并须 PI 与会。

## 二、轮 3 重签预注册的硬性要求(写给 lane B,预注册级)

1. **窗规则函数化,不许写死数**:`T_PK(L) = ceil( m × τ_late(L) × ln(R0(L)/1e-12) )`,
   其中 τ_late(L) = **本轮实测**迟时 e-fold(每个 L 在正式判门前的标定段实测,入册),
   R0(L) = 标定段起始残余,裕度 m ≥ 2。禁止再用试飞 e-fold。
2. **先预言后验证**:窗重签的同时,用轮 2 已有的指数率外推,**预先写下**每个 L 的
   预计穿线时刻 T_cross(L) 入预注册;轮 3 实测穿线须落在预言的 ±50% 内。
   这是防"时域调参"(一直加长直到过)的牙:窗不是加到过为止,是按物理率算出来、
   预言、然后验证。
3. **七门不许回退**:轮 2 已 PASS 的 7 门在轮 3 全部重测,任一回退 = 新 HALT,
   不得只补跑 G6。
4. **计数规则**:轮 2 计"连续不过"1 轮,不清零;轮 3 若 G6 再 FAIL → 计数 2,
   按纪律全线停手、写追因报告、报 PI(M1′ FAIL 条款 D2 预备启动)。
5. **炮组维持暂停**,G6 过线后同轮补全炮组,M1′ 收口仍需全门 + 全炮一次运行。

## 三、预写分支(运行前写死,不许事后择)

- **分支 A(预期)**:轮 3 G6 按预言穿线 → M1′ 全门 PASS → 炮组 → 车道A 复核
  (焦点:τ_late 标定的独立性、T_cross 预言命中、七门无回退)→ PI 收口。
- **分支 B**:加窗后残余曲线**偏离纯指数、出现底板** → 仪器归因作废,升级为物理病:
  立即停手;若底板量级与 sponge 反射系数签名相关 → ② 升为活议题(构造侧,重冻结,
  单独预注册);同时 ③ 审计升为活议题(PI 与会)。两升级互不自动豁免对方。
- **分支 C**:穿线但预言脱靶(>±50%)→ G6 判 PASS 但标定机器记疑,τ_late 标定
  方法追因后方可进炮组。

## 四、边界

本裁定只动观测协议,不动任何门线、判据核、构造与冻结件;轮 2 全部读数(含 FAIL)
照常入册;ε_DOF=1.0 落位是 v2 地图 ε=1 锚点的首个闭环级实测,其记账不受 G6 影响,
但 **M1′ 收口前不得对外表述为"Maxwell 闭环完成"**。
