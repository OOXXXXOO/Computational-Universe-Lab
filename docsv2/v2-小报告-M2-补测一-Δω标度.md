## 一、预注册(先行写死;运行前签)

- **观测量**:Δω(k) ≡ |ω_walk(k) − ω_shell(k)| 沿体对角射线 k = comp·(1,1,1);
  ω_walk = 冻结 `cp1_v4_L2.walk_symbol(k, π/3)` 正本征相位(±对称性入册自检),
  ω_shell = 冻结 `r15_walk_dedonder.shell_omega(k, c=0.5)`。axial (1,0,0) 为
  位级零控制列,face (1,1,0) 为诊断列(不参与分支判定)。
- **预言指数**:**α = 2.0 ± 0.3**(同源 p=2 推导:κ_i=2sin(k_i/2) 奇函数无
  二阶差 ⟹ shell O(k²);xyz 有序乘积轴向精确同谱、体对角 BCH 对易子首阶
  O(k²) ⟹ Δω ∝ k²)。
- **拟合协议**:R37 冻结口径逐位同源——L∈{16,24,32,48} 按 n/L 精确分数池化
  去重、拟合窗 n/L ≤ 1/8、k0 邻域(仅 n=1 出处)剔点、常数 vs 幂律 A+B·k^α
  (α 网格 0.05..4.00 步 0.01)、AIC 决定性 |ΔAIC| ≥ 2。
- **常数分量两口径并列**(签发时刻裁定二 D-M2-6 双控制件尚未落盘,按裁定
  "如实报告两口径并列"执行):口径一 = R37 遗留 |A| ≤ 2σ_A;口径二 = D-M2-6
  截断稳健双测(高阶模型 ΔAIC≥2 且截距塌缩 ≥5×;半窗 |A_half| ≤ |A|/2;
  两测同判方为污染)。分支触发用"口径一失守**且**口径二不判污染"。
- **两分支写死**:(a) α∈[1.7,2.3] 且无常数分量 → SCALING-CONFIRMED;
  (b) 常数分量存在 → TRUE-CONE-SPLIT(候选改频重跑,停手报车道A);
  其余 → AMBIGUOUS 报会商。
