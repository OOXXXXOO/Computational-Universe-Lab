# M3′ Strict-Local Real-Space `q` Family Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个统一状态空间、真实可调用、严格局域、fp64 辛、无逐 `k`/FFT 时间步的 `q=0…4` 构造族，并用实测证书把 M3′ Round 0 从 legacy 停手重新判到诚实状态。

**Architecture:** 新模块把冻结 R25 保守 walk 刚度与 R30 Yee 刚度写成四个局域 counter-kick 前缀，并以非负平方罚项 `κ_C||ζ-C_sp h/4||²/2` 保守耦合四通道约束波；宏步是对称 Störmer–Verlet。证书模块从真实 factory 测支撑、adjoint、Floquet、生产步对拍与辛缺陷，并在 `64³` 全布里渊区审计稳定性；预飞并列保存 legacy R2 拒绝和新家族判读，只有实测证书全过才返回 `READY-PILOT`。

**Tech Stack:** Python 3.9+、NumPy fp64、stdlib `dataclasses/unittest/json/hashlib`、冻结 `rulespace_v2.frozen` 适配层。

核心类型固定为：

```python
@dataclass(frozen=True)
class LocalFamilyState:
    h: np.ndarray
    p_h: np.ndarray
    zeta: np.ndarray
    p_zeta: np.ndarray

    @classmethod
    def zeros(cls, L: int, dtype=np.complex128) -> "LocalFamilyState":
        return cls(
            np.zeros((10, L, L, L), dtype=dtype),
            np.zeros((10, L, L, L), dtype=dtype),
            np.zeros((4, L, L, L), dtype=dtype),
            np.zeros((4, L, L, L), dtype=dtype),
        )

    @property
    def schema(self) -> tuple[tuple[int, ...], ...]:
        return tuple(x.shape for x in (self.h, self.p_h, self.zeta, self.p_zeta))
```

局域刚度：

```python
def apply_walk_stiffness(h):
    return frozen.mod("r25_realspace_step").aw_op(h)

def apply_r30_stiffness(h):
    return 0.25 * negative_laplacian(h)

def apply_counter_stiffness(h, layer):
    if layer not in range(4):
        raise ValueError("layer must be 0..3")
    return 0.25 * (apply_r30_stiffness(h) - apply_walk_stiffness(h))
```

`constraint_spatial` 与 adjoint 共享预计算 packed tensor 系数 `C_SP_COEFF[ν,a,i]`；差分固定为
`D_i f = roll(f,-1)-f`，伴随为 `D_i†g = roll(g,1)-g`。

- [x] **Step 6: 实现真实 factory 与对称宏步**

```python
@dataclass(frozen=True)
class LocalFamilyStep:
    q: int
    kappa_c: float
    dt: float

    def __call__(self, state: LocalFamilyState) -> LocalFamilyState:
        p_h, p_zeta = half_potential_kick(state, self.q, self.kappa_c, self.dt)
        h = state.h + self.dt * p_h
        zeta = state.zeta + self.dt * p_zeta
        midpoint = LocalFamilyState(h, p_h, zeta, p_zeta)
        p_h, p_zeta = half_potential_kick(
            midpoint, self.q, self.kappa_c, self.dt
        )
        return LocalFamilyState(h, p_h, zeta, p_zeta)

def realspace_step_factory(q, kappa_c):
    return LocalFamilyStep(
        q=q,
        kappa_c=kappa_c,
        dt=floquet_retune_table()[q]["dt"],
    )
```

`half_potential_kick` 必须按前缀显式执行，不能先在 Fourier 空间合并：

```python
def half_potential_kick(state, q, kappa_c, dt):
    force_h = apply_walk_stiffness(state.h)
    for layer in range(q):
        force_h = force_h + apply_counter_stiffness(state.h, layer)
    force_zeta = apply_r30_stiffness(state.zeta)
    mismatch = state.zeta - 0.25 * constraint_spatial(state.h)
    force_h = force_h - 0.25 * kappa_c * constraint_spatial_adjoint(mismatch)
    force_zeta = force_zeta + kappa_c * mismatch
    scale = 0.5 * dt
    return (
        state.p_h - scale * force_h,
        state.p_zeta - scale * force_zeta,
    )
```

离线 auditor 只在证书函数中使用 plane-wave 探针得到：

```python
V_qk = symbol_of_potential(q, kappa_c, k)
zero = np.zeros_like(V_qk)
identity = np.eye(V_qk.shape[0], dtype=complex)
K = np.block([[identity, zero], [-(dt / 2.0) * V_qk, identity]])
D = np.block([[identity, dt * identity], [zero, identity]])
M = K @ D @ K
```

冻结样本：

```python
K_CERT = (
    (0.0, 0.0, 0.0),
    (2*pi/32, 0.0, 0.0),
    (2*pi/32, 2*pi/32, 0.0),
    (2*pi/32, 2*pi/32, 2*pi/32),
    (pi/2, 0.0, 0.0),
    (pi/2, pi/2, 0.0),
    (pi/2, pi/2, pi/2),
    (pi, pi, pi),
)
```

将复矩阵转成 real representation，按 `[Re(q,p), Im(q,p)]` 使用两个 canonical `J` 块测
`R(M).T @ J_real @ R(M) - J_real`。零模的 Jordan 平移允许稳定模 `|λ|=1`，仍须辛；
零模谱稳定由 Hermitian 势能谱和 `dt² λ_max<4` 判定，不对重根调用通用 eigensolver。
