## 0. 目标与范围

**目标一句话**:自旋 2 端到端耦合闭环——**R30 复形几何(手搭,ε_geo=0)+ 涌现物质
走行耦合**,同一实空间 rule、同一次运行,通过全部极限语言门(DOF/J5、Newton、
Eddington、moving source、守恒、约束分层归纳、稳定)+ 全炮组击穿,把自旋 2 扇区的
第一个**耦合闭环点**以分扇区 ε 坐标 (ε_geo=0, ε_mat 实测) 落上 (ε, σ) 地图。
这是北极星 §五 M2′ 行的操作化:**全门 PASS + 全炮 FAIL = v1 卡点④(单次联验)在
新主语下的重生**。

**不在范围**:任何对 v1 封存主句的重开(§1 写死);几何扇区的涌现主张(ε_geo=0 是
本候选的定义属性,不是待测项);完整双向反作用动力学(v1 死锁地盘,见 §2.3);
M3′ 边界制图与 M4′ 剪枝(共用本闭环产出的锚点,另行预注册);动态维度/不可约投影
(扩展轴排序不变)。

## 1. 主语与主张边界(最关键一节,签发时逐字冻结)

### 1.1 候选主语(写死)

M2′ 候选 = **R30 复形几何 + 涌现物质走行耦合**,三件套:

- **几何扇区:R30 手搭复形**(`experiments/r30_tensor_complex_dynamical.py` 谱系,
  存在性有独立复核证书):放置半角 κ 微积分、placed Riemann/inc 算子、张量
  `div curl = 0` 多项式恒等式、Störmer–Verlet leapfrog 局域酉演化,ker K =
  gauge(4)⊕TT(2) 按构造保持。**ε_geo = 0,如实记账:几何扇区全部传播-曲率 DOF
  手搭,零涌现。**
- **物质扇区:涌现 Dirac 走行**(v1 冻结走行谱系的物质半):物质场由规则动力学
  自行传播,目标 ε_mat = 1(由 j_inv 不变量机器实测,不由构造声明)。
- **耦合层:源链**(R10 精确键流 + R25 source-lift/运动源镜像 sector 血统):物质
  应力-能量以 de Donder 相容方式作 R30 复形的源;光行/测试场在 h 背景上读
  Eddington(置零反事实)。基线为**弱场单向源耦合 + 测试场读数**(§2.3)。

### 1.2 与 v1 封存的关系(红线,不许改写)

- **不翻案**:v1 封存主句——"纲领四承诺全要时,自旋 2 的 M3 结构性不可达,死于
  极化计数与稳定性死锁"——**原样不动**。本任务书**不宣称"涌现走行落进复形"**,
  不宣称任何绕过 76.2° 运动学锚、R36 (b) 三线或死锁标度性的路径。M2′ 的任何结果
  (含全绿)都**不追溯修改**封存结论。
- **宣称的是什么**:"**手搭正确几何 + 涌现物质的耦合闭环**"——即 RC3-(ii) R2 落点
  ("部分 Yee 化 = R30 几何 + 涌现物质走行")的**正面化**,血统为封存文档 §八
  **选项 A** 原文:"把'手搭正确几何 + 涌现物质耦合'(RC3-(ii) R2 的落点)正面化"。
  v2 坐标语言下:这是在 ε 轴 **ε_geo=0 端**打的一个耦合闭环点,不是向 ε_geo=1 端的
  任何位移。
- **比 R2 更彻底也更干净**:RC3-(ii) R2 实测"达 2 需手搭 75–100% 传播-曲率 DOF,
  只剩 TT(扇区能量 14–39%)真涌现"。本候选基线**不取部分 Yee 化**,而取
  **整几何扇区手搭(j_hand = N_curv,ε_geo 恰 0)**——记账口径最锐利、无"TT 半
  涌现"的灰区。"部分 Yee 化保 TT 涌现"的变体是 ε_geo∈(0,0.25] 的族参数,属 M3′
  边界制图,不进 M2′ 主跑。
- **卡点④ 的地位**:v1 卡点④(全门 + 九炮 + endurance 同一次运行)在原主语
  ("涌现走行形变到复形")下**继续正式按住**,永不因 M2′ 解封。M2′ 联验是同一
  验收形态在**新主语**(耦合系统)下的重生;两者主语不同,不得混用表述。

### 1.3 主张分级与措辞红线

- M2′ PASS 可宣告的最大句(L1/L2 级):"**自旋 2 耦合闭环完成:手搭 R30 几何 +

## 2. 候选构造基线与择定(D-M2-1 已裁——审定 R4)

### 2.1 几何基座(冻结件,只读)

R30 复形以 `r30_tensor_complex_dynamical.py` + `r30_complex_verify.py`(独立复核)
为构造权威;M2′ 候选的几何 step 由 `rulespace_v2` **加文件**(如 `spin2.py`)载入,

N_prop=2 断崖、Bianchi 多项式恒等式、酉性(|eig|=1 于 CFL 带)在预飞对拍行复证
(§5),不引证书代填。

### 2.2 物质走行与耦合层

- 物质走行:v1 冻结 Dirac 走行谱系(物质半),θ_m 与几何 leapfrog 的 dt=c=cos θ_g
  **共 θ**(J5 按构造瞄准,实测判定)。**D-M2-1 已裁(审定 R4):基线物质载体 =
  v1 冻结走行物质半**(I 类资产,证书链最全);其他局域酉 Dirac 载体归 M3′ 族参数,
  不进 M2′;
- 静源:R25 source-lift 静态件(I 类继承)→ Newton 井;
- 动源:R10 精确键流(de Donder 相容按放置给)+ R25-E2 运动源镜像 sector
  (保 h̄₀ᵢ,reality 生成镜像,非 `Re(h̄₊)`),源速上限预注册为 **v/c ≤ 0.5
  (即格点单位 v ≤ 0.25,c=cos θ_g=0.5)**——草案 "v≤0.5c" 的歧义(0.5c vs
  0.5 格点单位)按审定 R3 就此钉死;
- 源守恒相容性:R30 契约——`κ^m G_mn ≡ 0`(恒等式)⟹ 源必须满足 `κ^m T̄_mn = 0`
  方可自洽;物质走行给出的 T̄ 行守恒残差即 M2-G5 的门读数(§3)。

### 2.3 耦合方向裁定(D-M2-1 核心子项,已裁——审定 R4)

- **基线(默认):弱场单向耦合**——物质 T̄ → 几何源(线性响应),Eddington 用
  h 背景上的**测试场/零测地读数**(R25 Eddington 谱系,置零 h_ij 反事实),
  **不含几何→物质的动力学反作用回授**(审定 R4:单向 + 测试场基线批准)。
- **理由(封存血统,写死)**:双向反作用是 v1 死锁的地盘(R36 (b):72 个非零
  反作用构型 0 稳定;BZ 超增长 ∝η²,无调参走廊)。虽然彼处主语是"涌现走行 +
  清尾耦合"而此处是"手搭复形 + 物质源",**不得默认死锁不迁移**:北极星 §五
  M2′ FAIL 分支("耦合层出现新死锁 → 封存式追因,不硬闯")正为此预留。
- **死锁哨兵(预注册)**:主跑全程监测 BZ 谱半径超增长随耦合强度 η 的标度;若出现
  ∝η² 型超增长(v1 死锁指纹,比值判据沿封存 §一支撑 3 口径;定量触发线 D-M2-5
  已裁,见 §3 M2-G7 与 §6——审定 R5),立即触发 §6 FAIL 分支,禁止调 η 到过。
- 双向反作用变体:仅作**记名探测项**(不进 PASS 判定),且只在单向基线全绿后、
  带哨兵、限预算试跑;任何不稳即如实入册停手。**探测预算定量化(审定 R4):预算
  ≤ 单轮计算时间 10%、哨兵必备、任何不稳即停,结果只入册不进判定。**
