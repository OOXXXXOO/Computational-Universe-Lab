# M3′ 涌现边界制图 Round 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以可测试的 manifest 与家族准入审计启动 M3′ 预飞，并在当前 RC3-(ii) 仍只是谱空间记账时诚实停在 `HALT-FAMILY-ADMISSION`。

**Architecture:** `rulespace_v2/m3_family.py` 只定义冻结参数表和纯函数审计，不触碰冻结实验脚本；`experiments/v2m3_preflight.py` 只读上游 SHA/运行态与 RC3-(ii) 拓扑锚，写一份结果和一份运行态。主 pilot 与昂贵扫描保持未实现、未解锁，避免预飞越权成为主跑。

**Tech Stack:** Python 3.12、stdlib `dataclasses/json/hashlib/unittest`、NumPy fp64、现有 `rulespace_v2.frozen` 适配层。
