# v2 设计：M3′ 30 格 pilot 实测（2026-07-30）

*状态：执行设计。承 `v2-任务书-M3-涌现边界制图.md` 的 `READY-PILOT`，依 PI
既有授权由执行者完成路线裁定、自审和实施。本件只运行冻结的 `5×6=30` 格 pilot，
不运行、也不解锁 `10²–10³` 正式扫描。*

## 1. 方案裁定

| 路线 | 内容 | 裁定 |
|---|---|---|
| A | 全尺寸局域波包长演化，再用时序 FFT/DMD 分离传播模 | 不采用：pilot 会变成小长跑，且引入窗函数、时长和模分离新口径 |
| B | 直接读取 `symbol_of_potential` 生成 Floquet 模 | 不采用作主证据：快速但不是“实际运行后测量” |
| C | 对 28 个 canonical delta 输入各调用一次真实 `realspace_step_factory`，由实测紧支撑核重建 Floquet shell | **采用**：每格均真实运行，生产时间步无 FFT/逐 `k` 投影，且资源有界 |

路线 C 利用已证的一步支撑半径 `R=4`。在 `L_probe=17>2R` 的周期格上，中心 delta
响应不会与自身重叠；28 次生产宏步完整测得该 cell 的 `28×28` 平移不变传播核。Fourier
求值只发生在运行结束后的 evaluator 中，地位等同于对实测输出作频谱分析，不进入动力学。

## 2. 冻结运行协议

每个 manifest cell `(q,κ_C,η=0,ε_mat=1)` 执行：

1. 在 `L_probe=17`、中心格点依次激发
   `X=(h[10],ζ[4],p_h[10],p_ζ[4])` 的 28 个单位 delta；
2. 每次只调用一次该 cell 的 `realspace_step_factory(q,κ_C)`；
3. 按同一通道序收集输出，形成
   `K[out_channel,in_channel,dx,dy,dz]`；
4. 记录实测最大支撑半径、kernel SHA-256、28 次运行计数和 wall time；
5. 用固定复振幅的直接 plane wave 生产步，与实测核在同一 `k` 的响应作独立桥接，
   相对残差须 `≤1e-12`；
6. 对冻结射线所需的 `k`，仅在运行后计算
   `M(k)=Σ_dx K(dx)exp(-ik·dx)`。

生产运行路径继续禁止 `numpy.fft`；evaluator 也不需要 FFT，只对半径 4 的已测系数作有限和。
离线 `symbol_of_potential` 只允许作为测试负控，不产生权威坐标。

## 3. 传播—曲率子空间

对实测 `M(k)`：

1. fp64 本征分解，按 `|λ|-1≤1e-10` 识别稳定 Floquet 模；若任一非零判据模超线，
   cell 无效；
2. 以 `arg λ>1e-9` 取正频支；坐标块投影到 physical `h[10]`；
   先对整个正频支的 `h` 投影作 SVD 正交化，避免本征向量缩放或简并簇内换基改变后续秩；
3. 用冻结 R30 placed null shell
   `κ_placed(k,c=1/2)` 构造 `inc_matrix` 与
   `ker C = TT[2] ⊕ gauge[4]`；
4. 对 `inc @ B_h` 作 SVD，以冻结阈值 `s_i/s_0≥0.05` 取
   `S_curv`，其秩为 `N_curv`；
5. 对 `span(S_curv)` 与 `ker C` 调用
   `rulespace_v2.invariants.subspace_invariants`。

选择完整正频支而非某一条“看起来最好”的频带，避免 `κ_C` 引起频带交叉时事后挑模。
辅助 `ζ` 模若在 `κ_C=0` 时没有 `h` 分量，会由曲率 SVD 自动丢弃。

## 4. `ε_geo` 实测

沿冻结三方向：

```text
axial        d=(1,0,0)
face-diagonal d=(1,1,0)
body-diagonal d=(1,1,1)
```

主判参考比值固定为 `n/L=1/8`，即每个非零分量为 `π/4`。逐方向定义：

```text
j_hand_inv(d) = #{sin θ_i(span(S_curv),ker C) >= 0.05}
ε_geo(d)      = 1 - j_hand_inv(d)/N_curv(d)
```

每格同时报告：

- `epsilon_geo_by_direction`；
- `epsilon_geo_min_max`，作为 pilot 地图的保守区间，不跨方向平均；
- 离散签名 `[(N_curv,j_hand_inv)_axial,face,body]`；
- `ε_E` 诊断：`S_curv` 在 TT 子空间中的平均投影能量，只入册、不判门；
- 全主角谱与三次固定种子简并簇内酉旋转的基稳健性，漂移须 `≤1e-12`。

`q` 不进入上述公式，`κ_C` 也不进入任何坐标赋值。

## 5. `σ=(α,A)` 实测

三个方向分别继承 R37 冻结协议：

- lattice provenance：`L={16,24,32,48}`；
- 上下文窗：每分量 `n/L≤1/4`；
- 拟合窗：每分量 `n/L≤1/8`；
- 按有理比值去重；
- 合并点至少有一个 `n≥2` 出处，纯 `n=1` 点只作扩窗诊断；
- 主观测量：`max sin θ(span(S_curv),ker C)`；
- 辅观测量：`rms sin θ`；
- 双模型：常数与 `A+B|k|^α`，`α=0.05…4.00`、步长 `0.01`；
- `|ΔAIC|≥2` 才称决定性；幂律决定性胜出且 `|A|≤2σ_A` 才为 PASS；
- `|A_winner|≥0.05` 且排零失败为 FAIL；其余 ambiguous。

每格报告逐方向 `(α,A,σ_α,σ_A,ΔAIC,verdict)`，另报逐点 LOO 与纳入纯 `n=1`
点的扩窗诊断。三个方向不平均，不以最优方向替代完整结果。

## 6. 运行门与可分辨性复核

### 6.1 运行有效性

30 格全部同时满足才可进入可分辨性复核：

- 每格恰有 28 次实空间 delta 生产运行；
- 实测支撑半径 `≤4`；
- kernel—plane-wave 桥接残差 `≤1e-12`；
- 非零判据模 `max |||λ|-1||≤1e-10`；
- `N_curv>0` 且三方向全部得到有限坐标；
- 基不变量漂移 `≤1e-12`；
- 脚本、上游 preflight、局域家族证书和结果 SHA 闭合。

任一失败返回 `HALT-PILOT-INVALID`，不作边界解释。

### 6.2 判据有牙

pilot 只有同时满足以下预注册条件才称“可分辨”：

1. **ε 计数牙**：30 格中至少出现两个不同的三方向
   `[(N_curv,j_hand_inv)]` 离散签名；
2. **σ 连续牙**：至少存在一对 cell、同一方向，其幂律截距的
   `[A-2σ_A,A+2σ_A]` 区间不交且间隔严格大于 `1e-8`，该差异还须在双方全部
   LOO 拟合中保持同号且最小间隔大于 `1e-8`。该绝对牙距远高于本机 fp64/桥接
   `1e-12` 线，防止把 ULP 漂移误判为连续坐标可分辨；
3. **边界括区牙**：至少一个方向同时出现 PASS 和 FAIL cell；只有 PASS/ambiguous
   或 FAIL/ambiguous 不能声称已括住边界；
4. **方向完整性**：上述检查使用轴/面/体全部读数，不删除坏方向；
5. **资源牙**：实测总 wall time 与峰值 RSS 外推到 30 格的余量至少为 `1.5×`，
   且没有启用 GPU 或正式扫描。

资源上限在运行前固定为单进程 CPU wall `300 s`、峰值 RSS `2 GiB`。第一个 manifest
cell 同时是正式数据和资源样本，不为 benchmark 重跑；用其 wall time 作 `30×` 外推，
并以 `min(300/外推秒数, 2 GiB/实测峰值 RSS)` 定义预飞余量。若小于 `1.5`，保留首格
证据后停止，不运行其余 29 格。最终资源牙用 30 格实际总 wall 与实际峰值 RSS 重算。

这是 pilot 的元判据，不是 M3′ 物理 PASS。若运行有效但任一判齿条件不满足，状态固定为
`HALT-PILOT-UNRESOLVED`：回 M0′ evaluator/重设计构造族，正式扫描保持锁定。

若全部满足，只能写 `READY-FORMAL-PREREGISTRATION`：允许另行冻结 `10²–10³`
正式扫描任务书；本轮仍令 `formal_scan_unlocked=false`，不得直接开跑。

## 8. 自审

- 实际运行与运行后频谱分析的边界清楚，未把离线 symbol 偷换成 cell 输出；
- ε 的离散计数、σ 的拟合和构造旋钮完全分离；
- 三方向、LOO、扩窗和两侧括区均预先写死；
- 稳定阈值 `1e-10` 比 Round 0 实测 `4.3e-15` 留有超过 `10^4` 倍数值裕度；
- `1e-12` 桥接/基稳健门沿既有 fp64 证书线，不骑在预期信号上；
- 若该保守族使正频 `h` 支张满相同子空间，设计会如实给出“无牙”而不是换支、改窗或改阈值；
- 唯一可能的解锁状态仍需另行正式预注册，当前实现不会启动正式扫描。
