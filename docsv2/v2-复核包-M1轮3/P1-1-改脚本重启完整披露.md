## 3. 修改动机与 bug 描述

- bug:分支 A 的 verdict 文案字符串同时含字面量 `%` 与 `%s` 占位符,经 `%`
  格式化时,`±50% 全命中` 中 `%` 后的 `全`(U+5168)被解析为格式符 →
  `ValueError: unsupported format character '?' (0x5168) at index 23`。
- 触发位置:pre-fix 版第 1360 行(`main()` 尾部 verdict 组装),在
  `payload["branch"]/"verdict"/"status"` 写入**之前**、全部物理段/门列组装/
  分支判定计算**之后**——纯报告层,不触任何判据数值。
- 为什么必须重启:崩溃发生于终态写盘前,增量 JSON 停留在 status=RUNNING、无
  verdict/branch 终态节;脚本无断点续跑设计(预注册为"每 L 一条连续运行记录"),
  合法路径只有整脚本确定性重跑。判据/窗规则/预言表/门线/种子零改动。
